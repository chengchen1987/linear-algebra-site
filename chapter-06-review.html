第六部分综合复习

Part 6: Review and Connections

本部分把第一部分的“能否精确达到目标”延伸为“在所有可达向量中，哪一个最接近目标”。请先检查对象与条件，再计算；每题的反馈既给数值，也解释为什么这样做。

从解方程到最佳逼近 From Solving Equations to Best Approximation

固定实矩阵 A∈ℝm×nA\in\mathbb R^{m\times n}、秩 rr，固定目标 𝐛∈ℝm\mathbf b\in\mathbb R^m，未知系数 𝐱∈ℝn\mathbf x\in\mathbb R^n。

问题 / Question 精确方程 A𝐱=𝐛A\mathbf x=\mathbf b / Exact equation 最小化 ∥𝐛−A𝐱∥\|\mathbf b-A\mathbf x\| / Least squares
几何条件 / Geometry 目标属于 Col⁡A\operatorname{Col}A 像等于 proj⁡Col⁡A𝐛\operatorname{proj}_{\operatorname{Col}A}\mathbf b
代数判据 / Algebra rank⁡[A∣𝐛]=r\operatorname{rank}[A\mid\mathbf b]=r；等价于每个左零空间向量与 𝐛\mathbf b 点积为零 ATA𝐱=AT𝐛A^TA\mathbf x=A^T\mathbf b
固定目标的存在性 / Existence for this target 取决于相容条件 总存在
对所有目标的存在性 / Existence for every target 当且仅当 r=mr=m（满行秩） 对任意A均成立
系数唯一性 / Unique coefficients 对固定目标：先相容，再要求 r=nr=n 当且仅当 r=nr=n，与目标取值无关
全部系数解 / All coefficient solutions 相容时 𝐱p+Nul⁡A\mathbf x_p+\operatorname{Nul}A；不相容时空集 始终为 𝐱̂0+Nul⁡A\widehat{\mathbf x}_0+\operatorname{Nul}A
输出与误差 / Output and error 相容时输出固定为 𝐛\mathbf b，误差0 投影、残差与最小误差始终唯一

对所有目标都恰有一个精确解要求同时满行秩、满列秩，因而必须 m=n=rm=n=r；只满列秩不保证相容。相容时两类解集相同，这是最小二乘的一种边界情形。

一条直线串起几何与代数 A Line Connects Geometry and Algebra

取 𝐚=(1,1)T,𝐛=(2,0)T\mathbf a=(1,1)^T,\mathbf b=(2,0)^T。求投影矩阵 PP、残差与误差，写 PP 的两个特征空间；说明为什么更换直线的基不改结果。

提示 / Hint

投影保留沿直线的分量、消去正交方向。可以先不解特征方程。

完整解答 / Full Solution

P=12[1111]P=\frac12\begin{bmatrix}1&1\\1&1\end{bmatrix}，P𝐛=(1,1)TP\mathbf b=(1,1)^T，残差 (1,−1)T(1,-1)^T，误差 2\sqrt2。E1=Span⁡{(1,1)T}E_1=\operatorname{Span}\{(1,1)^T\}，E0=Span⁡{(1,−1)T}E_0=\operatorname{Span}\{(1,-1)^T\}。更换非零倍数只是换直线的基，投影由子空间决定；也可在分子分母中约去同一倍数的平方。P2=P=PTP^2=P=P^T，但幂等单独不够，见反例。

同一数据的两种求解路线 Two Solution Routes for the Same Data

对 (0,1),(1,1),(2,2)(0,1),(1,1),(2,2)，写设计矩阵，解释精确直线方程为何不相容；任选正规方程或QR求参数，另一种方法作核验。必须分别报告参数、拟合向量与残差。

提示 / Hint

前两式给 c=1,d=0c=1,d=0，检查第三式。QR计算中先得到Q坐标，再回代。

完整解答 / Full Solution

X=[101112]X=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix}，第三式要求 c+2d=2c+2d=2，与前两式的结果不符。正规方程给 (ĉ,d̂)=(5/6,1/2)(\widehat c,\widehat d)=(5/6,1/2)；QR给 QT𝐲=(4/3,1/2)TQ^T\mathbf y=(4/\sqrt3,1/\sqrt2)^T，回代得到同一参数。拟合 (5/6,4/3,11/6)T(5/6,4/3,11/6)^T，残差 (1/6,−1/3,1/6)T(1/6,-1/3,1/6)^T，XT𝐞=0X^T\mathbf e=0，误差平方 1/61/6。完整步骤见线性模型。

第二组数据。 对 (1,1),(2,2),(3,2)(1,1),(2,2),(3,2) 拟合直线 y=c+dty=c+dt，求截距、斜率、拟合值、残差及残差平方和，并核验残差与设计矩阵各列正交。

提示 / Hint

每行设计向量为 (1,ti)(1,t_i)；建立两条正规方程。

完整解答 / Full Solution

设计矩阵为 X=[111213]X=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix}，所以 XTX=[36614]X^TX=\begin{bmatrix}3&6\\6&14\end{bmatrix}、XT𝐲=(5,11)TX^T\mathbf y=(5,11)^T。相减消元得截距 2/32/3、斜率 1/21/2；拟合 (7/6,5/3,13/6)T(7/6,5/3,13/6)^T、残差 (−1/6,1/3,−1/6)T(-1/6,1/3,-1/6)^T，误差平方仍为 1/61/6。 因残差分量之和及其与 (1,2,3)T(1,2,3)^T 的点积均为零，XT𝐞=0X^T\mathbf e=0。

秩亏与四空间 Rank Deficiency and the Four Spaces

取 B=[121212]B=\begin{bmatrix}1&2\\1&2\\1&2\end{bmatrix}。对 𝐛=(1,1,2)T\mathbf b=(1,1,2)^T 求全部最小二乘解；若把目标改成 𝐛=(2,2,2)T\mathbf b=(2,2,2)^T，哪些结论改变？

提示 / Hint

Col⁡B\operatorname{Col}B 是常数方向，Nul⁡B=Span⁡{(−2,1)T}\operatorname{Nul}B=\operatorname{Span}\{(-2,1)^T\}。投影首先确定的是输出。

完整解答 / Full Solution

第一种目标的投影为 (4/3,4/3,4/3)T(4/3,4/3,4/3)^T，全解为 (4/3,0)T+s(−2,1)T(4/3,0)^T+s(-2,1)^T，残差 (−1/3,−1/3,2/3)T∈Nul⁡(BT)(-1/3,-1/3,2/3)^T\in\operatorname{Nul}(B^T)。第二种目标已在列空间中，全解变为 (2,0)T+s(−2,1)T(2,0)^T+s(-2,1)^T，误差变为0，系数仍不唯一。BTBB^TB 始终奇异；这不妨碍两类最小二乘问题有解。

函数逼近与度量 Function Approximation and the Metric

用一次多项式逼近 t2t^2，分别采用 [−1,1][-1,1] 上积分内积与节点 −1,0,1-1,0,1 的求值内积。为什么两个结果不同？再写出 [0,2π][0,2\pi] 上 f(t)=tf(t)=t 的一阶傅里叶投影。

完整解答 / Full Solution

两种内积下 1,t1,t 都正交，但 t2t^2 沿常数方向的系数分别为 (2/3)/2=1/3(2/3)/2=1/3 与 2/32/3。它们优化不同误差度量：一个比较整个区间的平方积分，一个比较三个采样值的平方和。残差分别为 t2−1/3t^2-1/3 与 t2−2/3t^2-2/3。傅里叶一阶投影为 π−2sin⁡t\pi-2\sin t；它在两端均取 π\pi，最优含义是积分平方误差最小，不是处处误差最小。

进一步计算与辨析 Further Calculations and Interpretation

正交化训练。 对 (1,1,1,1)T,(0,1,1,1)T,(0,0,1,1)T(1,1,1,1)^T,(0,1,1,1)^T,(0,0,1,1)^T 正交化，先不归一化。

提示 / Hint

依次减去在已得到正交方向上的投影，缩放残差不改变其方向。

完整解答 / Full Solution

第一向量保留。第二残差是 (−3/4,1/4,1/4,1/4)T(-3/4,1/4,1/4,1/4)^T，可乘正数4改写为 𝐯2=(−3,1,1,1)T\mathbf v_2=(-3,1,1,1)^T。第三列在前两方向上的投影为 12(1,1,1,1)T+16(−3,1,1,1)T=(0,2/3,2/3,2/3)T\frac12(1,1,1,1)^T+\frac16(-3,1,1,1)^T=(0,2/3,2/3,2/3)^T，故第三残差 (0,−2/3,1/3,1/3)T(0,-2/3,1/3,1/3)^T 可乘3化为 𝐯3=(0,−2,1,1)T\mathbf v_3=(0,-2,1,1)^T。三个向量平方范数为 4,12,64,12,6，两两点积为零。归一化并取点积可得 R=[23/2103/21/3006/3]R=\begin{bmatrix}2&3/2&1\\0&\sqrt3/2&1/\sqrt3\\0&0&\sqrt6/3\end{bmatrix}；其正对角对应最终单位向量的方向。可对照教材§6.4的逐步正交化。

由核判断一个模式。 将一个二值图案按列排成非零向量 𝐰\mathbf w，令 W=Span⁡{𝐰}W=\operatorname{Span}\{\mathbf w\}，选 W⟂W^\perp 的一组基作为 CC 的行，记 M=CTCM=C^TC。为什么 𝐮TM𝐮=0\mathbf u^TM\mathbf u=0 当且仅当 𝐮∈W\mathbf u\in W？这与教材§6.3图案识别例有何联系？

完整解答 / Full Solution

𝐮TM𝐮=∥C𝐮∥2\mathbf u^TM\mathbf u=\|C\mathbf u\|^2，为零当且仅当 C𝐮=0C\mathbf u=0，即 𝐮⟂W⟂\mathbf u\perp W^\perp。由正交分解，(W⟂)⟂=W(W^\perp)^\perp=W：若 𝐮=𝐰0+𝐳\mathbf u=\mathbf w_0+\mathbf z，𝐳∈W⟂\mathbf z\in W^\perp，又 𝐮⟂W⟂\mathbf u\perp W^\perp，与 𝐳\mathbf z 点乘得 ∥𝐳∥2=0\|\mathbf z\|^2=0。所以判据精确识别这一条模式直线。若 𝐮,𝐰\mathbf u,\mathbf w 均为非零0–1向量，同一条直线上只能有 𝐮=𝐰\mathbf u=\mathbf w；一般实向量还会包含所有非零缩放，不能把这个数学判据当作通用图像识别算法。

前后部分怎样连接？ Connections across the Course

第一部分的存在性与唯一性在本部分变成“精确解”与“最优系数”的比较。第二部分的秩与四空间说明核引入多少自由系数、左零空间容纳怎样的残差；转置把逐列正交组织成一个方程；LU与QR都说明矩阵分解如何组织计算。

第四部分的基与坐标解释 RR 的转换方向，一般空间让函数逼近成为同一理论。第五部分的一般特征基不自动正交，投影却可直接从 W,W⟂W,W^\perp 读出0、1特征空间。

若 AA 是 n×nn\times n 实方阵，则 AA 可逆当且仅当 ATAA^TA 可逆：两者都等价于 Nul⁡A={0}\operatorname{Nul}A=\{0\}。这是把已有可逆矩阵定理与核等式连接起来的课程推论，不是教材新编号的续篇。

第七部分的正交对角化 / Orthogonal Diagonalization连接特征方向与正交基；SVD与最小范数 / SVD and Minimum Norm继续解决“秩亏时怎样选择一个系数解”。导读 / Part 7 Overview给出从二次型到数据降维的阅读路线。
