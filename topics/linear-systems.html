线性方程组与矩阵表示

Linear Systems and Matrix Representation

求解是在寻找什么？ 未知数的一组取值，需要同时满足所有给定条件。 本页及当前例题在实数范围内讨论；后续内容会按需要说明标量范围。 从方程的含义出发，学习怎样用矩阵记录同一组条件；随后用高斯消元法求解。

从一个候选答案开始 Start with a Candidate Solution

考虑方程组 {2x−y=0,−x+2y=3.\left\{\begin{aligned} 2x-y&=0,\\ -x+2y&=3. \end{aligned}\right. 按 x,yx,y 的顺序取 (1,2)(1,2)，代入后两式左边分别得到 0,30,3，因此这组取值同时满足两个方程；若取 (0,0)(0,0)，则只满足第一式。求解要找的是能够同时满足所有方程的一组未知数取值，不能为每个方程分别选取不同的数。

线性方程、方程组与基本记号 Linear Equations, Systems and Notation

形如 a1x1+⋯+anxn=ba_1x_1+\cdots+a_nx_n=b 的方程叫作线性方程（linear equation）。nn 为正整数，x1,…,xnx_1,\ldots,x_n 是未知数（unknowns）， 给定的实数 a1,…,ana_1,\ldots,a_n 为系数（coefficients），bb 是给定的常数项（constant term）。 未知数只以一次项出现，允许系数为零；没有未知数之间的乘积。 例如 2x−y=02x-y=0、x−3z=2x-3z=2 都是线性的，xy=1xy=1 和 x2+y=1x^2+y=1 不是。 这里“哪些量是未知数”须先说清：系数是题目给定的数，求解时不随未知数改变。

mm 个关于同一组 nn 个未知数的线性方程构成线性方程组（system of linear equations）： {a11x1+⋯+a1nxn=b1,⋮am1x1+⋯+amnxn=bm.\left\{\begin{aligned} a_{11}x_1+\cdots+a_{1n}x_n&=b_1,\\ \qquad\vdots\\ a_{m1}x_1+\cdots+a_{mn}x_n&=b_m. \end{aligned}\right. m,nm,n 为正整数，可以不同。第一个下标 ii 指第几个方程，第二个下标 jj 指第几个未知数的系数。 我们按固定顺序排列未知数 x1,…,xnx_1,\ldots,x_n，并按这个顺序记录它们的一组取值。例如，按 x,yx,y 的顺序，(1,2)(1,2) 表示 x=1x=1、y=2y=2；顺序颠倒，含义也随之改变。

解与解集 Solutions and Solution Sets

未知数的一组取值若使每个方程都成立，就叫作方程组的一个解（solution）；所有解合起来叫作解集（solution set）。代入检验时，要检查全部方程：只满足其中一式，还不能称为方程组的解。

面对给定的线性方程组，我们首先应该判断：是否存在一组未知数的取值，能够同时满足所有方程？如果存在，还需要进一步判断：这样的解是否唯一？这分别是解的存在性（existence）与唯一性（uniqueness）问题。

没有解时，解集为空集（empty set）⌀\varnothing。有至少一个解称为相容（consistent）；否则不相容（inconsistent）。一般不能仅凭方程和未知数的个数作出判断，还需要考察方程之间的具体关系。行图像的三个变式将比较相同数目的方程为何会有不同结果。数量有时也能提供限制：例如，未知数多于方程时，相容系统不能有唯一解；主元与自由变量会解释这个限制。

固定顺序，把方程写成矩阵 Fix the Order and Write the Matrix

仍用开头的方程组。先固定未知数顺序 x,yx,y，再按方程的次序逐行记录系数。 这样排成的矩形数表叫矩阵（matrix）；横排叫行（row），竖排叫列（column）。 系数矩阵（coefficient matrix）为 A=[2−1−12].A=\begin{bmatrix}2&-1\\-1&2\end{bmatrix}. 第一行记录第一个方程的系数；第二行记录第二个方程的系数。第一列记录各式中 xx 的系数，第二列记录 yy 的系数。 负号是系数的一部分，−y-y 的系数是 −1-1，不是 11。

把各方程右边的常数按同样次序排为一列 𝐛\mathbf b，再附在 AA 右边，得到增广矩阵（augmented matrix）： 𝐛=[03],[A𝐛]=[2−10−123].\mathbf b=\begin{bmatrix}0\\3\end{bmatrix},\qquad \left[\begin{array}{c|c}A&\mathbf b\end{array}\right]=\left[\begin{array}{rr|r}2&-1&0\\-1&2&3\end{array}\right]. 竖虚线仅用来分隔系数部分与常数列；它不是数据列。最右列记录常数，不代表多一个未知数。

缺项必须补零 Use Zeros for Missing Terms

若未知数顺序是 x,y,zx,y,z，那么 x−3z=2x-3z=2 的系数应依次记录为 1,0,−31,0,-3，等号右边的常数为 22：中间的零保存了 yy 的位置。 例如 {x−3z=2,−y+z=−1.\left\{\begin{aligned} x-3z&=2,\\ -y+z&=-1. \end{aligned}\right. 对应的增广矩阵是 [10−320−11−1].\left[\begin{array}{rrr|r}1&0&-3&2\\0&-1&1&-1\end{array}\right]. 逐行检查时，先对齐未知数，再抄系数和各方程右边的常数，就不容易漏掉缺项或负号。

一般尺寸与转写所需的信息 Dimensions and Required Information

mm 个方程、nn 个未知数的系数矩阵 AA 有 mm 行、nn 列，尺寸记为 m×nm\times n；增广矩阵有 mm 行、n+1n+1 列。 𝐛\mathbf b 有 mm 个分量。矩阵不必是方阵，上面缺项例的 AA 就是 2×32\times3。

反过来，指定未知数顺序为 x,yx,y，并知道竖虚线标出常数列，便可把 [2−10−123]\left[\begin{array}{rr|r}2&-1&0\\-1&2&3\end{array}\right] 逐行还原为 {2x−y=0,−x+2y=3.\left\{\begin{aligned} 2x-y&=0,\\ -x+2y&=3. \end{aligned}\right. 若改用顺序 y,xy,x，第一行就表示 2y−x=02y-x=0，含义变了。 只有系数矩阵 AA，无法确定各方程右边的常数：同一个 AA 可以配不同的 𝐛\mathbf b，得到不同的方程组。 因此，从矩阵读回方程组时，仍需明确未知数的顺序和常数列的位置。

短练习与反馈 Short Practice and Feedback

先独立完成，再展开答案核对。

  1. 以 x,yx,y 为未知数，3x−2y=53x-2y=5、xy=5xy=5、x2−y=0x^2-y=0 哪些是线性方程？

  2. 按 x,y,zx,y,z 顺序，把下面的方程组写成系数矩阵与增广矩阵：

    {x−3z=2,−y+z=−1.\left\{\begin{aligned} x-3z&=2,\\ -y+z&=-1. \end{aligned}\right.

  3. 按 u,vu,v 顺序，将下面的增广矩阵还原为方程组。若只给前两列，缺什么信息？

    [0−2410−1].\left[\begin{array}{rr|r}0&-2&4\\1&0&-1\end{array}\right].

  4. 判断 (0,0)(0,0)、(1,2)(1,2)、(3,3)(3,3) 是否为开头两式的解。再说明“三个方程、五个未知数”的候选答案需要几个数。

答案：辨认线性与双向转写

  1. 只有 3x−2y=53x-2y=5 是线性的；另两式分别含未知数乘积和平方。

  2. A=[10−30−11]A=\left[\begin{smallmatrix}1&0&-3\\0&-1&1\end{smallmatrix}\right]，增广矩阵见缺项例。零不能省，第二行首项为零，yy 系数为 −1-1，等号右边的常数也为 −1-1。

  3. 方程组为

    {−2v=4,u=−1.\left\{\begin{aligned} -2v&=4,\\ u&=-1. \end{aligned}\right.

    仅有系数矩阵不能知道各方程右边的常数 4,−14,-1；反向转写还需固定未知数顺序。

答案：逐式代入检验

三个点使两式左边依次为 (0,0)(0,0)、(0,3)(0,3)、(3,3)(3,3)，只有 (1,2)(1,2) 同时给出所需的 (0,3)(0,3)。 五个未知数的候选答案需要五个数；三个方程给出三项检查，不把答案改成三元组。

概念与术语：回到含义查阅 Concepts and Terminology

术语 使用时要检查什么
线性方程 / linear equation 给定系数与一次项，没有未知数乘积
解 / solution；解集 / solution set 每一式同时成立；一个解与所有解的集合不同
相容 / consistent 至少一个解，不等于唯一解
系数矩阵 / coefficient matrix 未知数顺序、缺项补零、负号
增广矩阵 / augmented matrix 常数列与尺寸，末列不对应未知数
