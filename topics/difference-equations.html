差分方程：解空间与初值

Difference Equations: Solution Spaces and Initial Values

递推用相邻项之间的关系生成序列。它还能把所有满足同一规则的序列组织成一个空间。本篇应用阅读依据教材§4.8，用一个二阶自编例贯穿初值、基、非齐次解集和状态矩阵。

递推是序列之间的线性规则 A Recurrence Is a Linear Rule on Sequences

沿用全体双向实序列空间 𝒮\mathcal S，k∈ℤk\in\mathbb Z。nn 阶常系数线性差分方程（linear difference equation，也称 linear recurrence relation）从 a0yk+n+a1yk+n−1+⋯+anyk=zka_0y_{k+n}+a_1y_{k+n-1}+\cdots+a_ny_k=z_k 出发，首末系数 a0,ana_0,a_n 均非零。除以首系数并重新记系数，可写成规范形式 yk+n+a1yk+n−1+⋯+anyk=zk,an≠0.y_{k+n}+a_1y_{k+n-1}+\cdots+a_ny_k=z_k,\qquad a_n\ne0. 这里 n≥1n\ge1，各 aia_i 为实常数，𝐳=(zk)\mathbf z=(z_k) 是给定目标信号。若 𝐳=𝟎\mathbf z=\mathbf0，称齐次（homogeneous）；否则称非齐次（nonhomogeneous）。

定义差分算子 L:𝒮→𝒮L:\mathcal S\to\mathcal S，使 (L𝐲)k(L\mathbf y)_k 等于方程左边。它保持逐项加法和数乘，故线性；齐次解集为 ker⁡L\ker L，是子空间。用前篇的右移算子还可写为 L=S−n+a1S−(n−1)+⋯+anIL=S^{-n}+a_1S^{-(n-1)}+\cdots+a_nI，负指数是因为本式读取后面的项。

本篇例子为 yk+2−3yk+1+2yk=0.y_{k+2}-3y_{k+1}+2y_k=0. 给定 y0=3,y1=5y_0=3,y_1=5，向前得到 y2=9,y3=17y_2=9,y_3=17；向后由 y1−3y0+2y−1=0y_1-3y_0+2y_{-1}=0 得 y−1=2y_{-1}=2。一整条解序列是一个向量，单个值不是这个向量。

初值为什么确定唯一的双向解？ Why Do Initial Values Determine a Unique Two-Sided Solution?

教材§4.8，定理19 / Textbook §4.8, Theorem 19

设 n≥1n\ge1，a1,…,an∈ℝa_1,\ldots,a_n\in\mathbb R 且 an≠0a_n\ne0，给定双向实信号 (zk)k∈ℤ(z_k)_{k\in\mathbb Z}。方程

yk+n+a1yk+n−1+⋯+anyk=zk(k∈ℤ)y_{k+n}+a_1y_{k+n-1}+\cdots+a_ny_k=z_k\qquad(k\in\mathbb Z)

在任意指定实初值 y0,…,yn−1y_0,\ldots,y_{n-1} 后，都有唯一的双向信号解。

完整理由。 从 y0,…,yn−1y_0,\ldots,y_{n-1} 出发，依次对 k=0,1,…k=0,1,\ldots 使用 yk+n=zk−a1yk+n−1−⋯−anyky_{k+n}=z_k-a_1y_{k+n-1}-\cdots-a_ny_k 求得所有后项。再对 k=−1,−2,…k=-1,-2,\ldots 使用 yk=zk−yk+n−a1yk+n−1−⋯−an−1yk+1any_k=\frac{z_k-y_{k+n}-a_1y_{k+n-1}-\cdots-a_{n-1}y_{k+1}}{a_n} 求得所有前项。这样构造的序列在每个整数 kk 满足方程，故存在；任何解都必须按相同公式逐项取值，故唯一。定理汇编 / Reference。

末系数非零保证能向后恢复，不能省略。例如 yk+1=0y_{k+1}=0 若对所有整数 kk 成立，则整条序列只能为零，无法任意指定 y0=1y_0=1。若只讨论 k≥0k\ge0 的单向递推，只需向前计算，条件可以不同；它不是此处双向定理的同一问题。

初值映射给出解空间的维数 Initial Values Determine the Dimension of the Solution Space

教材§4.8，定理20 / Textbook §4.8, Theorem 20

设 n≥1n\ge1，a1,…,an∈ℝa_1,\ldots,a_n\in\mathbb R 且 an≠0a_n\ne0。齐次差分方程

yk+n+a1yk+n−1+⋯+anyk=0(k∈ℤ)y_{k+n}+a_1y_{k+n-1}+\cdots+a_ny_k=0\qquad(k\in\mathbb Z)

的全部双向实信号解组成一个 nn 维向量空间 HH。

完整理由。 齐次解空间 H=ker⁡LH=\ker L 是子空间。初值映射 F:H→ℝn,F(𝐲)=(y0,…,yn−1)𝖳F:H\to\mathbb R^n,\qquad F(\mathbf y)=(y_0,\ldots,y_{n-1})^{\mathsf T} 保持加法和数乘。定理19的唯一性说明它单射，任意初值的存在性说明它满射，故是线性同构。更具体地，取 ℝn\mathbb R^n 的各标准单位列对应的解；这些解的初值列无关，因而它们无关；任意初值列可由单位列组合，唯一性保证同样的组合生成对应整条解。所以这些解组成 HH 的一组含 nn 个向量的基，dim⁡H=n\dim H=n。定理汇编 / Reference。

无穷长序列不意味着解空间无限维：有限个初值已决定所有其余项。如果找到 nn 个线性无关解，由基定理它们便构成整个齐次解空间的基，不必再猜测是否遗漏另一类解。

试探指数序列，找到一组完整解 Trying Exponential Sequences to Find a Full Basis

对齐次方程试探 yk=rky_k=r^k，要求 r≠0r\ne0 才能在所有整数处定义。代入并除以非零 rkr^k，得到辅助多项式（auxiliary polynomial）方程 rn+a1rn−1+⋯+an=0.r^n+a_1r^{n-1}+\cdots+a_n=0. 其非零实根给出实指数解；这一步找候选解，完整性还要依靠无关性和维数。这里不发展重复根或复根的一整套求解法。

二阶例的辅助多项式为 r2−3r+2=(r−1)(r−2).r^2-3r+2=(r-1)(r-2). 因此 𝐮=(1)k∈ℤ\mathbf u=(1)_{k\in\mathbb Z}、𝐯=(2k)k∈ℤ\mathbf v=(2^k)_{k\in\mathbb Z} 都是解。若 c𝐮+d𝐯=𝟎c\mathbf u+d\mathbf v=\mathbf0，查看 k=0,1k=0,1，得到 {c+d=0,c+2d=0.\left\{\begin{aligned}c+d&=0,\\c+2d&=0.\end{aligned}\right. 故 c=d=0c=d=0。它们是二维解空间中的两个无关解，因而构成完整基，所有解为 yk=c+d2k.y_k=c+d2^k. 对初值 y0=α,y1=βy_0=\alpha,y_1=\beta，系数为 d=β−αd=\beta-\alpha、c=2α−βc=2\alpha-\beta。前例 (α,β)=(3,5)(\alpha,\beta)=(3,5) 得 yk=1+2⋅2ky_k=1+2\cdot2^k，与前后递推值一致。初值列 (α,β)𝖳(\alpha,\beta)^{\mathsf T} 与此解基下的坐标 (c,d)𝖳(c,d)^{\mathsf T} 也不是同一列数字。

非齐次：一个特解加齐次解 Nonhomogeneous Equations: A Particular Plus a Homogeneous Solution

对同一个 LL，若 L𝐲p=𝐳L\mathbf y_p=\mathbf z，则全部解是 𝐲p+ker⁡L\mathbf y_p+\ker L：加核向量不改输出，任意两解之差又在核中。这个双向理由已见一般映射的解集，也是第一部分非齐次方程的推广。

在自编例中取 zk=−1z_k=-1，试 yp,k=ky_{p,k}=k： (k+2)−3(k+1)+2k=−1.(k+2)-3(k+1)+2k=-1. 所以 yk+2−3yk+1+2yk=−1y_{k+2}-3y_{k+1}+2y_k=-1 的全部双向解为 yk=k+c+d2ky_k=k+c+d2^k。这不是子空间，零序列不满足目标。指定初值后，由定理19从这个平移解集中选出唯一一条序列。给定初值唯一与未给初值时存在一族解，并不矛盾。

改写为一阶状态方程 Rewriting as a First-Order State Equation

把相邻两项作为状态向量（state vector） 𝐱k=[ykyk+1].\mathbf x_k=\begin{bmatrix}y_k\\y_{k+1}\end{bmatrix}. 由二阶齐次例得到 𝐱k+1=A𝐱k,A=[01−23].\mathbf x_{k+1}=A\mathbf x_k,\qquad A=\begin{bmatrix}0&1\\-2&3\end{bmatrix}. 第一行把旧第二项变成新第一项；第二行按递推产生 yk+2y_{k+2}。例如 A(3,5)𝖳=(5,9)𝖳A(3,5)^{\mathsf T}=(5,9)^{\mathsf T}。det⁡A=2≠0\det A=2\ne0，所以状态也能向后恢复。对非齐次目标 zkz_k，则为 𝐱k+1=A𝐱k+[0zk].\mathbf x_{k+1}=A\mathbf x_k+\begin{bmatrix}0\\z_k\end{bmatrix}. 注意 AA 已在此处重新定义为二阶状态矩阵，与第二部分的 3×43\times4 贯穿矩阵无关。

一般 nn 阶齐次方程取 𝐱k=(yk,…,yk+n−1)𝖳\mathbf x_k=(y_k,\ldots,y_{k+n-1})^{\mathsf T}。对应 n×nn\times n 状态矩阵的前 n−1n-1 行在紧邻对角线右侧为1、其余为0，最后一行为 (−an,−an−1,…,−a1)(-a_n,-a_{n-1},\ldots,-a_1)；n=1n=1 时就是 [−a1][-a_1]。这把高阶标量递推改成一阶向量递推，是教材§4.8的基本方法。第五部分的离散动力系统将进一步研究反复作用 AA，本篇不提前展开特征值算法。

进一步阅读：Casorati判别的条件 Further Reading: Conditions for the Casorati Test

对 pp 条一般信号 𝐲(1),…,𝐲(p)\mathbf y^{(1)},\ldots,\mathbf y^{(p)}，把连续 pp 个位置的值按列排成 Casorati矩阵（Casorati matrix） C(k)=[yk(1)⋯yk(p)yk+1(1)⋯yk+1(p)⋮⋮yk+p−1(1)⋯yk+p−1(p)].C(k)=\begin{bmatrix} y^{(1)}_k&\cdots&y^{(p)}_k\\ y^{(1)}_{k+1}&\cdots&y^{(p)}_{k+1}\\ \vdots&&\vdots\\ y^{(1)}_{k+p-1}&\cdots&y^{(p)}_{k+p-1} \end{bmatrix}. 如果某个 kk 满足 det⁡C(k)≠0\det C(k)\ne0，任意整条信号的零组合在这些位置也必须为零；矩阵可逆便强制所有系数为零，所以信号无关。这连接第三部分的行列式判据。

一般信号的一次零行列式不能反推相关。 例如 𝛅\boldsymbol\delta 与 S2𝛅S^2\boldsymbol\delta 无关，但在位置0、1组成的矩阵为 [1000]\begin{bmatrix}1&0\\0&0\end{bmatrix}，行列式为0；窗口漏掉了第二个脉冲。

若恰是同一个满足首末系数非零条件的 nn 阶齐次递推的 nn 条解，则连续 nn 个值就是任意平移起点的初值。若某次 C(k)C(k) 奇异，存在不全为零的组合在这 nn 个位置为零；该组合仍是同一齐次方程的解，由初值唯一性，它在所有位置都为零，故相关。此时无关等价于每次 C(k)C(k) 可逆。不能把这个加强结论套到任意信号上。

对本篇两条基解 1,2k1,2^k，C(k)=[12k12k+1]C(k)=\begin{bmatrix}1&2^k\\1&2^{k+1}\end{bmatrix}，行列式为 2k≠02^k\ne0，与直接检查两初值相符。

小结与返回主线 Summary and Return to the Core

线性规则给出核，初值给出坐标，维数保证一组无关解已经完整；非齐次解集又是熟悉的平移结构。应用的作用，是让同一条主线在无限长序列上仍清楚可见。
