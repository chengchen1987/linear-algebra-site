特征值的数值估计

Numerical Estimation of Eigenvalues

第五部分导读 / Part 5 Overview · 知识与术语速查 / Concepts and Terminology

应用阅读 / Application Reading · 教材§5.8。 特征多项式适合说明概念和计算小例；大型矩阵通常用数值迭代估计特征值，不以展开高次多项式为默认算法。这里学习幂法与带位移反幂法，连接矩阵幂和第二部分的LU求解。

幂法为什么会找到一个方向？ Why Can the Power Method Find a Direction?

给出一组足够条件：实矩阵 AA 可在实数域对角化，有唯一严格主导模的特征值 |λ1|>|λ2|≥⋯≥|λn|,|\lambda_1|>|\lambda_2|\ge\cdots\ge|\lambda_n|, 并且初始向量的展开 𝐱0=∑ici𝐯i\mathbf x_0=\sum_i c_i\mathbf v_i 中 c1≠0c_1\ne0。于是 λ1−kAk𝐱0=c1𝐯1+∑i≥2ci(λi/λ1)k𝐯i→c1𝐯1.\lambda_1^{-k}A^k\mathbf x_0=c_1\mathbf v_1+ \sum_{i\ge2}c_i(\lambda_i/\lambda_1)^k\mathbf v_i \longrightarrow c_1\mathbf v_1. 这证明反复乘法趋向主导特征方向。若 λ1<0\lambda_1<0，未归一化向量可能正负交替；方向所张成的直线仍趋近。若 c1=0c_1=0，该模式根本不出现；若最大模并列，例如90度旋转，则不能套用此论证。一般复数域也有对应论证，但实矩阵的非实根成共轭对，不可能由其中单个非实根独占最大模。

误差模式中的比值 |λ2/λ1||\lambda_2/\lambda_1| 越接近1，方向通常收敛越慢。归一化（normalization）控制数值幅度，防止反复乘法的增长导致溢出，或衰减导致下溢；它不补足缺失的收敛条件。

算法与残差 Algorithm and Residual

每步先计算新的 𝐰=A𝐱\mathbf w=A\mathbf x，取绝对值最大的分量 s=wjs=w_j，保留它的符号，令 𝐱←𝐰/s\mathbf x\leftarrow\mathbf w/s。这样该分量变成1。若 𝐰=0\mathbf w=0，当前非零 𝐱\mathbf x 已是零特征值向量，应停止，不能除以零。最大分量并列时固定选最先出现者。

对近似向量 𝐯\mathbf v，选 |vj||v_j| 最大的分量，估计 λ̂=(A𝐯)j/vj\widehat\lambda=(A\mathbf v)_j/v_j，然后计算残差（residual） 𝐫=A𝐯−λ̂𝐯,∥𝐫∥∞=maxi|ri|.\mathbf r=A\mathbf v-\widehat\lambda\mathbf v,\qquad \|\mathbf r\|_\infty=\max_i|r_i|. 最后的符号只是最大分量绝对值的简记。残差小表示特征方程近似成立；只看打印数字不再改变不够。对一般矩阵，小残差也不能无条件替代严格的特征值误差界。

输入 A，非零 x，容差 tol，最大步数 N
将 x 除以自身绝对值最大的带符号分量
重复至多 N 次：
    w = A x
    若 w = 0：报告零特征值与当前向量，停止
    s = w 中绝对值最大的带符号分量
    x = w / s
    z = A x；j = |x_j| 最大的位置
    lambda_hat = z_j / x_j
    residual = max_i |z_i - lambda_hat x_i|
    若 residual <= tol：报告近似结果与残差，停止
达到 N 时报告尚未达到容差

带位移反幂法 Shifted Inverse Iteration

若希望找到靠近标量 μ\mu 的特征值，假定 A−μIA-\mu I 可逆。对特征向量， (A−μI)−1𝐯i=1λi−μ𝐯i.(A-\mu I)^{-1}\mathbf v_i=\frac1{\lambda_i-\mu}\mathbf v_i. 因此离 μ\mu 最近的根在这个变换下具有最大的模。若最近根唯一、初始对应分量非零且 AA 可对角化，就满足前述充分条件。μ\mu 不能恰等于一个特征值；距离相同也可能失去严格主导性。

实际实现每步求解 (A−μI)𝐲=𝐱,(A-\mu I)\mathbf y=\mathbf x, 再用 𝐲\mathbf y 的最大带符号分量 ss 归一化为 𝐱new=𝐲/s\mathbf x_{\mathrm{new}}=\mathbf y/s，不显式形成逆矩阵。当归一化分量稳定时，ss 近似 1/(λ−μ)1/(\lambda-\mu)，可用 μ+1/s\mu+1/s 估计原特征值；也可对新向量用上一节的分量比值估计并检查原方程残差。

固定 mu，使 A - mu I 可逆
对 A - mu I 作一次带必要换行的 LU 分解
循环：
    利用该分解求解 (A - mu I) y = x
    s = y 中绝对值最大的带符号分量
    x = y / s
    用 A x 估计 lambda_hat 并检查原方程残差

固定 μ\mu 时，只有右端向量变化，因此可分解一次、多次三角求解。选得很近可加快模式分离，但也会使方程接近奇异，有限精度下需要注意求解误差；这里不展开误差分析课程。

进一步查阅与练习 Further Reading and Practice

教材§5.8练习还介绍实向量的Rayleigh商（Rayleigh quotient） R(𝐱)=𝐱𝖳A𝐱𝐱𝖳𝐱(𝐱≠0).R(\mathbf x)=\frac{\mathbf x^{\mathsf T}A\mathbf x}{\mathbf x^{\mathsf T}\mathbf x}\quad(\mathbf x\ne0). 若 𝐱\mathbf x 恰为实特征向量，代入等式便得 R(𝐱)=λR(\mathbf x)=\lambda，所以也可作近似估计。这里仅使用已有矩阵乘法；对称情形的误差性质需要后续理论。QR特征值迭代、Krylov方法与大规模误差分析留待后续数值线性代数；它们与下一部分的QR分解不能混为一个算法。

练习。 对 H=diag⁡(−3,1)H=\operatorname{diag}(-3,1)、𝐱0=(1,1)𝖳\mathbf x_0=(1,1)^{\mathsf T}，完成两步带符号归一化；估计特征值并计算残差。若初值改为 (0,1)𝖳(0,1)^{\mathsf T} 呢？

提示 / Hint

第一步新向量为 (−3,1)𝖳(-3,1)^{\mathsf T}，缩放因子是 −3-3。

完整解答 / Full Solution

𝐱1=(1,−1/3)𝖳\mathbf x_1=(1,-1/3)^{\mathsf T}，再乘得 (−3,−1/3)𝖳(-3,-1/3)^{\mathsf T}，𝐱2=(1,1/9)𝖳\mathbf x_2=(1,1/9)^{\mathsf T}。以最大分量位置取比值得 λ̂=−3\widehat\lambda=-3；在第二步向量上的残差为 (0,4/9)𝖳(0,4/9)^{\mathsf T}，尚未为零，不能因估计特征值已准确就宣称向量也准确。初值 (0,1)𝖳(0,1)^{\mathsf T} 的主导分量为零，始终停留在特征值1方向，不能得到 −3-3 的方向。
