主成分分析与数据降维

Principal Component Analysis and Dimensionality Reduction

前一页近似的是一整个矩阵。现在把列解释为观测数据，问题变为：数据相对均值主要沿哪些方向变化？投影到较低维空间后丢失多少变化？本页落实教材§7.5“图像处理与统计中的应用（Applications to Image Processing and Statistics）”，连接第六部分的中心化与投影，以及本部分的约束极值。

先约定数据怎样排列 Fix the Data Arrangement First

设有 N≥2N\ge2 个观测，每个含 pp 个实数特征，将观测放在列中： X=[𝐱1⋯𝐱N]∈ℝp×N,𝛍=1N∑j=1N𝐱j.X=[\mathbf x_1\ \cdots\ \mathbf x_N]\in\mathbb R^{p\times N},\qquad \boldsymbol\mu=\frac1N\sum_{j=1}^N\mathbf x_j. 这里 𝛍\boldsymbol\mu 是样本均值向量。将每个观测减去它，得到中心化（centering）矩阵 B=[𝐱1−𝛍⋯𝐱N−𝛍],B𝟏N=0.B=[\mathbf x_1-\boldsymbol\mu\ \cdots\ \mathbf x_N-\boldsymbol\mu],\qquad B\mathbf1_N=0. 定义样本协方差矩阵（sample covariance matrix） S⏟p×p=1N−1BBT.\underbrace{S}_{p\times p}=\frac1{N-1}BB^T. 分母 N−1N-1 是这里使用的样本协方差约定。第 (a,b)(a,b) 元为 sab=1N−1∑j=1N(xaj−μa)(xbj−μb).s_{ab}=\frac1{N-1}\sum_{j=1}^N(x_{aj}-\mu_a)(x_{bj}-\mu_b). 对角元 saas_{aa} 是第 aa 个特征的样本方差，非对角元是两个特征的样本协方差；正协方差表示它们相对各自均值通常同向变化，负协方差表示通常反向变化。tr⁡(S)=∑asaa\operatorname{tr}(S)=\sum_a s_{aa} 是总方差。

ST=SS^T=S，且对任意 𝐮∈ℝp\mathbf u\in\mathbb R^p， 𝐮TS𝐮=1N−1∥BT𝐮∥2≥0.\mathbf u^TS\mathbf u=\frac1{N-1}\|B^T\mathbf u\|^2\ge0. 所以 SS 对称半正定，可以正交对角化。中心化不等于将各特征除以各自标准差；不同单位或缩放会改变协方差矩阵和PCA方向。

最大方差方向就是一个约束极值 Maximum Variance Is a Constrained Extremum

对单位方向 𝐮\mathbf u，第 jj 个中心化观测在该方向的投影分数（projection score）是 zj=𝐮T(𝐱j−𝛍)z_j=\mathbf u^T(\mathbf x_j-\boldsymbol\mu)。这些分数的均值为零，其样本方差为 1N−1∑jzj2=𝐮TS𝐮.\frac1{N-1}\sum_j z_j^2=\mathbf u^TS\mathbf u. 因此定理6给出：最大方差等于 SS 的最大特征值，在相应单位特征方向取得。若要求下一方向与前一方向正交，定理7给出次大特征值；继续使用定理8，便得到按方差排序的正交方向。这就是主成分分析（principal component analysis, PCA）的核心选择过程。

令 SS 的特征值按重数排列为 λ1≥⋯≥λp≥0\lambda_1\ge\cdots\ge\lambda_p\ge0，选相应标准正交特征基 𝐩1,…,𝐩p\mathbf p_1,\ldots,\mathbf p_p，组成 PP。教材把这些主方向称为 主成分（principal components）；另一些语境也把投影分数称作主成分。因此使用该词时要说明指方向还是坐标数值。重复特征值允许在对应特征空间中另选正交方向，并不产生唯一的每根轴。

新坐标与不相关 New Coordinates and Uncorrelated Scores

令 Y=PTBY=P^TB，则 YY 的每一列是一个中心化观测在主方向基下的新坐标，每一行是一组方向上的分数。其均值仍为零，协方差为 1N−1YYT=PTSP=diag⁡(λ1,…,λp).\frac1{N-1}YY^T=P^TSP=\operatorname{diag}(\lambda_1,\ldots,\lambda_p). 非对角元为零，意味着不同方向分数不相关。不相关不等于独立：协方差只检验一种线性共同变化，不能排除非线性依赖。例如等概率取 T=−1,0,1T=-1,0,1，TT 与 T2T^2 的协方差为零，但后者完全由前者决定。PCA本身没有证明数据的统计独立性。

方向 𝐩i\mathbf p_i 是数据所在的 ℝp\mathbb R^p 中的单位向量，分数 𝐩iT(𝐱−𝛍)\mathbf p_i^T(\mathbf x-\boldsymbol\mu) 是标量，投影重建则又是数据所在的 ℝp\mathbb R^p 中的向量，三者不是同一种对象。

手算二维数据 Worked Two-Dimensional Data

取四个观测 𝐱1=(3,2)T\mathbf x_1=(3,2)^T、𝐱2=(1,0)T\mathbf x_2=(1,0)^T、𝐱3=(2,3)T\mathbf x_3=(2,3)^T、𝐱4=(0,1)T\mathbf x_4=(0,1)^T。均值和中心化矩阵为 𝛍=[3/23/2],B=12[3−11−31−33−1].\boldsymbol\mu=\begin{bmatrix}3/2\\3/2\end{bmatrix},\qquad B=\frac12\begin{bmatrix}3&-1&1&-3\\1&-3&3&-1\end{bmatrix}. 逐项相乘得到 BBT=[5335],S=13[5335].BB^T=\begin{bmatrix}5&3\\3&5\end{bmatrix},\qquad S=\frac13\begin{bmatrix}5&3\\3&5\end{bmatrix}. 特征值为 8/3,2/38/3,2/3，相应主方向可取 𝐩1=12[11],𝐩2=12[−11].\mathbf p_1=\frac1{\sqrt2}\begin{bmatrix}1\\1\end{bmatrix},\qquad \mathbf p_2=\frac1{\sqrt2}\begin{bmatrix}-1\\1\end{bmatrix}. 新坐标矩阵为 Y=[2−22−2−1/2−1/21/21/2].Y=\begin{bmatrix}\sqrt2&-\sqrt2&\sqrt2&-\sqrt2\\-1/\sqrt2&-1/\sqrt2&1/\sqrt2&1/\sqrt2\end{bmatrix}. 两行内积为零，平方和分别为8和2；除以 N−1=3N-1=3 正好得到各自方差。原坐标特征有正协方差1，沿 (1,1)T(1,1)^T 的共同变化较强。

降维与重建误差 Dimension Reduction and Reconstruction Error

保留前 kk 个方向，记 Pk=[𝐩1⋯𝐩k]P_k=[\mathbf p_1\ \cdots\ \mathbf p_k]。一个观测只需保留 kk 个分数，重建为 𝐱̂=𝛍+PkPkT(𝐱−𝛍).\widehat{\mathbf x}=\boldsymbol\mu+P_kP_k^T(\mathbf x-\boldsymbol\mu). 均值必须加回。残差与保留的方向空间正交，因此这是在经过均值、方向空间为 Col⁡Pk\operatorname{Col}P_k 的仿射平面内离原观测最近的点。对整组中心化数据， ∥B−PkPkTB∥F2=(N−1)∑j>kλj.\|B-P_kP_k^TB\|_F^2=(N-1)\sum_{j>k}\lambda_j. 理由是丢弃方向上的分数平方和分别为 (N−1)λj(N-1)\lambda_j，而正交方向的误差平方相加。这也与上一页的截断SVD误差一致；最佳低秩近似结论说明该选择在同维数的正交投影子空间中最小化总平方重建误差。

当 tr⁡(S)>0\operatorname{tr}(S)>0 时，保留方差比例（explained variance ratio）为 λ1+⋯+λktr⁡(S).\frac{\lambda_1+\cdots+\lambda_k}{\operatorname{tr}(S)}. 例中只保留第一主方向，比例为 (8/3)/(10/3)=4/5(8/3)/(10/3)=4/5；重建点依次为 (5/2,5/2)T(5/2,5/2)^T、(1/2,1/2)T(1/2,1/2)^T、(5/2,5/2)T(5/2,5/2)^T、(1/2,1/2)T(1/2,1/2)^T。每点误差平方为 1/21/2，总和2，也等于 3(2/3)3(2/3)。

若全部观测相同，则 B=0B=0、S=0S=0、总方差为零，任意方向都没有变化；不能计算 0/00/0 的方差比例。此时只存均值即可精确重建所有观测。

与SVD的两种排列约定 Two SVD Conventions for the Same Data

若 B=UΣVTB=U\Sigma V^T，则 S=1N−1UΣΣTUT.S=\frac1{N-1}U\Sigma\Sigma^TU^T. 所以主方向是 BB 的左奇异向量，且非零值满足 λi(S)=σi(B)2/(N−1)\lambda_i(S)=\sigma_i(B)^2/(N-1)；补全方向对应零特征值。例中 BB 的非零奇异值是 8,2\sqrt8,\sqrt2。

教材另令 A=BT/N−1∈ℝN×pA=B^T/\sqrt{N-1}\in\mathbb R^{N\times p}，于是 S=ATAS=A^TA，主方向是这个 AA 的右奇异向量。这不是不同的PCA理论，而是转置和缩放后的数据排列不同。用软件时先核对观测是行还是列，再判断需要哪一端的奇异向量。不能脱离矩阵尺寸记忆“PCA总取左边”或“总取右边”。

多通道图像：一个像素是一列观测 Multichannel Images: One Pixel Is One Observation

在多通道图像中，同一像素位置可能有红、绿、蓝或更多波段的测量值。若有 pp 个通道、NN 个像素，把每个像素的 pp 个通道值叠成 𝐱j∈ℝp\mathbf x_j\in\mathbb R^p，得到 p×Np\times N 数据矩阵。数据特征空间（feature space）的维数是通道数，不是像素的二维位置坐标。

若两个通道常随像素共同变亮，它们会有较大的正协方差。PCA用各通道中心化值的加权和产生分数，例如 zij=𝐩iT(𝐱j−𝛍)z_{ij}=\mathbf p_i^T(\mathbf x_j-\boldsymbol\mu)；把固定 ii 的所有像素分数放回原位置，就得到一个分数图像。保留若干方向后，每个像素由较少的数近似描述，并可用均值和主方向重建各通道值。

与上一页对比：单幅灰度图的矩阵行列是两种空间位置索引；这里矩阵的行是通道特征、列是像素观测。前者直接近似像素矩阵，后者分析通道之间的协方差。两者都使用SVD，但不是同一个图像处理问题，也不保证总比其他算法快。

动笔：缩放与零方差 Practice: Scaling and Zero Variance

沿手算例，把所有中心化观测整体乘以2：协方差、主方向、奇异值、保留方差比例和秩一重建总平方误差如何变化？若只将第一个特征乘以2，方向一定不变吗？另说明四个完全相同观测的情况。

提示 / Hint

整体缩放给 B′=2BB'=2B。单个特征缩放则是左乘一个对角矩阵，通常不是标量倍数。

完整解答 / Full Solution

整体缩放后 S′=4SS'=4S，特征值为 32/3,8/332/3,8/3，可选同样的主方向；奇异值加倍为 28,222\sqrt8,2\sqrt2，比例仍为 4/54/5，误差平方变为8。只放大第一个特征时，协方差变成 13[20665]\frac13\begin{bmatrix}20&6\\6&5\end{bmatrix}，(1,1)T(1,1)^T 不再是特征向量，方向一般改变。全部相同的观测中心化后为零，方差比例不定义；重建使用均值，误差为零。
