初等矩阵与矩阵求逆

Elementary Matrices and Computing Inverses

本部分导读 / Part Overview · 逆矩阵与逆变换 / Inverses and Inverse Transformations

用矩阵乘法表示初等行变换 Representing Elementary Row Operations by Matrix Multiplication

第一部分把行操作理解为对每个列向量施加同一个规则，并把各列的结果并排记作 EAEA。现在矩阵乘法已经定义，这正是通常的乘积：若 A=[𝐚1⋯𝐚n]∈ℝm×nA=[\mathbf a_1\ \cdots\ \mathbf a_n]\in\mathbb R^{m\times n}，则 EA=[E𝐚1⋯E𝐚n].EA=[E\mathbf a_1\ \cdots\ E\mathbf a_n]. 第一部分的逐列解释说明操作为何保持方程组全部解；这里用初等矩阵表示这些行操作，进而解释矩阵求逆的方法。

初等矩阵 / Elementary Matrix 是对 ImI_m 做一次初等行操作所得的 m×mm\times m 矩阵。相同的行操作施加于 AA，结果为 EAEA。以下给二维例子；高维时在涉及的行上改变 ImI_m，其他行保持。

行操作 / Row Operation 规则与矩阵 / Rule and Matrix 逆操作 / Inverse Operation
交换两行 / Interchange (u,v)↦(v,u)(u,v)\mapsto(v,u)；P=[0110]P=\begin{bmatrix}0&1\\1&0\end{bmatrix} 再交换；P−1=PP^{-1}=P
一行乘c≠0c\ne0 / Scale (u,v)↦(cu,v)(u,v)\mapsto(cu,v)；D=[c001]D=\begin{bmatrix}c&0\\0&1\end{bmatrix} 乘1/c1/c；D−1=[1/c001]D^{-1}=\begin{bmatrix}1/c&0\\0&1\end{bmatrix}

行替换保留提供倍数的另一行。每条逆操作规则在两个顺序下都还原任意列向量，因此对应矩阵 FF 满足 FE=EF=ImFE=EF=I_m。每个初等矩阵可逆，它的逆仍是初等矩阵。 后面将用这一事实证明求逆算法。只有保留另一行的行替换才是初等行操作；只留下两式之和会丢失信息。

把求逆转化为方程组求解 Turning Inverse Computation into Linear Systems

求 n×nn\times n 方阵 AA 的逆，需要找到同阶矩阵 BB，使 AB=BA=InAB=BA=I_n。我们先研究其中的条件 AB=InAB=I_n；此时还没有把它当作完整的逆矩阵条件。

把未知矩阵与单位矩阵分别按列写成 B=[𝐛1⋯𝐛n],In=[𝐞1⋯𝐞n].B=[\mathbf b_1\ \cdots\ \mathbf b_n],\qquad I_n=[\mathbf e_1\ \cdots\ \mathbf e_n]. 其中每个 𝐛j∈ℝn\mathbf b_j\in\mathbb R^n 都是待求的列向量，𝐞j∈ℝn\mathbf e_j\in\mathbb R^n 是已知的标准单位向量。由矩阵乘法的逐列定义， AB=In⇔A𝐛j=𝐞j(j=1,…,n).AB=I_n\quad\Longleftrightarrow\quad A\mathbf b_j=\mathbf e_j\quad(j=1,\ldots,n). 这样，求一个未知矩阵变成了求解 nn 个线性方程组。它们的系数矩阵都是 AA，只有右边的向量不同；第 jj 个方程组的解就是 BB 的第 jj 列。

用同一组行变换求解各列方程 Solving the Column Systems with the Same Row Operations

既然系数矩阵相同，对系数部分所做的消元就无需重复 nn 次。把这些方程组的常数列并排放在右侧，得到 [A∣𝐞1⋯𝐞n]=[A∣In].[A\mid\mathbf e_1\ \cdots\ \mathbf e_n]=[A\mid I_n]. 第一部分已经说明：初等行变换对增广矩阵的每一列施行相同操作，并保持方程组的全部解。以前右侧只有一个常数向量，现在有 nn 个；对所有常数列同步操作，每个方程组保持等价的理由不变。

如果系数部分化为 InI_n，每个方程组的解便直接出现在对应的右端列中。先用一个完整算例观察这一过程，再证明所得矩阵为什么同时满足另一个条件 BA=InBA=I_n。

完整例题：用同一组行变换求解两列方程 Worked Example: Solving Two Column Systems Together

取 H=[1123]H=\begin{bmatrix}1&1\\2&3\end{bmatrix}，要求 H𝐛1=𝐞1H\mathbf b_1=\mathbf e_1 和 H𝐛2=𝐞2H\mathbf b_2=\mathbf e_2。先写出 [H∣I2][H\mid I_2]；向前消元消去第一列下方的元素，再向后化简，消去第二个主元上方的元素：

[11102301]→R2←R2−2R1[111001−21]\left[\begin{array}{rr|rr}1&1&1&0\\2&3&0&1\end{array}\right] \xrightarrow{R_2\leftarrow R_2-2R_1} \left[\begin{array}{rr|rr}1&1&1&0\\0&1&-2&1\end{array}\right] →R1←R1−R2[103−101−21].\xrightarrow{R_1\leftarrow R_1-R_2} \left[\begin{array}{rr|rr}1&0&3&-1\\0&1&-2&1\end{array}\right].

左边成为 I2I_2，右边得到 B=[3−1−21].B=\begin{bmatrix}3&-1\\-2&1\end{bmatrix}. 按方程组读出两列：𝐛1=(3,−2)𝖳\mathbf b_1=(3,-2)^{\mathsf T} 解 H𝐛1=𝐞1H\mathbf b_1=\mathbf e_1，𝐛2=(−1,1)𝖳\mathbf b_2=(-1,1)^{\mathsf T} 解 H𝐛2=𝐞2H\mathbf b_2=\mathbf e_2。所以 HB=I2HB=I_2。直接计算也能核对这一点： HB=[3−2−1+16−6−2+3]=I2.HB=\begin{bmatrix}3-2&-1+1\\6-6&-2+3\end{bmatrix}=I_2. 再检查本例的另一个乘积： BH=[3−23−3−2+2−2+3]=I2.BH=\begin{bmatrix}3-2&3-3\\-2+2&-2+3\end{bmatrix}=I_2. 两个次序均得到单位矩阵，故 B=H−1B=H^{-1}。例如 H−1(2,5)𝖳=(1,1)𝖳H^{-1}(2,5)^{\mathsf T}=(1,1)^{\mathsf T}，恢复了对应的输入。下面解释为什么一般的同步消元也会得到双侧逆，而不只是满足 AB=InAB=I_n 的候选矩阵。

为什么同步消元得到双侧逆？ Why Does Simultaneous Row Reduction Give a Two-Sided Inverse?

设依次施行的初等行变换对应 E1,…,EkE_1,\ldots,E_k。先做 E1E_1 再做 E2E_2，结果为 E2(E1A)E_2(E_1A)；由结合律，后做的矩阵写在左边。因此，记 G=Ek⋯E2E1,G=E_k\cdots E_2E_1, 同一组行操作在两侧产生 [A∣In]→[GA∣G].[A\mid I_n]\longrightarrow[GA\mid G]. 若左侧成为 InI_n，则 GA=InGA=I_n。各初等矩阵都可逆，由上一主题已证明的逆矩阵乘积性质，GG 也可逆。于是 G−1(GA)=G−1In⇒A=G−1.G^{-1}(GA)=G^{-1}I_n\quad\Longrightarrow\quad A=G^{-1}. 因此 AG=G−1G=InAG=G^{-1}G=I_n，与 GA=InGA=I_n 一起说明右侧的 GG 确实是 A−1A^{-1}。这里用的是初等矩阵的逆和已证明的逆运算性质，没有调用下一主题的可逆矩阵定理。

这一推导给出“能化为 InI_n 就可逆”的方向。教材定理7还包含反方向，并指出结果不依赖于选择哪一组合法行操作：

教材§2.2，定理7 / Textbook §2.2, Theorem 7

设 A∈ℝn×nA\in\mathbb R^{n\times n}。AA 可逆当且仅当 AA 行等价于 InI_n。此时，任何把 AA 化成 InI_n 的初等行操作序列，施加在 InI_n 上都会得到 A−1A^{-1}。

因此在增广矩阵 [AIn]\left[\begin{array}{c|c}A&I_n\end{array}\right] 上同步操作，若左侧能化成 InI_n，右侧即为 A−1A^{-1}；若不能，AA 不可逆。

可逆推出行等价 / Invertibility Implies Row Equivalence. 若 AA 可逆，由定理5，A𝐱=𝟎A\mathbf x=\mathbf0 只有零解。按第一部分的基本变量与自由变量判据，齐次方程没有自由变量，所以 AA 的每一列都有主元。n×nn\times n 方阵共有 nn 个主元，位于不同的行和列，其简化行阶梯形只能是 InI_n。

行等价推出可逆 / Row Equivalence Implies Invertibility. 上面的推导适用于任意一组把 AA 化为 InI_n 的初等行操作。同一组操作作用于 InI_n 所得的矩阵都是 A−1A^{-1}，这也证明了定理中“任何一组”的断言。定理汇编 / Theorem Reference。

算法小结 / Algorithm Summary. 对 [A∣In][A\mid I_n] 的所有列同步施行初等行变换，向前消元后归一化主元、清除主元上方的元素。若左侧成为 InI_n，右侧就是 A−1A^{-1}；若完成必要的行化简后确认左侧不能成为 InI_n，则 AA 不可逆。

判断的对象是左侧系数矩阵。右侧的非零元素或主元不能补齐左侧缺失的主元。如果当前准备选取主元的位置为零，应检查下方是否有非零元素可通过换行移到该位置；不能把暂时遇到零或一次尝试失败当作不可逆的依据。主元本身必须非零。

不可逆时发生什么？ What Happens in the Singular Case?

不可逆对照 / A Singular Contrast. J=[1224]J=\begin{bmatrix}1&2\\2&4\end{bmatrix}，做 R2←R2−2R1R_2\leftarrow R_2-2R_1：

[J∣I2]→[121000−21].[J\mid I_2]\longrightarrow \left[\begin{array}{rr|rr}1&2&1&0\\0&0&-2&1\end{array}\right].

左边不能化成 I2I_2；右端第一列对应方程出现 0=−20=-2，第二列出现 0=10=1，两个方程组都无解。也可看到 J(−2,1)𝖳=0J(-2,1)^{\mathsf T}=0，输入无法唯一恢复。非零方阵未必可逆；不要把右半边的某个矩阵直接叫作逆。

推广：同一系数矩阵的多个方程组 Extension: Multiple Systems with the Same Coefficient Matrix

求逆把单位矩阵的各列作为方程组的右端。若把右端换成其他已知向量，同步消元仍然适用。设 AA 为 m×nm\times n，把 rr 个未知解向量排成 X=[𝐱1⋯𝐱r]∈ℝn×rX=[\mathbf x_1\ \cdots\ \mathbf x_r]\in\mathbb R^{n\times r}，把方程右边的已知向量排成 F=[𝐟1⋯𝐟r]∈ℝm×rF=[\mathbf f_1\ \cdots\ \mathbf f_r]\in\mathbb R^{m\times r}。由乘法的列定义， AX=F⇔A𝐱j=𝐟j(j=1,…,r).AX=F\quad\Longleftrightarrow\quad A\mathbf x_j=\mathbf f_j\quad(j=1,\ldots,r). 这是同一个系数矩阵的多个方程组；XX 的第 jj 列是第 jj 个方程组的解。对增广矩阵 [A∣F][A\mid F] 消元，所有常数列必须同步变化。

当 AA 是可逆方阵时，每个方程组都有唯一解，合起来就是 X=A−1FX=A^{-1}F。这也解释了上面的求逆过程为何选择 F=InF=I_n。实际求解 AX=FAX=F 时，可以直接化简 [A∣F][A\mid F]，不必先计算整个 A−1A^{-1}。

独立计算 / Independent Practice. 取 H=[1123],F=[2153].H=\begin{bmatrix}1&1\\2&3\end{bmatrix},\qquad F=\begin{bmatrix}2&1\\5&3\end{bmatrix}. 用同一组行变换求 HX=FHX=F，再逐列回代。

提示 / Hint

先做 R2←R2−2R1R_2\leftarrow R_2-2R_1，再清除第二个主元上方的元素；两列常数都要同步处理。

完整答案 / Complete Solution

先后顺序怎样记录？ Recording the Order of Operations

先做 E1E_1，再做 E2E_2，结果是 E2(E1A)=(E2E1)AE_2(E_1A)=(E_2E_1)A：后做的矩阵在左边。对总操作求逆时 (E2E1)−1=E1−1E2−1.(E_2E_1)^{-1}=E_1^{-1}E_2^{-1}.

例如先交换两行，再做 R2←R2−2R1R_2\leftarrow R_2-2R_1，总矩阵为 G=[10−21][0110]=[011−2].G=\begin{bmatrix}1&0\\-2&1\end{bmatrix} \begin{bmatrix}0&1\\1&0\end{bmatrix} =\begin{bmatrix}0&1\\1&-2\end{bmatrix}. GG 可逆，却不是一次操作从 I2I_2 得到的三类矩阵中任何一种。因此，多个初等矩阵的乘积未必还是单个初等矩阵。右乘的列操作也不能替代这里的同一行操作。

回到矩阵 HH 的求逆过程，两步行操作对应 E1=[10−21],E2=[1−101].E_1=\begin{bmatrix}1&0\\-2&1\end{bmatrix},\qquad E_2=\begin{bmatrix}1&-1\\0&1\end{bmatrix}. 因此 H−1=E2E1H^{-1}=E_2E_1，不是 E1E2E_1E_2。这与两步行操作的先后次序完全一致。

矩阵方程中保持顺序 Keeping the Order in a Matrix Equation

设 A,X,A−AXA,X,A-AX 均为可逆的同阶实方阵，且 (A−AX)−1=X−1B(A-AX)^{-1}=X^{-1}B。证明 BB 可逆，再用 A,BA,B 表示 XX。

提示 / Hint

先左乘 XX 得到 BB 是两个可逆矩阵的乘积；再把原等式两边求逆。不能把矩阵当分数约去。

完整推导 / Complete Derivation

B=X(A−AX)−1B=X(A-AX)^{-1}，所以可逆。原等式求逆得 A−AX=B−1XA-AX=B^{-1}X，即 A=(B−1+A)XA=(B^{-1}+A)X。 由于 B−1+A=AX−1B^{-1}+A=AX^{-1} 是可逆矩阵的乘积，所需的逆存在。因此 X=(B−1+A)−1A.X=(B^{-1}+A)^{-1}A. 不能写成 A(B−1+A)−1A(B^{-1}+A)^{-1}；未证明可逆前，也不能先对和式求逆。
