从逐列作用到正式乘积 From Column Action to a Matrix Product

第一部分把行操作理解为对每个列向量施加同一个规则，并把各列的结果并排记作 EAEA。现在矩阵乘法已经定义，这正是通常的乘积：若 A=[𝐚1⋯𝐚n]∈ℝm×nA=[\mathbf a_1\ \cdots\ \mathbf a_n]\in\mathbb R^{m\times n}，则 EA=[E𝐚1⋯E𝐚n].EA=[E\mathbf a_1\ \cdots\ E\mathbf a_n]. 第一部分的逐列解释说明操作为何保持方程组全部解；这里进一步把操作记录下来，用于求逆和复用消元。

初等矩阵 / Elementary Matrix 是对 ImI_m 做一次初等行操作所得的 m×mm\times m 矩阵。相同的行操作施加于 AA，结果为 EAEA。以下给二维例子；高维时在涉及的行上改变 ImI_m，其他行保持。

行操作 / Row Operation 规则与矩阵 / Rule and Matrix 撤销 / Undoing
交换两行 / Interchange (u,v)↦(v,u)(u,v)\mapsto(v,u)；P=[0110]P=\begin{bmatrix}0&1\\1&0\end{bmatrix} 再交换；P−1=PP^{-1}=P
一行乘c≠0c\ne0 / Scale (u,v)↦(cu,v)(u,v)\mapsto(cu,v)；D=[c001]D=\begin{bmatrix}c&0\\0&1\end{bmatrix} 乘1/c1/c；D−1=[1/c001]D^{-1}=\begin{bmatrix}1/c&0\\0&1\end{bmatrix}
不同行间替换 / Replace R2←R2+cR1R_2\leftarrow R_2+cR_1；(u,v)↦(u,v+cu)(u,v)\mapsto(u,v+cu)；E=[10c1]E=\begin{bmatrix}1&0\\c&1\end{bmatrix} R2←R2−cR1R_2\leftarrow R_2-cR_1；E−1=[10−c1]E^{-1}=\begin{bmatrix}1&0\\-c&1\end{bmatrix}

行替换保留提供倍数的另一行。每条撤销规则在两个顺序下都还原任意列向量，因此对应矩阵 FF 满足 FE=EF=ImFE=EF=I_m。每个初等矩阵可逆，它的逆仍是初等矩阵。 这是具体操作与已学矩阵乘法的联系，不是把任意两个行式合并也当成合法消元。

先后顺序怎样记录？ Recording the Order of Operations

先做 E1E_1，再做 E2E_2，结果是 E2(E1A)=(E2E1)AE_2(E_1A)=(E_2E_1)A：后做的矩阵在左边。撤销总操作时 (E2E1)−1=E1−1E2−1.(E_2E_1)^{-1}=E_1^{-1}E_2^{-1}.

例如先交换两行，再做 R2←R2−2R1R_2\leftarrow R_2-2R_1，总矩阵为 G=[10−21][0110]=[011−2].G=\begin{bmatrix}1&0\\-2&1\end{bmatrix} \begin{bmatrix}0&1\\1&0\end{bmatrix} =\begin{bmatrix}0&1\\1&-2\end{bmatrix}. GG 可逆，却不是一次操作从 I2I_2 得到的三类矩阵中任何一种。因此，多个初等矩阵的乘积未必还是单个初等矩阵。右乘的列操作也不能替代这里的同一行操作。

行化简为什么能求逆？ Why Row Reduction Computes an Inverse

教材§2.2，定理7 / Textbook §2.2, Theorem 7

设 A∈ℝn×nA\in\mathbb R^{n\times n}。AA 可逆当且仅当 AA 行等价于 InI_n。此时，任何把 AA 化成 InI_n 的初等行操作序列，施加在 InI_n 上都会得到 A−1A^{-1}。

因此在增广矩阵 [AIn]\left[\begin{array}{c|c}A&I_n\end{array}\right] 上同步操作，若左侧能化成 InI_n，右侧即为 A−1A^{-1}；若不能，AA 不可逆。

可逆推出行等价 / Invertibility Implies Row Equivalence. 若 AA 可逆，则由定理5，A𝐱=𝟎A\mathbf x=\mathbf0 只有零解。按第一部分的基本/自由变量判据，AA 的每一列都有主元。n×nn\times n 方阵共有 nn 个主元，位于不同的行和列，所以其RREF只能是 InI_n。

行等价推出可逆 / Row Equivalence Implies Invertibility. 假设任意一串初等行操作将 AA 化成 InI_n。记 G=Ek⋯E2E1,GA=In.G=E_k\cdots E_2E_1,\qquad GA=I_n. 各因子可逆，由已证的逆运算律，GG 可逆。左乘 G−1G^{-1} 得 A=G−1A=G^{-1}，故 AA 可逆且 A−1=GA^{-1}=G；特别地也有 AG=InAG=I_n。同一串操作施加在 InI_n 上，结果就是 GIn=G=A−1GI_n=G=A^{-1}。这证明了“任何一串”的断言，没有预先使用下一主题的定理8。定理汇编 / Theorem Reference。

同步消元算法 / Simultaneous Row-Reduction Algorithm.

  1. 写出 [A∣In][A\mid I_n]，右侧每一列都是一个目标。
  2. 对整个增广矩阵做相同行操作，向前消元后归一主元、清除上方元素。
  3. 若左侧成为 InI_n，右侧即为 A−1A^{-1}；若左侧最终不能成为 InI_n，则 AA 不可逆。

这里判断的是左侧系数矩阵能否化成 InI_n。右侧可能有主元或非零元素，但不能靠它们补齐左侧缺失的主元。一个暂时为零的待用主元也不直接证明不可逆，应先检查可否换行。

完整例题：同一次操作求所有单位目标 Worked Example: All Unit Targets at Once

第一部分已经说明消元为什么保解。现在取 H=[1123]H=\begin{bmatrix}1&1\\2&3\end{bmatrix}，新问题是：操作作用在两个单位目标上会得到什么？

[11102301]→R2←R2−2R1[111001−21]\left[\begin{array}{rr|rr}1&1&1&0\\2&3&0&1\end{array}\right] \xrightarrow{R_2\leftarrow R_2-2R_1} \left[\begin{array}{rr|rr}1&1&1&0\\0&1&-2&1\end{array}\right] →R1←R1−R2[103−101−21].\xrightarrow{R_1\leftarrow R_1-R_2} \left[\begin{array}{rr|rr}1&0&3&-1\\0&1&-2&1\end{array}\right].

因此 H−1=[3−1−21]H^{-1}=\begin{bmatrix}3&-1\\-2&1\end{bmatrix}。独立双侧核对：

HH−1=[3−2−1+16−6−2+3]=I2,HH^{-1}=\begin{bmatrix}3-2&-1+1\\6-6&-2+3\end{bmatrix}=I_2, H−1H=[3−23−3−2+2−2+3]=I2.H^{-1}H=\begin{bmatrix}3-2&3-3\\-2+2&-2+3\end{bmatrix}=I_2.

例如输出 (2,5)𝖳(2,5)^{\mathsf T} 恢复为 (1,1)𝖳(1,1)^{\mathsf T}。这次求逆在两个右端上保存了同一套操作，后面的分块与 LU 将继续这个思路。

不可逆时发生什么？ What Happens in the Singular Case?

不可逆对照 / A Singular Contrast. J=[1224]J=\begin{bmatrix}1&2\\2&4\end{bmatrix}，做 R2←R2−2R1R_2\leftarrow R_2-2R_1：

[J∣I2]→[121000−21].[J\mid I_2]\longrightarrow \left[\begin{array}{rr|rr}1&2&1&0\\0&0&-2&1\end{array}\right].

左边不能化成 I2I_2；右端第一列对应方程出现 0=−20=-2，第二列出现 0=10=1，均不能解。也可看到 J(−2,1)𝖳=0J(-2,1)^{\mathsf T}=0，输入无法唯一恢复。非零方阵未必可逆；不要把右半边的某个矩阵直接叫作逆。

对本例，E1=[10−21]E_1=\begin{bmatrix}1&0\\-2&1\end{bmatrix}、E2=[1−101]E_2=\begin{bmatrix}1&-1\\0&1\end{bmatrix}，因此 H−1=E2E1H^{-1}=E_2E_1，不是 E1E2E_1E_2。左侧化成单位矩阵，右侧就记录了恢复每个目标所需的输入。

矩阵方程中保持顺序 Keeping the Order in a Matrix Equation

设 A,X,A−AXA,X,A-AX 均为可逆的同阶实方阵，且 (A−AX)−1=X−1B(A-AX)^{-1}=X^{-1}B。证明 BB 可逆，再用 A,BA,B 表示 XX。

提示 / Hint

先左乘 XX 得到 BB 是两个可逆矩阵的乘积；再把原等式两边求逆。不能把矩阵当分数约去。

完整推导 / Complete Derivation

B=X(A−AX)−1B=X(A-AX)^{-1}，所以可逆。原等式求逆得 A−AX=B−1XA-AX=B^{-1}X，即 A=(B−1+A)XA=(B^{-1}+A)X。 由于 B−1+A=AX−1B^{-1}+A=AX^{-1} 是可逆矩阵的乘积，所需的逆存在。因此 X=(B−1+A)−1A.X=(B^{-1}+A)^{-1}A. 不能写成 A(B−1+A)−1A(B^{-1}+A)^{-1}；未证明可逆前，也不能先对和式求逆。

求逆把 AA 化到 InI_n；后面的LU分解只化到阶梯形 UU，便可保存消元供新目标复用。先进入可逆矩阵定理 / The Invertible Matrix Theorem，连接“给定目标”和“所有目标”。
