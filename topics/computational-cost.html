线性代数运算的计算量估算

Estimating the Computational Cost of Linear Algebra Operations

同一个结果可以怎样计算？规模变大时，哪一步最费工作？本页用两种方法估算：输出数量 × 每个输出所需工作量，以及各步骤工作量相加，再据此比较运算顺序和分解复用。

先熟悉矩阵乘法的元素公式 / Entry Formula for Matrix Products；讨论分解复用时使用LU构造与三角求解 / LU Construction and Triangular Solves。本页承接教材§2.1的运算规则与§2.5的数值注解，并补充计数推导；这些推导是课程说明，没有另设教材编号定理。学习秩与CR分解 / Rank and CR Factorization可直接接续LU的列关系，不必先学本页。

数什么：约定与规模 What to Count: Conventions and Size

对实数的一次加、减、乘、除各计一次算术运算（arithmetic operation）。以下讨论常规算法；除最后的结构辨析外，按一般稠密矩阵计数，不利用偶然出现的零或单位元素。算术次数、存储元素数和实际运行时间是不同指标。

长度为 nn 的向量有 nn 个元素；m×nm\times n 矩阵有 mnmn 个元素，尺寸均为正整数。逐元素加减或数乘，每个输出只需一次运算，所以向量各需 nn 次，矩阵各需 mnmn 次。

由这些具体计数引入大O记号（big-O notation）：nn 次是 O(n)O(n)，mnmn 次是 O(mn)O(mn)。例如 O(n2)O(n^2) 表示规模充分大时，次数可由某个与 nn 无关的常数乘 n2n^2 控制；它给出增长的上界量级。这里描述所讨论的算法，不宣称所有算法的下界。正文关注主要项和量级，精确低阶项集中在折叠推导中。

怎样数：从点积到矩阵乘法 How to Count: From Dot Products to Matrix Products

长度为 nn 的点积（dot product） ∑j=1najxj\sum_{j=1}^n a_jx_j 需要 nn 次乘法与 n−1n-1 次加法，合计约 2n2n 次，是 O(n)O(n)。

设 A∈ℝm×nA\in\mathbb R^{m\times n}、𝐱∈ℝn\mathbf x\in\mathbb R^n。A𝐱A\mathbf x 有 mm 个输出，每个是长度为 nn 的行与输入的点积，因此约需 m⋅2n=2mnm\cdot2n=2mn 次。这里数的是 mm 个向量点积。

再设 B∈ℝn×pB\in\mathbb R^{n\times p}。ABAB 有 mpmp 个输出元素，每个由长度为 nn 的行列点积给出，所以约需 mp⋅2n=2mnpmp\cdot2n=2mnp 次。这就是“输出数量 × 每个输出所需工作量”。

运算 / Operation 输出数量 × 每个输出工作 / Outputs × Work per Output 量级 / Order
长度 nn 的向量加减或数乘 n×1=nn\times1=n O(n)O(n)
m×nm\times n 矩阵加减或数乘 mn×1=mnmn\times1=mn O(mn)O(mn)
长度 nn 的点积 1×(2n−1)≈2n1\times(2n-1)\approx2n O(n)O(n)
m×nm\times n 矩阵乘向量 约 m×2n=2mnm\times2n=2mn；方阵约 2n22n^2 O(mn)O(mn)；方阵 O(n2)O(n^2)
m×nm\times n 与 n×pn\times p 矩阵相乘 约 mp×2n=2mnpmp\times2n=2mnp；方阵约 2n32n^3 O(mnp)O(mnp)；方阵 O(n3)O(n^3)
选读推导：精确到低阶项 / Optional Derivation: Exact Lower-Order Terms

每个点积的精确次数为 2n−12n-1。因此，A𝐱A\mathbf x 共需 m(2n−1)m(2n-1) 次；ABAB 共需 mp(2n−1)mp(2n-1) 次。方阵情形分别为 2n2−n2n^2-n 和 2n3−n22n^3-n^2，主要项为 2n22n^2 和 2n32n^3。这些精确式用于理解计数，不必逐个记忆。

分步工作量：消元与三角求解 Adding Step Costs: Elimination and Triangular Solves

课程中的完整高斯消元法（Gaussian elimination）包括向前得到阶梯形（REF），再向后归一化主元并清除上方元素，得到简化阶梯形（RREF）。向后行化简（backward row reduction）继续改变矩阵；回代（back substitution）则从最后一行起逐个确定未知数。LU求解只需前代与回代，不必先把 UU 化为RREF。

考虑可按无换行LU算法分解的非奇异稠密 n×nn\times n 方阵。第 jj 步先计算乘子 lijl_{ij}，再更新剩余子矩阵： aih←aih−lijujh,i,h>j.a_{ih}\leftarrow a_{ih}-l_{ij}u_{jh},\qquad i,h>j. 这里 aiha_{ih} 指当前工作矩阵的元素，ujhu_{jh} 是当前主元行的元素。剩余方块有 (n−j)2(n-j)^2 个位置，每个位置一次乘法与一次减法。将各步相加，得到 2∑j=1n−1(n−j)2∼23n3.2\sum_{j=1}^{n-1}(n-j)^2\sim\frac23n^3. 乘子的除法只贡献低阶项，所以常规LU分解主要项约为 23n3\frac23n^3，是 O(n3)O(n^3)；∼\sim 表示 n→∞n\to\infty 时两项之比趋于1。

常规完整消元的整体量级也是 O(n3)O(n^3)，但具体次数取决于更新范围、归一化方式和求解任务。上述 23n3\frac23n^3 是这里的LU分解主要项，不能不加限定地用作所有完整消元实现的统一系数，也不能断言所有向后行化简一律只需 O(n2)O(n^2)。

从每行数出前代与回代 Counting Forward and Back Substitution by Rows

对非零对角元的下三角方程组，第 ii 行使用已经求得的 i−1i-1 个分量。每个分量带来一次乘法、一次减法，最后除以对角元；每行的工作随行号增长。相加得到一次前代约 n2n^2 次；回代反向逐行计数，同样约 n2n^2 次。一次前代加回代约 2n22n^2 次。单位下三角的前代可省掉除以1，主要项不变。求解公式与条件见三角方程组 / Triangular Systems。

选读推导：逐步求和与适用范围 / Optional Derivation: Step Sums and Scope

令 q=n−jq=n-j，有 2∑q=1n−1q2=n(n−1)(2n−1)3=23n3−n2+13n.2\sum_{q=1}^{n-1}q^2=\frac{n(n-1)(2n-1)}3 =\frac23n^3-n^2+\frac13n. 乘子需 ∑q=1n−1q=n(n−1)/2\sum_{q=1}^{n-1}q=n(n-1)/2 次除法。若只数这些除法与剩余子块的乘减，分解共 23n3−12n2−16n\frac23n^3-\frac12n^2-\frac16n 次算术运算。一般前代逐行共 ∑i=1n[2(i−1)+1]=n2.\sum_{i=1}^n[2(i-1)+1]=n^2. 单位下三角前代为 n(n−1)n(n-1) 次；一般上三角回代为 n2n^2 次。因此LU后的两次三角求解共 2n2−n2n^2-n 次，主要项是 2n22n^2。

复制、赋值、主元比较与数据交换不计入本处标量加减乘除。采用 PA=LUPA=LU 时须相应排列目标向量。教材§2.5的数值注解给出上述主要项；这里补上求和。稀疏、快速或其他特殊结构算法可能有不同成本；小规模时也不能忽略低阶项。

若任务是求逆，对 [A∣In][A\mid I_n] 的处理要同步作用于 nn 个目标列；它的成本不能等同于对一个向量做一次回代。这里不展开求逆的完整计数。

同一结果，计算顺序为何重要？ Why Does Evaluation Order Matter?

由列组合和线性性已证明复合等式 / Composition Identity (AB)𝐱=A(B𝐱)(AB)\mathbf x=A(B\mathbf x)。结合律允许改变括号，但不能交换 A,BA,B。给定两个 n×nn\times n 稠密矩阵 A,BA,B，ABAB 尚未计算，这次只求一个给定输入向量 𝐱∈ℝn\mathbf x\in\mathbb R^n 的像 (AB)𝐱(AB)\mathbf x：

  • 先算 B𝐱B\mathbf x，再算 A(B𝐱)A(B\mathbf x)：两次矩阵向量乘法，约 4n24n^2 次，是 O(n2)O(n^2)。
  • 先显式形成 ABAB，再乘 𝐱\mathbf x：常规方法主要项约 2n32n^3 次，是 O(n3)O(n^3)。

代数上相同，计算的组织方式会影响工作量。 比较针对这一次求值；若 ABAB 已经算好，或还要用于其他任务，就应按实际复用情形重新比较。

短练习 / Quick Practice. A,BA,B 都是 100×100100\times100 稠密矩阵，尚未计算 ABAB，只需一个 (AB)𝐱(AB)\mathbf x。选择哪种顺序？按主要项估计各需多少次运算（数值保留两位有效数字）？

反馈：先数所需的点积 / Feedback: Count the Required Dot Products

选 A(B𝐱)A(B\mathbf x)：约 4.0×1044.0\times10^4 次；先形成乘积再乘向量约 2.0×1062.0\times10^6 次。这里采用主要项估计。区别在于第二条路径先求出了整个矩阵的全部列，而本次只需一个向量的像；不能据此交换 A,BA,B 的顺序。

回到LU：一次性成本与每次求解成本 Returning to LU: Setup Cost and Cost per Solve

仍限于上述非奇异稠密方阵和常规算法。一次分解保存对 AA 的消元结果；每次新目标只需解 L𝐲=𝐛L\mathbf y=\mathbf b、U𝐱=𝐲U\mathbf x=\mathbf y。

因此，对同一个 AA 的 kk 个目标向量，分解一次再复用的主要计算量约为 23n3+2kn2,\boxed{\frac23n^3+2kn^2}, 而每次独立重新消元会把分解成本也付 kk 次，主项约为 k(23n3+2n2)k(\frac23n^3+2n^2)。这解释了为何理论上可写 𝐱=A−1𝐛\mathbf x=A^{-1}\mathbf b，实际求解却常复用LU。已有LU后增加一个目标约需 2n22n^2 次。这里的 kk 表示目标个数，求和中的 jj 表示步骤编号。

短练习 / Quick Practice. 对可按当前算法分解的非奇异稠密 100×100100\times100 矩阵依次求解10个目标。用上述主要项估计：分解一次再复用、每个目标重新分解并求解，各需多少？若LU已经给出，新增第11个目标又需多少？数值保留两位有效数字。

反馈：分清一次成本与每次成本 / Feedback: Separate Setup from Each Solve
  • 分解一次后解十个目标：23⋅1003+2⋅10⋅1002≈8.7×105\frac23\cdot100^3+2\cdot10\cdot100^2\approx8.7\times10^5 次。
  • 十次各自重新分解并求解：10(23⋅1003+2⋅1002)≈6.9×10610(\frac23\cdot100^3+2\cdot100^2)\approx6.9\times10^6 次。
  • 已有分解后增加一个目标：2⋅1002≈2.0×1042\cdot100^2\approx2.0\times10^4 次。

这些都是主要项估计，不能与含低阶项的精确计数混用。第二项只把“一次分解加一次求解”的成本乘10；新增目标则不再计分解成本。

用结构节省计算 Saving Work with Matrix Structure

回看特殊矩阵的乘法 / Products of Special Matrices：已知零元素可以省掉工作，但未必改变增长量级。对利用结构的常规算法：

  • 对角矩阵乘向量只需分别缩放 nn 个分量，为 O(n)O(n)。
  • 一般稠密三角矩阵乘向量，约有一半元素参与，工作仍随 n2n^2 增长，为 O(n2)O(n^2)。
  • 同阶稠密三角矩阵相乘，虽然每个元素的求和范围缩短，全部工作仍为 O(n3)O(n^3)。
  • 三角方程组求解为 O(n2)O(n^2)；它求未知输入，与计算两个矩阵的乘积是不同任务。

简短辨析 / Quick Check. “上三角矩阵乘积仍为上三角，所以两个上三角矩阵相乘只需 O(n2)O(n^2)。”这个理由充分吗？

反馈：结果数量之外还要数每个结果 / Feedback: Count the Work per Output Too

不充分。对上三角 U,VU,V，第 (i,j)(i,j) 个输出在 i≤ji\le j 时仍须累计 j−i+1j-i+1 个乘积。许多输出的求和长度随 nn 增长；结果约有一半为零，并没有把常规算法的总量级降到 O(n2)O(n^2)。
