矩阵代数

Chapter 2 · Matrix Algebra

汇编目录 / Reference contents · 本页的矩阵和标量均为实数。InI_n 是 nn 阶单位矩阵，ATA^T 是转置（transpose）。方阵 AA 可逆（invertible）指存在同阶矩阵 A−1A^{-1} 满足 AA−1=A−1A=IAA^{-1}=A^{-1}A=I。 基、维数和秩的简要说明放在§2.8与§2.9，前面的可逆性判据不预用它们。

§2.1 矩阵运算 / Matrix Operations

定理 1：矩阵加法与数乘运算律 Addition and Scalar Multiplication Laws

来源 / Source：第2章 定理1 / Chapter 2, Theorem 1；§2.1。中英文名为描述性名称。

设 A,B,C∈ℝm×nA,B,C\in\mathbb R^{m\times n}，r,s∈ℝr,s\in\mathbb R，00 是同尺寸的零矩阵。则：

  1. A+B=B+AA+B=B+A。

  2. (A+B)+C=A+(B+C)(A+B)+C=A+(B+C)。

  3. A+0=AA+0=A。

  4. r(A+B)=rA+rBr(A+B)=rA+rB。

  5. (r+s)A=rA+sA(r+s)A=rA+sA。

  6. r(sA)=(rs)Ar(sA)=(rs)A。

理解与回查。 加法和数乘逐元素进行，因此沿用实数运算律；相加矩阵必须同尺寸。运算性质；教材逐项说明见 §2.1。

定理 2：矩阵乘法运算律 Matrix Multiplication Laws

来源 / Source：第2章 定理2 / Chapter 2, Theorem 2；§2.1。中英文名为描述性名称。

设 A∈ℝm×nA\in\mathbb R^{m\times n}，r∈ℝr\in\mathbb R。以下每条各自假设其中的加法和乘法有定义：

  1. A(BC)=(AB)CA(BC)=(AB)C。例如 BB 为 n×pn\times p、CC 为 p×qp\times q。

  2. A(B+C)=AB+ACA(B+C)=AB+AC，其中 B,CB,C 同为 n×pn\times p。

  3. (B+C)A=BA+CA(B+C)A=BA+CA，其中 B,CB,C 同为 p×mp\times m。

  4. r(AB)=(rA)B=A(rB)r(AB)=(rA)B=A(rB)，其中 BB 为 n×pn\times p。

  5. ImA=A=AInI_mA=A=AI_n。

理解与回查。 结合律允许改括号，不允许交换因子；不能把这些式子读成 AB=BAAB=BA。复合与结合律、性质表；教材 §2.1，其他分项见 §2.1 Exercises 37–39。

定理 3：转置运算律 Transpose Laws

来源 / Source：第2章 定理3 / Chapter 2, Theorem 3；§2.1。中英文名为描述性名称。

对实矩阵及实数 rr，在各式尺寸相容时：

  1. (AT)T=A(A^T)^T=A。

  2. (A+B)T=AT+BT(A+B)^T=A^T+B^T（A,BA,B 同尺寸）。

  3. (rA)T=rAT(rA)^T=rA^T。

  4. (AB)T=BTAT(AB)^T=B^TA^T（例如 AA 为 m×nm\times n，BB 为 n×pn\times p）。

理解与回查。 转置乘积时必须倒转次序，所得尺寸为 p×mp\times m。转置与乘法；教材 §2.1，(d)证明指向 §2.1 Exercise 41。

§2.2 逆矩阵 / The Inverse of a Matrix

定理 4：二阶矩阵的逆公式与奇异判据 The Inverse of a Two-by-Two Matrix

来源 / Source：第2章 定理4 / Chapter 2, Theorem 4；§2.2。中英文名为描述性名称。

设 A=[abcd]A=\begin{bmatrix}a&b\\c&d\end{bmatrix}，a,b,c,d∈ℝa,b,c,d\in\mathbb R。

  • 若 ad−bc≠0ad-bc\ne0，则 AA 可逆，且

    A−1=1ad−bc[d−b−ca]. A^{-1}=\frac1{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}.

  • 若 ad−bc=0ad-bc=0，则 AA 不可逆。

理解与回查。 先检查分母，再使用公式；奇异分支不能用“分母为零时公式无意义”代替不可逆结论。教材把证明留在 §2.2 Exercises 35–36。已有增广求逆计算可与一般公式对照。

定理 5：可逆系统的唯一解 Solving with an Inverse

来源 / Source：第2章 定理5 / Chapter 2, Theorem 5；§2.2。中英文名为描述性名称。

若 A∈ℝn×nA\in\mathbb R^{n\times n} 可逆，则对每个 𝐛∈ℝn\mathbf b\in\mathbb R^n，方程 A𝐱=𝐛A\mathbf x=\mathbf b 有唯一解，且 𝐱=A−1𝐛\mathbf x=A^{-1}\mathbf b。

理解与回查。 代入验证存在，左乘 A−1A^{-1} 验证所有解都只能是这一向量。存在与唯一的证明；教材 §2.2。该表达式是理论结论，不要求计算时先显式求逆。

定理 6：逆矩阵运算律 Properties of Inverses

来源 / Source：第2章 定理6 / Chapter 2, Theorem 6；§2.2。中英文名为描述性名称。

  1. 若实方阵 AA 可逆，则 A−1A^{-1} 也可逆，且 (A−1)−1=A(A^{-1})^{-1}=A。

  2. 若 A,B∈ℝn×nA,B\in\mathbb R^{n\times n} 都可逆，则 ABAB 可逆，且 (AB)−1=B−1A−1(AB)^{-1}=B^{-1}A^{-1}。

  3. 若实方阵 AA 可逆，则 ATA^T 可逆，且 (AT)−1=(A−1)T(A^T)^{-1}=(A^{-1})^T。

理解与回查。 复合动作要按相反次序撤销；每个逆候选都要满足双侧乘积为单位矩阵。双侧核对；教材 §2.2。

定理 7：行消元求逆的充要条件 Row Reduction and Invertibility

来源 / Source：第2章 定理7 / Chapter 2, Theorem 7；§2.2。中英文名为描述性名称。

设 A∈ℝn×nA\in\mathbb R^{n\times n}。AA 可逆当且仅当 AA 行等价于 InI_n。此时，任何把 AA 化成 InI_n 的初等行操作序列，施加在 InI_n 上都会得到 A−1A^{-1}。

因此在增广矩阵 [AIn]\left[\begin{array}{c|c}A&I_n\end{array}\right] 上同步操作，若左侧能化成 InI_n，右侧即为 A−1A^{-1}；若不能，AA 不可逆。

理解与回查。 右侧记录同一串操作的作用。初等矩阵解释、可逆性等价链；教材证明与算法见 §2.2。

§2.3 可逆性刻画 / Characterizations of Invertibility

定理 8：可逆矩阵定理：初始十二项 The Invertible Matrix Theorem

来源 / Source：第2章 定理8 / Chapter 2, Theorem 8；§2.3。教材原题名。

设 A∈ℝn×nA\in\mathbb R^{n\times n}。以下十二项等价：其中任意一项成立时全部成立，任意一项不成立时全部不成立。

消元与齐次系统 / Elimination and homogeneous systems

  1. AA 可逆。

  2. AA 行等价于 InI_n。

  3. AA 有 nn 个主元位置。

  4. A𝐱=𝟎A\mathbf x=\mathbf0 只有平凡解。

  5. AA 的列向量线性无关。

  6. 线性变换 𝐱↦A𝐱\mathbf x\mapsto A\mathbf x 是单射。

所有右端与映射 / All right-hand sides and mappings

  1. 对每个 𝐛∈ℝn\mathbf b\in\mathbb R^n，A𝐱=𝐛A\mathbf x=\mathbf b 至少有一个解。

  2. AA 的列向量张成 ℝn\mathbb R^n。

  3. 线性变换 𝐱↦A𝐱\mathbf x\mapsto A\mathbf x 把 ℝn\mathbb R^n 映满 ℝn\mathbb R^n。

单侧逆与转置 / One-sided inverses and transpose

  1. 存在 C∈ℝn×nC\in\mathbb R^{n\times n}，使 CA=InCA=I_n。

  2. 存在 D∈ℝn×nD\in\mathbb R^{n\times n}，使 AD=InAD=I_n。

  3. ATA^T 可逆。

理解与回查。 方阵前提把“足够多的主元”和“没有自由变量”合在一起；矩形矩阵不能照搬全部等价项。现有主元等价链；教材 §2.3 给完整链。(l)的反向由 (AT)T=A(A^T)^T=A 和定理6(c)得到。

后续阶段 / Later stages： §2.9 基与秩 m–q → §4.5 重述 m–q → §5.2 特征值 r → §7.4 正交补与奇异值 s–v。各阶段使用的新概念在对应页面说明。

定理 9：可逆变换与矩阵的逆 Invertible Linear Transformations

来源 / Source：第2章 定理9 / Chapter 2, Theorem 9；§2.3。中英文名为描述性名称。

设 T:ℝn→ℝnT:\mathbb R^n\to\mathbb R^n 线性，标准矩阵为 AA。这里 TT 可逆指存在映射 S:ℝn→ℝnS:\mathbb R^n\to\mathbb R^n，使对所有 𝐱∈ℝn\mathbf x\in\mathbb R^n 同时有

S(T(𝐱))=𝐱,T(S(𝐱))=𝐱. S(T(\mathbf x))=\mathbf x,\qquad T(S(\mathbf x))=\mathbf x.

则 TT 可逆当且仅当 AA 可逆；此时满足上述双侧关系的 SS 唯一，且 SS 是线性变换，其公式为

S(𝐱)=A−1𝐱.S(\mathbf x)=A^{-1}\mathbf x.

理解与回查。 两侧恒等分别保证可恢复原输入和每个输出都可被恢复。教材 §2.3 给出双侧定义，并在定理框中陈述等价、线性与唯一性；唯一性证明另指本节 Exercise 47。已有逆的解释与列关系中的可逆变换可帮助理解，完整一般命题见本条。

§2.4 分块矩阵 / Partitioned Matrices

定理 10：矩阵乘积的列行外积展开 Column–Row Expansion of AB

来源 / Source：第2章 定理10 / Chapter 2, Theorem 10；§2.4。教材原题名。

设 A∈ℝm×nA\in\mathbb R^{m\times n}、B∈ℝn×pB\in\mathbb R^{n\times p}。用 col⁡k(A)\operatorname{col}_k(A) 表示 AA 的第 kk 列（m×1m\times1），row⁡k(B)\operatorname{row}_k(B) 表示 BB 的第 kk 行（1×p1\times p）。则

AB=∑k=1ncol⁡k(A)row⁡k(B). AB=\sum_{k=1}^n\operatorname{col}_k(A)\operatorname{row}_k(B).

每一项都是 m×pm\times p 的外积（outer product），它们的和也是 m×pm\times p 矩阵。

理解与回查。 行乘列算一个元素，列乘行产生整个矩阵；本定理把乘积拆成后者的和。第 (i,j)(i,j) 个元素都是 ∑kaikbkj\sum_k a_{ik}b_{kj}，给出逐元素证明。已有分块与外积例；教材证明见 §2.4。

§2.6 投入产出模型 / The Leontief Input–Output Model

定理 11：投入产出模型的非负唯一解 Nonnegative Solutions of the Leontief Model

来源 / Source：第2章 定理11 / Chapter 2, Theorem 11；§2.6。中英文名为描述性名称。

设 C=(cij)∈ℝn×nC=(c_{ij})\in\mathbb R^{n\times n} 为消耗矩阵（consumption matrix）：cijc_{ij} 表示第 jj 部门生产一个单位产出需要第 ii 部门的投入量；𝐝∈ℝn\mathbf d\in\mathbb R^n 为最终需求（final demand），𝐱\mathbf x 为总产出。假设

cij≥0,di≥0,∑i=1ncij<1(j=1,…,n). c_{ij}\ge0,\quad d_i\ge0,\quad \sum_{i=1}^n c_{ij}<1\quad(j=1,\ldots,n).

则 In−CI_n-C 可逆，且

𝐱=(In−C)−1𝐝\mathbf x=(I_n-C)^{-1}\mathbf d

是方程 𝐱=C𝐱+𝐝\mathbf x=C\mathbf x+\mathbf d 的唯一解，并且各分量非负。

理解与回查。 每列和严格小于 11 是保证可行总产出的充分条件，不能反写为必要条件。教材 §2.6 用 I+C+C2+⋯I+C+C^2+\cdots 说明逆矩阵为何非负；模型定义也在本节。𝐝=𝟎\mathbf d=\mathbf0 时唯一解是 𝟎\mathbf0，也在结论内。

§2.8 子空间与基 / Subspaces and Bases

子空间（subspace）是含零且对加法、数乘封闭的子集。Col⁡A\operatorname{Col}A 是 AA 的列张成的空间；Nul⁡A={𝐱:A𝐱=𝟎}\operatorname{Nul}A=\{\mathbf x:A\mathbf x=\mathbf0\} 是零空间（null space）。子空间 HH 的基（basis）是 HH 内既线性无关又张成 HH 的一组向量。

定理 12：零空间是子空间 The Null Space Is a Subspace

来源 / Source：第2章 定理12 / Chapter 2, Theorem 12；§2.8。中英文名为描述性名称。

若 A∈ℝm×nA\in\mathbb R^{m\times n}，则 Nul⁡A\operatorname{Nul}A 是 ℝn\mathbb R^n 的子空间。等价地，一个含 nn 个未知数的实齐次线性方程组的解集是 ℝn\mathbb R^n 的子空间。

理解与回查。 未知向量有 nn 个分量，零空间因此在 ℝn\mathbb R^n 中，而不是 ℝm\mathbb R^m 中。零、加法与数乘检查；教材证明见 §2.8；第四章定理2重述此结论。

定理 13：原矩阵主元列给出列空间基 A Basis for the Column Space

来源 / Source：第2章 定理13 / Chapter 2, Theorem 13；§2.8。中英文名为描述性名称。

设 A∈ℝm×nA\in\mathbb R^{m\times n}。由 AA 的阶梯形确定主元列的下标，再从原矩阵 AA 中取出这些列，它们构成 Col⁡A\operatorname{Col}A 的一组基。

理解与回查。 行化简保留列之间的线性关系，却通常改变列空间；不能直接取阶梯形矩阵的列充当原列空间的基。教材 §2.8 的例7–8说明理由；第四章定理6重述。零矩阵没有主元列，零子空间的空基约定见下段。

§2.9 维数与秩 / Dimension and Rank

有限维空间的维数（dimension）是基中向量的个数，记作 dim⁡H\dim H；矩阵的秩（rank）定义为 rank⁡A=dim⁡Col⁡A\operatorname{rank}A=\dim\operatorname{Col}A，零度（nullity）是 dim⁡Nul⁡A\dim\operatorname{Nul}A。零子空间 {𝟎}\{\mathbf0\} 的维数是 00。

零子空间约定 / Zero-space convention。 教材 §2.9 脚注称零子空间“没有基”，并另定维数为 00；允许空集作基的另一常见约定则把空组作为它的基。本汇编在涉及空组时明确指出后一解释，不把两种措辞混用：零矩阵主元列为空，若允许空基，这个空组就是其零列空间的基；按教材措辞则将零子空间单列。两种约定的维数与秩计算相同。

定理 14：秩与零度定理 The Rank Theorem

来源 / Source：第2章 定理14 / Chapter 2, Theorem 14；§2.9。教材原题名。

若 A∈ℝm×nA\in\mathbb R^{m\times n}，则

rank⁡A+dim⁡Nul⁡A=n.\operatorname{rank}A+\dim\operatorname{Nul}A=n.

理解与回查。 主元列数与自由变量数合计为未知数个数 nn；不是行数 mm。零矩阵时为 0+n=n0+n=n。教材 §2.9；更一般的讨论实际位于 §4.5 定理14，不是原书此处交叉引用所写的 §4.6。

定理 15：子空间的基定理 The Basis Theorem

来源 / Source：第2章 定理15 / Chapter 2, Theorem 15；§2.9。教材原题名。

设 HH 是 ℝn\mathbb R^n 中维数为 pp 的子空间。

  • HH 中任何恰含 pp 个向量的线性无关组，都是 HH 的基。
  • HH 中任何恰含 pp 个向量、并且张成 HH 的向量组，也都是 HH 的基。

理解与回查。 数量等于维数时，只需检查“无关”或“张成”之一；向量首先必须属于 HH。p=0p=0 时按上面的零子空间约定解释。教材证明见 §4.5 定理13。

可逆矩阵定理续篇：基、秩与零空间扩展 The Invertible Matrix Theorem (continued)

来源 / Source：第2章 / Chapter 2，§2.9，The Invertible Matrix Theorem (continued)。教材原题名。

设 A∈ℝn×nA\in\mathbb R^{n\times n}。以下每一项都等价于“AA 可逆”，也等价于 §2.3 的(a)–(l)：

  1. AA 的列向量构成 ℝn\mathbb R^n 的一组基。

  2. Col⁡A=ℝn\operatorname{Col}A=\mathbb R^n。

  3. rank⁡A=n\operatorname{rank}A=n。

  4. dim⁡Nul⁡A=0\dim\operatorname{Nul}A=0。

  5. Nul⁡A={𝟎}\operatorname{Nul}A=\{\mathbf0\}。
