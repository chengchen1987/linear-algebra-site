线性方程与线性变换

Chapter 1 · Linear Equations and Linear Transformations

汇编目录 / Reference contents · 本页按教材第一章定理号排列。 本页矩阵、向量和标量均在实数域 ℝ\mathbb R 上；ℝn\mathbb R^n 是有 nn 个实分量的列向量空间。 Span\operatorname{Span} 表示所有线性组合构成的集合（张成 / span），𝟎\mathbf 0 表示所在空间的零向量。 需要消元、主元、线性无关和映射的定义时，可查术语表 / Glossary。

§1.2 行化简与阶梯形 / Row Reduction and Echelon Forms

定理 1：简化阶梯形的唯一性 Uniqueness of the Reduced Echelon Form

来源 / Source：第1章 定理1 / Chapter 1, Theorem 1；§1.2。教材原题名。

对任意 m×nm\times n 实矩阵 AA，存在且仅存在一个与 AA 行等价（row equivalent）的简化行阶梯形矩阵（reduced row echelon form，RREF）。行等价指可用有限次初等行操作互相得到。

理解与回查。 消元路径可以不同，最终 RREF 相同；一般行阶梯形（REF）并不唯一。零矩阵也包括在内。消元与主元给出完整陈述和计算；一般唯一性证明见教材附录A。两条数值消元路径仅是例证。

定理 2：解的存在与唯一性 Existence and Uniqueness Theorem

来源 / Source：第1章 定理2 / Chapter 1, Theorem 2；§1.2。教材原题名。

一个实线性方程组相容（consistent，有解），当且仅当其增广矩阵的最后一列不是主元列；等价地，增广矩阵的阶梯形中没有对应 0=b0=b、b≠0b\ne0 的行。

在已经相容的前提下：

  1. 没有自由变量时，解唯一；
  2. 至少有一个自由变量时，有无穷多个解。

理解与回查。 先检查存在性，再用自由变量判断唯一性。主元计数不可跳过相容性检查。读出解的类型与全部解给出理由和计算；教材 §1.2。

§1.4 矩阵方程 / The Matrix Equation

定理 3：三种方程表示的解集一致 Equivalent Forms of a Linear System

来源 / Source：第1章 定理3 / Chapter 1, Theorem 3；§1.4。中英文名为描述性名称。

设 A=[𝐚1⋯𝐚n]∈ℝm×nA=[\mathbf a_1\ \cdots\ \mathbf a_n]\in\mathbb R^{m\times n}，𝐛∈ℝm\mathbf b\in\mathbb R^m。以下三种表示对未知列向量 𝐱=(x1,…,xn)T∈ℝn\mathbf x=(x_1,\ldots,x_n)^T\in\mathbb R^n 给出完全相同的解集：

  • 矩阵方程 A𝐱=𝐛A\mathbf x=\mathbf b；
  • 向量方程 x1𝐚1+⋯+xn𝐚n=𝐛x_1\mathbf a_1+\cdots+x_n\mathbf a_n=\mathbf b；
  • 增广矩阵为 [𝐚1⋯𝐚n𝐛]\left[\begin{array}{ccc|c}\mathbf a_1&\cdots&\mathbf a_n&\mathbf b\end{array}\right] 的线性方程组。

理解与回查。 列组合的系数就是原方程组的未知数，三种写法没有换一批解。三种方程与求解；教材 §1.4。

定理 4：全部目标可达的四个等价条件 Solvability for Every Right-Hand Side

来源 / Source：第1章 定理4 / Chapter 1, Theorem 4；§1.4。中英文名为描述性名称。

对固定的 A∈ℝm×nA\in\mathbb R^{m\times n}，以下条件等价：

  1. 对每个 𝐛∈ℝm\mathbf b\in\mathbb R^m，A𝐱=𝐛A\mathbf x=\mathbf b 都有解。

  2. ℝm\mathbb R^m 中每个向量都是 AA 的列向量的线性组合。

  3. AA 的列向量张成 ℝm\mathbb R^m。

  4. AA 的每一行都有主元位置。

理解与回查。 它判断的是“所有右端都能达到”，并非只判断某个给定右端。条件(d)检查系数矩阵 AA，而非增广矩阵。每个目标与主元的双向理由；教材证明见 §1.4。

定理 5：矩阵向量乘积的线性 Linearity of Matrix-Vector Multiplication

来源 / Source：第1章 定理5 / Chapter 1, Theorem 5；§1.4。中英文名为描述性名称。

若 A∈ℝm×nA\in\mathbb R^{m\times n}，𝐮,𝐯∈ℝn\mathbf u,\mathbf v\in\mathbb R^n，c∈ℝc\in\mathbb R，则

  1. A(𝐮+𝐯)=A𝐮+A𝐯A(\mathbf u+\mathbf v)=A\mathbf u+A\mathbf v；

  2. A(c𝐮)=c(A𝐮)A(c\mathbf u)=c(A\mathbf u)。

理解与回查。 矩阵乘法保留输入的加法和数乘；这是“特解加齐次解”和线性变换的代数基础。一般分配律推导；教材 §1.4。

§1.5 线性系统的解集 / Solution Sets of Linear Systems

定理 6：非齐次解集是齐次解集的平移 A Particular Solution Plus Homogeneous Solutions

来源 / Source：第1章 定理6 / Chapter 1, Theorem 6；§1.5。中英文名为描述性名称。

设 A∈ℝm×nA\in\mathbb R^{m\times n}，𝐛∈ℝm\mathbf b\in\mathbb R^m，且 A𝐱=𝐛A\mathbf x=\mathbf b 相容。固定任意一个特解（particular solution）𝐩\mathbf p，即 A𝐩=𝐛A\mathbf p=\mathbf b。则全部解恰为

{𝐩+𝐯h:𝐯h∈ℝn,A𝐯h=𝟎}. \{\mathbf p+\mathbf v_h:\ \mathbf v_h\in\mathbb R^n,\ A\mathbf v_h=\mathbf0\}.

也就是说，每个齐次解都能加到 𝐩\mathbf p 上得到原方程的解，原方程的任意解减去 𝐩\mathbf p 又必是齐次解。

理解与回查。 求一个特解与求所有齐次解是两个任务。全部解的双向证明；教材 §1.5，Practice Problem 3 及其解答、Exercise 37。

条件说明。 允许 𝐛=𝟎\mathbf b=\mathbf0 或 𝐩=𝟎\mathbf p=\mathbf0；只需相容。教材定理后的 Warning 把图中非零平移的限制带入一般叙述，本条按定理框保留零情形。

§1.7 线性无关 / Linear Independence

定理 7：线性相关向量组的刻画 Characterization of Linearly Dependent Sets

来源 / Source：第1章 定理7 / Chapter 1, Theorem 7；§1.7。教材原题名。

设 S=(𝐯1,…,𝐯p)S=(\mathbf v_1,\ldots,\mathbf v_p) 是 ℝn\mathbb R^n 中的有序向量组，p≥2p\ge2。则 SS 线性相关（linearly dependent），当且仅当至少一个向量可以写成其余向量的线性组合。

进一步，若 SS 相关且 𝐯1≠𝟎\mathbf v_1\ne\mathbf0，则存在 j∈{2,…,p}j\in\{2,\ldots,p\}，使

𝐯j∈Span⁡{𝐯1,…,𝐯j−1}. \mathbf v_j\in\operatorname{Span}\{\mathbf v_1,\ldots,\mathbf v_{j-1}\}.

理解与回查。 一般结论说明“至少一个可删”；加强结论说明可以按既定次序找到可由前序表示的向量。不是每个向量都能由其余或前序表示。 从关系式解出一列给出一般两方向与前序条款的简短证明；教材证明在 §1.7。

证明思路。 非平凡零关系中解出一个非零系数对应的向量；反过来，把表示式移到一边，得到一个系数为 11 的非平凡零关系。若 𝐯1≠𝟎\mathbf v_1\ne\mathbf0，取关系中最后一个非零系数的下标 jj，必有 j>1j>1，即可得到前序表示。

定理 8：向量数多于分量数必相关 More Vectors Than Coordinates

来源 / Source：第1章 定理8 / Chapter 1, Theorem 8；§1.7。中英文名为描述性名称。

若 𝐯1,…,𝐯p∈ℝn\mathbf v_1,\ldots,\mathbf v_p\in\mathbb R^n 且 p>np>n，则这组向量线性相关。

理解与回查。 把向量排成 n×pn\times p 矩阵，主元至多有 nn 个，齐次系统必有自由变量。p≤np\le n 时本定理不作判断。主元数论证与训练；教材 §1.7。

定理 9：含零向量的组必相关 Sets Containing the Zero Vector

来源 / Source：第1章 定理9 / Chapter 1, Theorem 9；§1.7。中英文名为描述性名称。

若有限向量组 S=(𝐯1,…,𝐯p)S=(\mathbf v_1,\ldots,\mathbf v_p) 位于 ℝn\mathbb R^n 中，且至少一个向量为 𝟎\mathbf0，则 SS 线性相关。

理解与回查。 给该零向量系数 11，给其余向量系数 00，就得到非平凡零关系；只有零向量的单向量组也适用。定义与零向量情形；教材证明见 §1.7。

§1.9 线性变换的矩阵 / The Matrix of a Linear Transformation

定理 10：线性变换的唯一标准矩阵 The Standard Matrix of a Linear Transformation

来源 / Source：第1章 定理10 / Chapter 1, Theorem 10；§1.9。中英文名为描述性名称。

设 T:ℝn→ℝmT:\mathbb R^n\to\mathbb R^m 是线性变换（linear transformation）。存在唯一的 m×nm\times n 实矩阵 AA，使每个 𝐱∈ℝn\mathbf x\in\mathbb R^n 都满足 T(𝐱)=A𝐱T(\mathbf x)=A\mathbf x。 若 𝐞j\mathbf e_j 是 InI_n 的第 jj 列，即第 jj 个标准单位向量，则

A=[T(𝐞1)⋯T(𝐞n)]. A=[T(\mathbf e_1)\ \cdots\ T(\mathbf e_n)].

理解与回查。 只要知道所有标准单位向量的像，就知道整个线性规则。标准矩阵的构造、唯一性与计算；教材 §1.9，唯一性另见 §1.9 Exercise 41。

定理 11：单射与零核等价 Injectivity and the Zero Kernel

来源 / Source：第1章 定理11 / Chapter 1, Theorem 11；§1.9。中英文名为描述性名称。

设 T:ℝn→ℝmT:\mathbb R^n\to\mathbb R^m 线性。TT 为单射（one-to-one / injective），当且仅当方程 T(𝐱)=𝟎T(\mathbf x)=\mathbf0 只有平凡解 𝐱=𝟎\mathbf x=\mathbf0。 单射指不同输入有不同输出，等价于每个输出至多有一个原像。

理解与回查。 线性性把任意两个输入的比较化为它们之差是否映到零。两向证明；教材 §1.9。

定理 12：单满射的列向量判据 Onto and One-to-One Matrix Transformations

来源 / Source：第1章 定理12 / Chapter 1, Theorem 12；§1.9。中英文名为描述性名称。

设 T:ℝn→ℝmT:\mathbb R^n\to\mathbb R^m 线性，标准矩阵为 A∈ℝm×nA\in\mathbb R^{m\times n}。则：

  1. TT 映满 ℝm\mathbb R^m（onto / surjective），当且仅当 AA 的列向量张成 ℝm\mathbb R^m。

  2. TT 是单射，当且仅当 AA 的列向量线性无关。

理解与回查。 满射关心每个目标有没有原像，单射关心已有原像是否唯一；矩形矩阵也适用。单射与满射的列判据；教材证明见 §1.9。

补充结论 / Supplementary Results

行操作保持解集 / Row Operations Preserve Solutions

对实线性方程组的整个增广矩阵施行有限次初等行操作（交换两行、一行乘非零数、一行加另一行的倍数），解集不变；因此行等价的增广矩阵表示等价方程组。每步均有同类逆操作，两个方向都成立。

来源：§1.1 的未编号说明。它说明消元为何能保留全部解，与定理1的“最终RREF唯一”不同。双向等价解释。

齐次非平凡解判据 / Nontrivial Homogeneous Solutions

设 A∈ℝm×nA\in\mathbb R^{m\times n}。A𝐱=𝟎A\mathbf x=\mathbf0 总有零解；存在非零解当且仅当行化简后至少有一个自由变量，也就是主元数小于 nn。特别地，n>mn>m 足以保证非零解。

来源：§1.5 未编号框；是定理2对必相容系统的具体化，也支持定理8，不另计为新编号定理。齐次解的参数表示。
