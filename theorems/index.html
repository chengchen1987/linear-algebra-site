定理汇编

Theorem Reference · Chapters 1–7

本汇编帮助你按教材查找结论，再回到课程学习主题理解推导和应用。范围为 Lay、Lay 与 McDonald，Linear Algebra and Its Applications，第六版，第1–7章。各章按教材节与定理号排列；学习主题仍按课程原有顺序组织。

怎样查找 / How to Find a Result

使用侧栏的全站搜索，可输入中文名（如“最小二乘”）、英文名（如“Cauchy”），或教材章与定理号（如“第2章 定理11”）。进入结果后核对条目旁的节号与来源信息；不同章的定理号会重复。

每条以教材小节编号（如 §2.3）定位，并保留该章内的定理号。名称标为“教材原题名”时，英文沿用原书题名；标为“描述性名称”时，是为查找编写的中英文概括。陈述用中文重新组织，分项字母与原书对应。

“理解与回查”提供使用提示、已有课程讲解链接或教材证明位置。简短思路不等于完整证明，数值验证也不能代替一般证明。没有课程讲解的条目可先按教材位置阅读。本汇编的收录不表示所有条目都要在同一次课堂中讲授。

可逆矩阵定理的五个位置 / Five Locations of the Invertible Matrix Theorem

  1. §2.3：a–l，消元、方程、映射、逆与转置。
  2. §2.9：新增 m–q，基、维数、秩与零空间。
  3. §4.5：重述 m–q，一般向量空间之后再看。
  4. §5.2：新增 r，零特征值。
  5. §7.4：新增 s–v，正交补、行空间与奇异值。

各阶段在本章说明所需的新概念，完整列出该处条件，并互相链接。第二章不预先混入后续章的全部条件。

补充结论 / Supplementary Results

以下5项是教材中的重要未编号结论，与编号定理分开列出；定义、算法和例题没有因此改称定理。

  • 行操作保持解集 / Row Operations Preserve Solutions：§1.1。
  • 齐次非平凡解判据 / Nontrivial Homogeneous Solutions：§1.5，是定理2的具体化。
  • 有限区域缩放 / Scaling Regions of Finite Area or Volume：§3.3，扩展定理10。
  • 行秩等于列秩 / Equality of Row Rank and Column Rank：§4.5。
  • 实对称矩阵谱分解 / Spectral Decomposition：§7.1，由正交对角化与列—行展开得到。

记号与术语 / Notation and Terms

除第五章明确使用复数的部分外，陈述使用实数域。矩阵尺寸为正整数；零子空间、零矩阵和零秩仍须分别处理。粗体小写字母表示向量，大写字母表示矩阵，斜体小写字母表示标量。𝟎\mathbf0 与 InI_n 的尺寸由所在空间确定。

中英术语表 / Glossary集中列出配对名称，第四至七章的页内说明给出基、坐标、特征空间、正则随机矩阵、正交补、奇异值等必要定义。零子空间的教材措辞与空基惯例见第二章约定；奇异值的列表长度见第七章约定。
