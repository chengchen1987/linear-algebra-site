前言

Preface

开始学习 / Start Learning · 第一章总览 / Chapter 1 Overview · 定理汇编 / Theorem Reference

线性代数是现代科学与技术的重要基础，为许多领域提供了共同的数学语言和计算工具。在数据科学中，它帮助我们表示和分析高维数据；在人工智能中，它广泛用于机器学习模型的计算；在信号与图像处理中，它用于数据的变换、压缩和重建。对于物理专业的学生，分析耦合振动、描述量子态和处理实验数据，也都需要线性代数。学习线性代数，既是掌握一套计算方法，也是学习如何描述问题、认识结构和分析规律。

然而，线性代数的学习与后续应用之间，常常存在脱节。不少同学能够完成消元、计算行列式，却仍然困惑：我们究竟在学什么？这些定义为什么要这样提出？它们有什么用？等到真正需要使用时，又难以把学过的知识与眼前的问题联系起来。加强基础数学与实际应用之间的联系，也是兰州大学物理学院选择由物理学工作者参与线性代数教学的重要考虑之一。

在我的教学经验中，这种脱节的一个重要原因，与教材和课程组织知识的方式有关。我接触的一些中文教材，十分重视知识体系的完整性和计算方法的归纳，读起来更像一部可供查阅的“百科全书”：具体的定义、定理和方法都能找到，但它们为什么出现、彼此如何联系，有时没有得到充分解释。对于已经建立整体认识的读者，这样的组织方式便于查阅；对于初学者，却容易使学习变成逐项记忆和逐类练习。知道一个知识点的表述，与理解它在整个知识体系中的位置，仍然是两回事。

这份材料希望为初学者提供一条逐步认识线性代数的路径。它以 D. C. Lay 等人的《线性代数及其应用》（Linear Algebra and Its Applications，第六版）为主要教材依据，整理自我在 2024—2026 年课堂教学中使用的教案，并根据课堂反馈不断修订。课程的整体主线是：

线性方程组 → 矩阵代数与行列式 → 向量空间与线性变换 → 特征值与特征向量 → 正交、投影与最小二乘 → 对称矩阵、二次型与奇异值分解。

这些内容相互联系，我们对它们的认识也会随着学习逐步加深。例如，矩阵最初用来记录方程组的系数；通过矩阵与向量的乘法，我们开始认识矩阵所表示的运算；进一步学习向量空间和线性变换后，又能从更一般的角度理解这种运算。前面的具体问题帮助我们理解为什么需要后面的抽象概念，后面的概念也帮助我们重新认识前面的方法。

因此，这份材料特别重视知识之间的逻辑联系。我们为什么需要一个新概念？它回答了什么问题？一个计算步骤改变了什么，又保留了什么？同一个问题的代数表达和几何图像如何对应？我希望通过具体算例、必要的推导、图示和练习，引导读者沿着这些问题逐步建立理解，并在合适的位置介绍数据科学、机器学习、物理等领域中的应用。采用网页形式，也便于补充课堂上来不及充分展开的内容，供大家课后学习和反复查阅。

这份材料不能代替教材。子曰：“学而不思则罔，思而不学则殆。”我希望它能为线性代数的学习多提供一些“思”的线索，帮助读者理解概念的由来和知识之间的联系。同时，准确的定义、严密的论证、系统的阅读和足够的练习，也不可缺少。建议大家将本网页与教材配合使用：带着问题阅读，在具体计算中检验理解，再回到教材中整理和巩固所学的知识。也希望大家能够找到一本适合自己的教材，认真地读下去。

目前上线的仍是一个尚未完成、持续修订的版本。上述主线是整个课程的建设目标，并不意味着所有内容都已完成。已上线的各部分也处于不同的修订阶段：有些内容经过了多轮课堂检验，有些仍在调整结构和表述。与实际应用的联系尚不充分，部分图示、交互演示和练习还需要完善，文字与数学表达也可能存在疏漏。这些不足需要在后续教学和实际使用中继续发现、修正。

欢迎同学和同行提出意见。除了指出文字、公式或图示中的错误，我尤其希望了解：哪些地方读起来不够顺畅，哪些概念之间的联系还不清楚，哪些例子帮助了理解，以及哪些问题值得进一步展开。

希望这份材料能够帮助大家更有方向地进入线性代数的世界，在掌握计算方法的同时，逐步理解这些方法背后的意义。更希望在之后的学习、研究和工作中，面对一个看似陌生的问题时，大家能够认出其中熟悉的结构，发现：“原来，这就是一个线性代数问题。”并由此找到继续分析和解决问题的思路。
