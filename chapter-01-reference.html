方程组与矩阵表示 Linear Systems and Matrix Representation

固定未知数顺序；逐行写系数，缺项补零，各方程右边的常数单独附列。mm个方程、nn个未知数给m×nm\times n系数矩阵和m×(n+1)m\times(n+1)增广矩阵；末列不是新变量。 定义与双向转写 · 基础练习。

存在性与唯一性 Existence and Uniqueness

对 A∈ℝm×nA\in\mathbb R^{m\times n}、𝐛∈ℝm\mathbf b\in\mathbb R^m，相容（consistent）指至少一个解；唯一解还需没有自由变量。阶梯化后的矛盾行 [0⋯0c]\left[\begin{array}{ccc|c}0&\cdots&0&c\end{array}\right]、c≠0c\ne0 表示无解；相容且有自由变量表示无穷多解。先查相容，再谈唯一，不能只数未知数。

主元、基本变量与自由变量 Pivots, Basic Variables and Free Variables

主元（pivot）与主元列（pivot column）。 消元中用来清除同列其他项的非零数叫作主元。一个矩阵的主元位置（pivot position）是与其简化行阶梯形各非零行首个 11 对应的位置，含有主元位置的列叫主元列。

主元行（pivot row）是当前步骤中主元所在、用于消去同列其他元素的行；主元术语集中解释区分数值、位置与当前行。

与系数矩阵主元列对应的是基本变量，其余为自由变量；常数列不对应未知数。适用于实矩形矩阵。完整消元提供三行五未知数主例的矩阵、每步操作和解；判据用于决定参数个数。

张成 Span

给定 𝐚1,…,𝐚n∈ℝm\mathbf{a}_1,\ldots,\mathbf{a}_n\in\mathbb{R}^m，它们的张成集（span）定义为

Span⁡{𝐚1,…,𝐚n}={x1𝐚1+⋯+xn𝐚n:x1,…,xn∈ℝ}.\operatorname{Span}\{\mathbf{a}_1,\ldots,\mathbf{a}_n\} =\{x_1\mathbf{a}_1+\cdots+x_n\mathbf{a}_n:x_1,\ldots,x_n\in\mathbb{R}\}.

用于判断目标是否是这些列的组合；若把这些向量排为 m×nm\times n 的 AA，则 𝐛\mathbf b 属于张成集等价于 A𝐱=𝐛A\mathbf x=\mathbf b 相容。定义解释、平面例与练习 · 每行主元的双向理由。

列空间、零空间与子空间 Column Space, Null Space and Subspaces

Col⁡A=Span⁡{𝐚j}⊆ℝm\operatorname{Col}A=\operatorname{Span}\{\mathbf a_j\}\subseteq\mathbb R^m；Nul⁡A={𝐱∈ℝn:A𝐱=0}\operatorname{Nul}A=\{\mathbf x\in\mathbb R^n:A\mathbf x=0\}。前者判右端可达，后者给齐次解。 子空间须含零并对加法、实数数乘封闭；过原点不足够。相容且𝐛≠0\mathbf b\ne0的解集为𝐱p+Nul⁡A\mathbf x_p+\operatorname{Nul}A，不含零，不是线性子空间；空解集也不含零，而 {𝟎}\{\mathbf0\} 满足三条条件。 两个空间的解释 · 封闭性 · 平移。

全部解与特解 All Solutions and Particular Solutions

限相容的 A𝐱=𝐛A\mathbf x=\mathbf b；AA为实m×nm\times n矩阵，特解 𝐱p∈ℝn\mathbf x_p\in\mathbb R^n 是预先选定的一个解，齐次解 𝐱h\mathbf x_h 满足 A𝐱h=0A\mathbf x_h=0。

{𝐱∈ℝn:A𝐱=𝐛}={𝐱p+𝐱h:A𝐱h=𝟎}.\begin{aligned} &\{\mathbf x\in\mathbb R^n:A\mathbf x=\mathbf b\}\\ &\quad=\{\mathbf x_p+\mathbf x_h:A\mathbf x_h=\mathbf0\}. \end{aligned}

线性无关 Linear Independence

设 𝐚1,…,𝐚n\mathbf{a}_1,\ldots,\mathbf{a}_n 是 ℝm\mathbb{R}^m 中的向量。若

c1𝐚1+⋯+cn𝐚n=𝟎c_1\mathbf{a}_1+\cdots+c_n\mathbf{a}_n=\mathbf{0}

只能在 c1=⋯=cn=0c_1=\cdots=c_n=0 时成立，就称这组向量线性无关（linearly independent）。全零系数叫平凡解（trivial solution）；定义要求零组合没有其他系数组合。

若存在至少一个系数非零的组合得到零向量，这组向量就线性相关（linearly dependent）；这条非平凡关系是相关性的证据。“非平凡”指系数不全为零，不要求每个系数都非零。

用于保证有解时表示唯一；不保证所有目标可达。消元与独立练习 · 唯一性双向解释。

线性变换 Linear Transformations

映射 T:ℝn→ℝmT:\mathbb{R}^n\to\mathbb{R}^m 是线性变换（linear transformation），指对任意输入 𝐮,𝐯\mathbf{u},\mathbf{v} 和实数 cc，

T(𝐮+𝐯)=T(𝐮)+T(𝐯),T(c𝐮)=cT(𝐮).T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v}),\qquad T(c\mathbf{u})=cT(\mathbf{u}).

这两条合起来给 T(α𝐮+β𝐯)=αT(𝐮)+βT(𝐯)T(\alpha\mathbf{u}+\beta\mathbf{v})=\alpha T(\mathbf{u})+\beta T(\mathbf{v})，并能反复用于有限个向量的组合。少量数值测试不能证明“任意”成立，但一个失败例子就能否定线性。

映射 T:ℝn→ℝmT:\mathbb R^n\to\mathbb R^m 的定义域（domain）为 ℝn\mathbb R^n，陪域（目标空间，codomain）为指定的 ℝm\mathbb R^m；T(𝐱)T(\mathbf x) 是 𝐱\mathbf x 的像（image），所有像组成值域（range）。矩阵映射满足 Range⁡(TA)=Col⁡(A)\operatorname{Range}(T_A)=\operatorname{Col}(A)，值域可以只是陪域的一部分。定义及例子。

线性两性质必须对任意输入成立；T(0)=0T(0)=0仅为必要条件，例如平方规则仍非线性。反例与理由。

单射与满射 Injectivity and Surjectivity

对象为指定定义域与陪域（目标空间）的映射 T:ℝn→ℝmT:\mathbb R^n\to\mathbb R^m。

单射（one-to-one / injective）指不同输入不能得到相同输出。等价地，T(𝐮)=T(𝐯)T(\mathbf{u})=T(\mathbf{v}) 必须推出 𝐮=𝐯\mathbf{u}=\mathbf{v}。它允许一些目标没有原像，只要求每个目标至多对应一个输入。

满射（onto / surjective）指目标空间中每个向量都可达到，即每个目标至少有一个输入。必须说清目标空间；把目标空间改小，会改变是否满射的判断。

矩阵映射的单射回到“齐次仅零解/每列主元”，满射回到“每个目标有解/每行主元”。B/C矩形对照及答案保留反例与两方向理由。
