综合复习与课程回望

Part 7: Review and Course Retrospective

课程起点是把多条线性方程组织成一个矩阵。现在同一个矩阵还描述线性映射、坐标转换、可达空间与方向伸缩。下面的比较和练习帮助判断该用什么对象、什么基、什么误差；各页的完整证明仍可按链接查阅。

三种分解，各回答什么问题？ What Questions Do the Three Decompositions Answer?

分解 / Decomposition 对象与存在条件 / Object and existence 基与尺寸 / Bases and dimensions 作用 / Use
一般对角化 A=PDP−1A=PDP^{-1} n×nn\times n，在所选数域有 nn 个无关特征向量 同一空间同一特征基；P,DP,D 均 n×nn\times n，基未必正交 把反复作用化为各特征方向上的乘法
正交对角化 A=PDPTA=PDP^T 实 n×nn\times n，当且仅当对称 同一标准正交特征基；三个因子均 n×nn\times n 兼顾特征方向与欧氏几何，化二次型、求极值
SVD A=UΣVTA=U\Sigma V^T 任意实 m×nm\times n，允许矩形、秩亏或零矩阵 输入基 V:n×nV:n\times n，输出基 U:m×mU:m\times m；Σ:m×n\Sigma:m\times n 区分可达与消失方向，量伸缩、解最小范数问题、截断近似

相似变换用同一空间的一套新基描述端到端作用；SVD一般在两个不同空间分别选基。即使 AA 是方阵，SVD的 U,VU,V 也不必相同。对实对称矩阵，奇异值是特征值的绝对值；负特征值的符号可由两端方向的相反取向承担，不能直接把含负数的特征值对角阵称作SVD的 Σ\Sigma。

四类问题：未知对象与目标 Four Problems: Unknowns and Objectives

问题 / Problem 未知对象 / Unknown 目标与限制 / Objective and constraint 关键区别 / Distinction
精确求解 / Exact solution 系数向量 𝐱\mathbf x A𝐱=𝐛A\mathbf x=\mathbf b 先检查相容；核决定自由度
最小二乘 / Least squares 系数向量 𝐱\mathbf x 最小化 ∥A𝐱−𝐛∥\|A\mathbf x-\mathbf b\| 总存在；拟合唯一但系数未必唯一
最小范数 / Minimum norm 上述解集中的系数向量 在最小二乘解中最小化 ∥𝐱∥\|\mathbf x\| 再用输入空间的正交性，唯一得到 A+𝐛A^+\mathbf b
低秩近似 / Low-rank approximation 与 AA 同尺寸的矩阵 BB rank⁡B≤k\operatorname{rank}B\le k，最小化指定的矩阵范数误差 近似整个映射或数据矩阵，不是给一个固定目标求系数

最小二乘把目标投到列空间，最小范数再消去输入中的核分量。PCA则将每个中心化观测投到同一个低维方向空间，并通过协方差的特征值选择总平方误差最小的空间。这些问题共享投影和正交分解，但未知对象与约束不同。

边界检查与课程回望 Boundary Checks and a Course Retrospective

先判断，再解释。 “有零特征值就不定”“重复特征值时任何特征向量都正交”“零矩阵没有SVD”“所有最小二乘系数都一样长”“全部观测相同时保留方差比例为1”分别错在哪里？

完整解答 / Full Solution

diag⁡(1,0)\operatorname{diag}(1,0) 半正定而不定性要求正、负方向同时存在；同一特征空间内一般基未必正交；零矩阵取 Σ=0\Sigma=0 与任意相应尺寸的正交基即可；加上非零核分量会使最小范数解的范数平方严格增加；全部相同数据总方差为零，比例是未定义的 0/00/0，虽可用均值精确重建，却不能据此计算比例。

从第一部分看，矩阵先是方程组的紧凑表示；列观点把求解变成线性组合。第二部分让矩阵表示可组合的映射，秩与四空间说明它的能力与限制。第三部分用行列式检测可逆与体积变化。第四部分区分向量本身和坐标，让同一结构适用于函数与抽象空间。第五部分用特征方向理解反复作用。第六部分引入内积几何，将“不相容”转成“最佳逼近”。本部分再把正交几何与特征方向结合，并在SVD中允许输入、输出使用不同的基。

遇到新问题时，可以先问：对象在哪个空间，坐标按哪组基，矩阵从哪里映到哪里，哪些分量可达或消失，以及“最好”由什么误差和约束定义。这样的提问把计算方法连成可迁移的推理，而不只是一张公式清单。
