第二部分 · 矩阵代数

Part 2: Matrix Algebra

第一部分从线性方程组出发，通过行图像、列图像和消元，讨论解的存在性与唯一性，并逐步认识线性组合、子空间和线性变换。第二部分将在这些认识的基础上，进一步学习矩阵运算，并用矩阵研究线性变换与相关空间的结构。

矩阵加法、数乘和乘法，使我们能够组合已有的线性变换；逆矩阵帮助我们理解何时能够从输出唯一恢复输入；分块与矩阵分解则帮助我们看清运算结构，并组织和复用计算。随后，我们通过基、维数和秩描述空间中的独立方向，并用矩阵的四个基本子空间，进一步理解哪些目标向量能够达到、解为什么可能不唯一，以及方程之间的关系怎样影响求解。这里，A∈ℝm×nA\in\mathbb R^{m\times n} 接受输入 𝐱∈ℝn\mathbf x\in\mathbb R^n，产生输出 A𝐱∈ℝmA\mathbf x\in\mathbb R^m；给定的方程右端目标向量 𝐛∈ℝm\mathbf b\in\mathbb R^m 是否能成为输出，正是 A𝐱=𝐛A\mathbf x=\mathbf b 是否有解的问题。

可逆矩阵定理是贯穿这些内容的一条重要线索。对于方阵，求解、主元、线性无关、张成和线性变换等不同语言，能够描述同一种可逆性。随着基、维数和秩的引入，我们会再次认识这一联系；后续学习行列式、特征值和奇异值分解时，还会获得新的理解。

本部分先在 ℝn\mathbb R^n 的具体子空间中建立这些认识，为后续学习一般向量空间、坐标与换基，以及内积、正交和投影作准备。向量空间也称线性空间。此前已用实坐标的点积计算矩阵乘积的元素，后续将系统研究内积带来的长度、夹角与正交关系。

按问题顺读 Read by Mathematical Questions

学习入口 / Topic 主要问题 / Guiding Question
矩阵基本运算 / Basic Matrix Operations 不同计算表示怎样表达同一运算，乘积怎样对应变换复合？
逆矩阵与逆变换 / Inverse Matrices and Inverse Transformations 何时每个目标向量都对应唯一的输入，逆矩阵怎样表示这种对应？
初等矩阵与矩阵求逆 / Elementary Matrices and Computing Inverses 怎样复用同一组行变换求解多列目标，并得到逆矩阵？
可逆矩阵定理 / The Invertible Matrix Theorem 对方阵，方程、主元、列向量和线性变换为什么给出等价的可逆判据？
分块表示与运算 / Block Representation and Operations 怎样按输入、输出或行列分组，理解和组织运算？
分块矩阵的逆 / Inverses of Partitioned Matrices 怎样利用块结构理解和求出整体逆变换？
LU分解与方程组求解 / LU Factorization and Solving Linear Systems 为什么值得分解？为什么消元乘子能直接组成 LL？
矩阵的秩与秩分解 / Matrix Rank and Rank Factorization 怎样用基和维数描述独立方向，用CR记录列的坐标，并回看可逆性？
四个基本子空间 / Four Fundamental Subspaces 四个空间怎样共同解释可达目标、解的不唯一性和行之间的关系？

这些主题在实数范围内提供定义、推理、例题与独立计算。核心结果默认可见；提示、长证明与完整答案可以展开。可以按问题顺读，也可以通过回查链接复习相关定义和计算。

一般向量空间与换基、特征值、正交关系与最小二乘、奇异值分解分别在后续部分深化；相关学习主题尚待建设。现有定理汇编用于教材回查，不表示这些主题已经讲解；这些后续理论也不是当前消元证明的先修。
