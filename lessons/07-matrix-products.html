矩阵基本运算

Basic Matrix Operations

知识与术语速查 / Concepts and Terminology · 本部分学习路线 / Part Overview

为什么矩阵这样相乘？先从已经熟悉的向量运算出发：把许多向量排成列，让它们接受同一个矩阵的作用。逐列作用给出定义，行与列的点积给出计算元素的方法，变换复合解释它的含义。本页讨论实数矩阵，对应教材 §2.1。

矩阵的数乘与加法 Scalar Multiplication and Matrix Addition

设 A=[𝐚1⋯𝐚n]A=[\mathbf a_1\ \cdots\ \mathbf a_n]、B=[𝐛1⋯𝐛n]B=[\mathbf b_1\ \cdots\ \mathbf b_n] 都是 m×nm\times n 矩阵，每列在 ℝm\mathbb R^m 中。两个矩阵相等（equal），是指尺寸相同且对应列相等，也就是所有对应元素相等。

向量可以相加或乘一个实数；对每列做同样的运算，就得到矩阵的加法（matrix addition）与数乘（scalar multiplication）。对实数 cc，定义

A+B=[𝐚1+𝐛1⋯𝐚n+𝐛n],cA=[c𝐚1⋯c𝐚n].A+B=[\mathbf a_1+\mathbf b_1\ \cdots\ \mathbf a_n+\mathbf b_n],\qquad cA=[c\mathbf a_1\ \cdots\ c\mathbf a_n].

若 aija_{ij} 表示第 ii 行、第 jj 列的元素，逐列定义也就是

(A+B)ij=aij+bij,(cA)ij=caij.(A+B)_{ij}=a_{ij}+b_{ij},\qquad(cA)_{ij}=ca_{ij}.

加法要求两个矩阵同尺寸。零矩阵（zero matrix）的每个元素都是零，尺寸由上下文说明；−A=(−1)A-A=(-1)A，A−B=A+(−B)A-B=A+(-B)。方阵中除主对角线外全为零的矩阵叫对角矩阵（diagonal matrix）；主对角线为1、其余元素为0的方阵叫单位矩阵（identity matrix） InI_n。

小例 / Example. 取

P=[120−1],Q=[0131].P=\begin{bmatrix}1&2\\0&-1\end{bmatrix},\qquad Q=\begin{bmatrix}0&1\\3&1\end{bmatrix}.

则 P+Q=[1330]P+Q=\begin{bmatrix}1&3\\3&0\end{bmatrix}，2P=[240−2]2P=\begin{bmatrix}2&4\\0&-2\end{bmatrix}。对于同一输入 𝐱∈ℝn\mathbf x\in\mathbb R^n，把新矩阵的列按 xjx_j 组合，有

(A+B)𝐱=∑jxj(𝐚j+𝐛j)=A𝐱+B𝐱,(cA)𝐱=∑jxj(c𝐚j)=c(A𝐱).(A+B)\mathbf x=\sum_jx_j(\mathbf a_j+\mathbf b_j)=A\mathbf x+B\mathbf x,\qquad (cA)\mathbf x=\sum_jx_j(c\mathbf a_j)=c(A\mathbf x).

这里 A,BA,B 是两个接受同样输入的矩阵，𝐱\mathbf x 提供列组合系数，cc 缩放输出。例如 𝐱=(1,2)𝖳\mathbf x=(1,2)^{\mathsf T} 时，P𝐱=(5,−2)𝖳P\mathbf x=(5,-2)^{\mathsf T}、Q𝐱=(2,5)𝖳Q\mathbf x=(2,5)^{\mathsf T}，其和为 (7,3)𝖳=(P+Q)𝐱(7,3)^{\mathsf T}=(P+Q)\mathbf x。

加法与数乘的规则 Addition and Scaling Rules

教材§2.1，定理1 / Textbook §2.1, Theorem 1.

设 A,B,C∈ℝm×nA,B,C\in\mathbb R^{m\times n}，r,s∈ℝr,s\in\mathbb R，00 是同尺寸的零矩阵。则：

  1. A+B=B+AA+B=B+A。

  2. (A+B)+C=A+(B+C)(A+B)+C=A+(B+C)。

  3. A+0=AA+0=A。

  4. r(A+B)=rA+rBr(A+B)=rA+rB。

  5. (r+s)A=rA+sA(r+s)A=rA+sA。

  6. r(sA)=(rs)Ar(sA)=(rs)A。

定理汇编：教材§2.1，定理1 / Theorem Reference

这些等式逐列继承向量的运算律，也可逐元素核对。例如 (A+B)+C(A+B)+C 与 A+(B+C)A+(B+C) 的第 (i,j)(i,j) 元分别为 (aij+bij)+cij(a_{ij}+b_{ij})+c_{ij} 与 aij+(bij+cij)a_{ij}+(b_{ij}+c_{ij})，由实数加法结合律相等。其余分项用相应实数运算律核对。另有 1A=A1A=A。

从一个向量推广到多列 From One Vector to Several Columns

第一部分的矩阵向量乘法把输入变成列的线性组合；初等行操作让每一列接受同一变换。现在，若许多向量都要接受矩阵 AA 的作用，能否把计算写在一起？

设 A∈ℝm×nA\in\mathbb R^{m\times n}，待作用的向量是 𝐛1,…,𝐛p∈ℝn\mathbf b_1,\ldots,\mathbf b_p\in\mathbb R^n。先分别算出 A𝐛1,…,A𝐛p∈ℝmA\mathbf b_1,\ldots,A\mathbf b_p\in\mathbb R^m，再把这些输出排成列。记 B=[𝐛1⋯𝐛p]∈ℝn×pB=[\mathbf b_1\ \cdots\ \mathbf b_p]\in\mathbb R^{n\times p}，定义矩阵乘积（matrix product）

AB:=[A𝐛1⋯A𝐛p]∈ℝm×p.AB:=[A\mathbf b_1\ \cdots\ A\mathbf b_p]\in\mathbb R^{m\times p}.

内尺寸必须匹配，是因为 BB 的每列必须是 AA 能接受的输入。结果有 mm 行，是因为输出在 ℝm\mathbb R^m；有 pp 列，是因为原来有 pp 个输入。第 jj 列 A𝐛jA\mathbf b_j 是 AA 的各列以 𝐛j\mathbf b_j 的分量为系数的线性组合。这不是对应位置相乘。

逐列计算 / Column Calculation. 沿用矩形例

D=[120−103],F=[10210−1].D=\begin{bmatrix}1&2&0\\-1&0&3\end{bmatrix},\qquad F=\begin{bmatrix}1&0\\2&1\\0&-1\end{bmatrix}.

DD 接受三分量输入。FF 的两列分别给出

D[120]=[5−1],D[01−1]=[2−3].D\begin{bmatrix}1\\2\\0\end{bmatrix}=\begin{bmatrix}5\\-1\end{bmatrix},\qquad D\begin{bmatrix}0\\1\\-1\end{bmatrix}=\begin{bmatrix}2\\-3\end{bmatrix}.

因此 DF=[52−1−3]DF=\begin{bmatrix}5&2\\-1&-3\end{bmatrix}，尺寸为 2×22\times2。

用行与列的点积计算乘积的元素 Computing Product Entries with Row–Column Dot Products

回顾 (A𝐱)i=∑k=1naikxk(A\mathbf x)_i=\sum_{k=1}^n a_{ik}x_k：第 ii 个输出分量是 AA 第 ii 行与输入对应分量相乘后求和。这里的内积／点积（dot product）只指实坐标中的这条计算规则。

令 𝐱=𝐛j\mathbf x=\mathbf b_j，就得到矩阵乘积各元素的计算公式：

(AB)ij=(A𝐛j)i=∑k=1naikbkj.(AB)_{ij}=(A\mathbf b_j)_i=\sum_{k=1}^{n}a_{ik}b_{kj}.

ii 选择 AA 的一行，jj 选择 BB 的一列；kk 遍历中间维数 nn。对刚才的 D,FD,F，四个元素依次是

DF=[1⋅1+2⋅2+0⋅01⋅0+2⋅1+0(−1)(−1)⋅1+0⋅2+3⋅0(−1)⋅0+0⋅1+3(−1)]=[52−1−3].DF=\begin{bmatrix} 1\cdot1+2\cdot2+0\cdot0&1\cdot0+2\cdot1+0(-1)\\ (-1)\cdot1+0\cdot2+3\cdot0&(-1)\cdot0+0\cdot1+3(-1) \end{bmatrix}=\begin{bmatrix}5&2\\-1&-3\end{bmatrix}.

逐列定义和行列点积算出同样的每一列、每一个元素，描述的是同一运算。固定 ii 并让 jj 遍历各列，还可把结果第 ii 行写为 row⁡i(AB)=row⁡i(A)B\operatorname{row}_i(AB)=\operatorname{row}_i(A)B。

矩阵乘法与变换复合 Matrix Multiplication and Composition

现在解释乘积的作用。对 𝐱=(x1,…,xp)𝖳∈ℝp\mathbf x=(x_1,\ldots,x_p)^{\mathsf T}\in\mathbb R^p，先由矩阵向量乘法写出 B𝐱=∑jxj𝐛jB\mathbf x=\sum_jx_j\mathbf b_j，再用 AA 所表示变换的线性性：

A(B𝐱)=A(∑jxj𝐛j)=∑jxjA𝐛j=(AB)𝐱.A(B\mathbf x)=A\left(\sum_jx_j\mathbf b_j\right) =\sum_jx_jA\mathbf b_j=(AB)\mathbf x.

最后一步来自 ABAB 的逐列定义。我们由已有的列组合和线性性推出等式，没有先假定矩阵乘法结合律。

ℝp→Bℝn→Aℝm.\mathbb R^p\ \xrightarrow{\ B\ }\ \mathbb R^n\ \xrightarrow{\ A\ }\ \mathbb R^m.

复合（composition）先做右侧的 BB，再做左侧的 AA，最终由 ABAB 表示。

注记三种描述，同一个乘积 / Three Descriptions, One Product

逐列作用 AB=[A𝐛j]AB=[A\mathbf b_j] 定义整个矩阵；行列点积 (AB)ij=∑kaikbkj(AB)_{ij}=\sum_k a_{ik}b_{kj} 计算元素；(AB)𝐱=A(B𝐱)(AB)\mathbf x=A(B\mathbf x) 说明连续变换的含义。

独立计算 / Independent Practice. 求 FDFD；用 𝐱=(1,2)𝖳\mathbf x=(1,2)^{\mathsf T} 分两步与一步核对 (DF)𝐱=D(F𝐱)(DF)\mathbf x=D(F\mathbf x)。

提示：先写结果尺寸 / Hint: Start with Dimensions

FDFD 的三行可分别看成 DD 两行的组合；F𝐱F\mathbf x 应有三个分量。

完整答案 / Complete Solution

FD=[12014310−3].FD=\begin{bmatrix}1&2&0\\1&4&3\\1&0&-3\end{bmatrix}. 三行分别是 DD 的第一行、两倍第一行加第二行、第二行的相反数。 F𝐱=(1,4,−2)𝖳F\mathbf x=(1,4,-2)^{\mathsf T}，所以 D(F𝐱)=(9,−7)𝖳D(F\mathbf x)=(9,-7)^{\mathsf T}；直接算 DF(1,2)𝖳DF(1,2)^{\mathsf T} 也得 (9,−7)𝖳(9,-7)^{\mathsf T}。这是本例核对，一般等式的理由是上面的线性推导。

矩阵乘法的规则 Rules of Matrix Multiplication

有了复合的解释，就能组织连续运算。每条规则首先要求所写的加法、乘法尺寸合法。

教材§2.1，定理2 / Textbook §2.1, Theorem 2.

设 A∈ℝm×nA\in\mathbb R^{m\times n}，r∈ℝr\in\mathbb R。以下每条各自假设其中的加法和乘法有定义：

  1. A(BC)=(AB)CA(BC)=(AB)C。例如 BB 为 n×pn\times p、CC 为 p×qp\times q。

  2. A(B+C)=AB+ACA(B+C)=AB+AC，其中 B,CB,C 同为 n×pn\times p。

  3. (B+C)A=BA+CA(B+C)A=BA+CA，其中 B,CB,C 同为 p×mp\times m。

  4. r(AB)=(rA)B=A(rB)r(AB)=(rA)B=A(rB)，其中 BB 为 n×pn\times p。

  5. ImA=A=AInI_mA=A=AI_n。

定理汇编：教材§2.1，定理2 / Theorem Reference

结合律改变括号，不改变因子顺序。若 C=[𝐜1⋯𝐜q]C=[\mathbf c_1\ \cdots\ \mathbf c_q]，则 A(BC)A(BC) 的第 jj 列是 A(B𝐜j)A(B\mathbf c_j)；由刚证明的复合等式，它等于 (AB)𝐜j(AB)\mathbf c_j，即 (AB)C(AB)C 的第 jj 列。各列相同，两个矩阵相等。

分配律也可逐列理解：例如 A(B+C)A(B+C) 的第 jj 列是 A(𝐛j+𝐜j)=A𝐛j+A𝐜jA(\mathbf b_j+\mathbf c_j)=A\mathbf b_j+A\mathbf c_j；右分配律则使用已经得到的 (B+C)𝐱=B𝐱+C𝐱(B+C)\mathbf x=B\mathbf x+C\mathbf x。数乘相容性来自 A(r𝐛j)=rA𝐛jA(r\mathbf b_j)=rA\mathbf b_j。左乘 ImI_m 不改任何输出列，右乘 InI_n 的第 jj 列是 A𝐞j=𝐚jA\mathbf e_j=\mathbf a_j，故两侧单位规则成立。

为什么一般不满足交换律？ Why Matrix Multiplication Is Generally Noncommutative

先看尺寸 / Dimensions First. 上例的 DFDF 为 2×22\times2，FDFD 为 3×33\times3。两者都有定义，却连尺寸都不同。交换后也可能根本没有定义。

尺寸自检 / Dimension Check. 若 AA 为 2×32\times3、BB 为 3×43\times4，ABAB 与 BABA 是否都有定义？

答案 / Answer

ABAB 有定义，尺寸为 2×42\times4；BABA 的内尺寸4与2不同，没有定义。

再看元素 / Compare Entries. 即使同阶方阵，行列配对也不同。取水平拉伸矩阵 HH 与水平剪切矩阵 SS：

H=[2001],S=[1101].H=\begin{bmatrix}2&0\\0&1\end{bmatrix},\qquad S=\begin{bmatrix}1&1\\0&1\end{bmatrix}.

行列计算给出

HS=[2201],SH=[2101].HS=\begin{bmatrix}2&2\\0&1\end{bmatrix},\qquad SH=\begin{bmatrix}2&1\\0&1\end{bmatrix}.

例如右上元素分别是 2⋅1+0⋅1=22\cdot1+0\cdot1=2 与 1⋅0+1⋅1=11\cdot0+1\cdot1=1，所以 HS≠SHHS\ne SH。

最后看操作次序 / Interpret the Order. H(u,v)𝖳=(2u,v)𝖳H(u,v)^{\mathsf T}=(2u,v)^{\mathsf T}，S(u,v)𝖳=(u+v,v)𝖳S(u,v)^{\mathsf T}=(u+v,v)^{\mathsf T}。对 𝐞2=(0,1)𝖳\mathbf e_2=(0,1)^{\mathsf T}：

先 S 后 H:(0,1)𝖳↦(1,1)𝖳↦(2,1)𝖳,先 H 后 S:(0,1)𝖳↦(0,1)𝖳↦(1,1)𝖳.\begin{aligned} \text{先 }S\text{ 后 }H:&\quad(0,1)^{\mathsf T}\longmapsto(1,1)^{\mathsf T}\longmapsto(2,1)^{\mathsf T},\\ \text{先 }H\text{ 后 }S:&\quad(0,1)^{\mathsf T}\longmapsto(0,1)^{\mathsf T}\longmapsto(1,1)^{\mathsf T}. \end{aligned}

因此矩阵乘法一般不满足交换律（noncommutative）；不是说任意两个矩阵都不能交换。单位矩阵以及标量矩阵 cIncI_n 都与任意同阶矩阵交换。

选读：泡利矩阵与对易子 / Pauli Matrices and Commutators用两个分量操作比较乘法次序，并练习不交换因子的展开。

不能直接照搬的标量规则 Scalar Rules That Need Conditions

取非零矩阵

N=[1000],K=[0001].N=\begin{bmatrix}1&0\\0&0\end{bmatrix},\qquad K=\begin{bmatrix}0&0\\0&1\end{bmatrix}.

先算再判断 / Calculate and Decide. 计算 NKNK、N(I2+K)N(I_2+K) 和 NI2NI_2。AB=0AB=0 能否推出某个因子为零？AB=ACAB=AC 能否消去 AA 而推出 B=CB=C？

反例与解释 / Counterexamples and Explanation

NK=0NK=0，但两因子都非零。N(I2+K)=N=NI2N(I_2+K)=N=NI_2，却有 I2+K≠I2I_2+K\ne I_2。所以零乘积性质（zero-product property）与消去律（cancellation law）不能无条件照搬。

一般地，AB=ACAB=AC 等价于 A(B−C)=0A(B-C)=0，这表示 B−CB-C 的每一列都属于 Nul⁡(A)\operatorname{Nul}(A)。若 AA 的列线性无关，零空间只有零向量，便能推出 B−C=0B-C=0，即 B=CB=C。这正是第一部分关于零输出表示的唯一性，不需要逆矩阵。

同样，AB=0AB=0 表示 BB 的每列 𝐛j\mathbf b_j 满足 A𝐛j=𝟎A\mathbf b_j=\mathbf0，即属于 Nul⁡(A)\operatorname{Nul}(A)。若 Nul⁡(A)={𝟎}\operatorname{Nul}(A)=\{\mathbf0\}，则由 AB=0AB=0 可推出 B=0B=0；当零空间含非零向量时，可以用它组成非零矩阵 BB 而仍有 AB=0AB=0。

矩阵乘幂与转置 Matrix Powers and Transpose

反复作用与乘幂 Repeated Action and Powers

对 n×nn\times n 方阵 AA，正整数幂 AkA^k 表示 kk 个 AA 相乘，作用于向量就是反复做 kk 次同一变换；约定 A0=InA^0=I_n。这里不引入负整数幂。

设 A,BA,B 为同阶方阵，由左右分配律，

(A+B)2=A2+AB+BA+B2.(A+B)^2=A^2+AB+BA+B^2.

一般不能把中间项写成 2AB2AB，因为尚无 AB=BAAB=BA 的条件。例如上面的 H,SH,S 就不满足这一条件。

行列互换与转置 Interchanging Rows and Columns

转置（transpose）把行列互换：若 AA 为 m×nm\times n，A𝖳A^{\mathsf T} 为 n×mn\times m，且 (A𝖳)ji=aij(A^{\mathsf T})_{ji}=a_{ij}。例如 D𝖳=[1−12003]D^{\mathsf T}=\begin{bmatrix}1&-1\\2&0\\0&3\end{bmatrix}。转置由行列互换定义，一般并不撤销原矩阵对向量的作用。

教材§2.1，定理3 / Textbook §2.1, Theorem 3.

对实矩阵及实数 rr，在各式尺寸相容时：

  1. (AT)T=A(A^T)^T=A。

  2. (A+B)T=AT+BT(A+B)^T=A^T+B^T（A,BA,B 同尺寸）。

  3. (rA)T=rAT(rA)^T=rA^T。

  4. (AB)T=BTAT(AB)^T=B^TA^T（例如 AA 为 m×nm\times n，BB 为 n×pn\times p）。

定理汇编：教材§2.1，定理3 / Theorem Reference

前三式逐元素沿用转置定义。乘积转置为何倒序？若 A:m×nA:m\times n、B:n×pB:n\times p，两侧尺寸都是 p×mp\times m，并且

((AB)𝖳)ji=∑kaikbkj=∑kbkjaik=(B𝖳A𝖳)ji.\bigl((AB)^{\mathsf T}\bigr)_{ji}=\sum_k a_{ik}b_{kj} =\sum_k b_{kj}a_{ik}=\bigl(B^{\mathsf T}A^{\mathsf T}\bigr)_{ji}.

这里只交换了实数因子，没有交换矩阵。对更多因子的乘积，反复使用此规则，转置后的因子次序也完全倒转。

转置把矩阵的行转成列，因而也把行的线性组合问题转成列的线性组合问题；后面定义行空间时会用到这一点。
