Inverse Matrices and Inverse Transformations

本部分导读 / Part Overview · 知识与术语速查 / Concepts and Terminology

从输出恢复输入 Recovering an Input from Its Output

第一部分分别问目标是否在值域中，以及得到它的输入是否唯一。现在固定实方阵 A∈ℝn×nA\in\mathbb R^{n\times n}：能否用同一个矩阵，把每个输出恢复成原输入？若恢复矩阵为 GG，先作用再恢复要求 G(A𝐱)=𝐱G(A\mathbf x)=\mathbf x；先恢复再作用也应能到达任何指定输出，即 A(G𝐛)=𝐛A(G\mathbf b)=\mathbf b。

矩阵 G∈ℝn×nG\in\mathbb R^{n\times n} 若满足 GA=AG=InGA=AG=I_n，称为 AA 的逆矩阵（inverse matrix），记作 A−1A^{-1}；AA 称为可逆（invertible），也称非奇异（nonsingular）。没有逆的方阵称为奇异（singular）。AG=IAG=I 说恢复后的输入确实到达给定输出；GA=IGA=I 说先作用再恢复会得到原输入。

双侧条件各有作用，不能在定义时省掉一侧。这里 InI_n 的主对角线为1，其余元素为0。本主题先讨论同阶方阵；矩形矩阵的单侧关系及方阵何时只检查一侧就够，见可逆矩阵定理。

唯一性 / Uniqueness. 若 G,HG,H 都是 AA 的逆，则 G=GIn=G(AH)=(GA)H=InH=H.G=GI_n=G(AH)=(GA)H=I_nH=H. 所以记号 A−1A^{-1} 没有歧义。这里使用上一主题已经证明的结合律，未交换任何因子。

例：撤销旋转 / Example: Undoing a Rotation. 对第一部分的90度旋转， M=[0−110],G=[01−10],MG=GM=I2.M=\begin{bmatrix}0&-1\\1&0\end{bmatrix},\qquad G=\begin{bmatrix}0&1\\-1&0\end{bmatrix},\qquad MG=GM=I_2. G(p,q)𝖳=(q,−p)𝖳G(p,q)^{\mathsf T}=(q,-p)^{\mathsf T}，正是顺时针90度旋转。例如把输出 (−1,2)𝖳(-1,2)^{\mathsf T} 恢复为 (2,1)𝖳(2,1)^{\mathsf T}。这个具体逆变换由双侧乘积验证；一般线性变换与矩阵的对应将在定理9中完整论证。

教材§2.2，定理5 / Textbook §2.2, Theorem 5

若 A∈ℝn×nA\in\mathbb R^{n\times n} 可逆，则对每个 𝐛∈ℝn\mathbf b\in\mathbb R^n，方程 A𝐱=𝐛A\mathbf x=\mathbf b 有唯一解，且 𝐱=A−1𝐛\mathbf x=A^{-1}\mathbf b。

证明 / Proof. 对任意给定 𝐛∈ℝn\mathbf b\in\mathbb R^n，先验证候选解： A(A−1𝐛)=(AA−1)𝐛=𝐛.A(A^{-1}\mathbf b)=(AA^{-1})\mathbf b=\mathbf b. 若 𝐮\mathbf u 是任意一个解，则 𝐮=(A−1A)𝐮=A−1(A𝐮)=A−1𝐛.\mathbf u=(A^{-1}A)\mathbf u=A^{-1}(A\mathbf u)=A^{-1}\mathbf b. 第一步说明存在，第二步排除其他解，二者不能互相代替。定理汇编 / Theorem Reference。公式说明解的结构；实际计算一个右端时，可以直接消元，通常没有必要先算整个逆。

从一个目标到多个目标 From One Target to Several Targets

设 AA 为 m×nm\times n，把 rr 个未知输入排成 X=[𝐱1⋯𝐱r]∈ℝn×rX=[\mathbf x_1\ \cdots\ \mathbf x_r]\in\mathbb R^{n\times r}，把对应目标排成 F=[𝐟1⋯𝐟r]∈ℝm×rF=[\mathbf f_1\ \cdots\ \mathbf f_r]\in\mathbb R^{m\times r}。由乘法的列定义， AX=F⇔A𝐱j=𝐟j(j=1,…,r).AX=F\quad\Longleftrightarrow\quad A\mathbf x_j=\mathbf f_j\quad(j=1,\ldots,r). 这是同一个系数矩阵的多个方程组；XX 的第 jj 列负责第 jj 个目标。对增广矩阵 [A∣F][A\mid F] 消元，所有目标列必须同步变化。

当 AA 是可逆方阵时，每列唯一，合起来就是 X=A−1FX=A^{-1}F。特别地，取 F=InF=I_n，求 AX=InAX=I_n 就是同时求 nn 个标准单位向量的输入。这解释了求逆与多个目标的联系。下一主题将证明同步消元如何保证得到双侧逆。

独立计算 / Independent Practice. 取 H=[1123],F=[2153].H=\begin{bmatrix}1&1\\2&3\end{bmatrix},\qquad F=\begin{bmatrix}2&1\\5&3\end{bmatrix}. 用同一次消元求 HX=FHX=F，再逐列回代。

提示 / Hint

先做 R2←R2−2R1R_2\leftarrow R_2-2R_1，再清除第二个主元上方的元素；两列目标都要处理。

完整答案 / Complete Solution

[11212353]→[11210111]→[10100111].\left[\begin{array}{rr|rr}1&1&2&1\\2&3&5&3\end{array}\right] \longrightarrow\left[\begin{array}{rr|rr}1&1&2&1\\0&1&1&1\end{array}\right] \longrightarrow\left[\begin{array}{rr|rr}1&0&1&0\\0&1&1&1\end{array}\right]. 因此 X=[1011]X=\begin{bmatrix}1&0\\1&1\end{bmatrix}。两列输入分别为 (1,1)𝖳(1,1)^{\mathsf T}、(0,1)𝖳(0,1)^{\mathsf T}，经 HH 得到 (2,5)𝖳(2,5)^{\mathsf T}、(1,3)𝖳(1,3)^{\mathsf T}；这就是整个矩阵等式 HX=FHX=F 的逐列核对。

一般二阶公式与不可逆分支 The Two-by-Two Formula and the Singular Case

二阶矩阵可以把双侧验证直接算完。设 A=[abcd]A=\begin{bmatrix}a&b\\c&d\end{bmatrix}；数量 ad−bcad-bc 称为它的二阶行列式 / determinant of order two，记作 det⁡A\det A。这里只使用这条二阶定义；一般行列式理论见第三部分。

教材§2.2，定理4 / Textbook §2.2, Theorem 4

设 A=[abcd]A=\begin{bmatrix}a&b\\c&d\end{bmatrix}，a,b,c,d∈ℝa,b,c,d\in\mathbb R。

  • 若 ad−bc≠0ad-bc\ne0，则 AA 可逆，且

    A−1=1ad−bc[d−b−ca]. A^{-1}=\frac1{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}.

  • 若 ad−bc=0ad-bc=0，则 AA 不可逆。

非零分支 / The Nonzero Case. 直接计算 A[d−b−ca]=[d−b−ca]A=[ad−bc00ad−bc].A\begin{bmatrix}d&-b\\-c&a\end{bmatrix} =\begin{bmatrix}d&-b\\-c&a\end{bmatrix}A =\begin{bmatrix}ad-bc&0\\0&ad-bc\end{bmatrix}. 若 ad−bc≠0ad-bc\ne0，除以这个非零标量，两个乘积都成为 I2I_2，因此给出的矩阵确实是逆。

零分支 / The Zero Case. 需要证明不可逆，而不只是指出公式不能除以零。

  • 若 (a,b)≠(0,0)(a,b)\ne(0,0)，取非零向量 𝐡=(−b,a)𝖳\mathbf h=(-b,a)^{\mathsf T}，则 A𝐡=(0,ad−bc)𝖳=𝟎A\mathbf h=(0,ad-bc)^{\mathsf T}=\mathbf0。
  • 若 (a,b)=(0,0)(a,b)=(0,0) 而 (c,d)≠(0,0)(c,d)\ne(0,0)，取 𝐡=(d,−c)𝖳≠𝟎\mathbf h=(d,-c)^{\mathsf T}\ne\mathbf0，仍有 A𝐡=𝟎A\mathbf h=\mathbf0。
  • 若两行均为零，取 𝐡=𝐞1\mathbf h=\mathbf e_1 即可。

所有情形都有非零输入给零输出。若逆存在，就会有 𝐡=A−1A𝐡=𝟎\mathbf h=A^{-1}A\mathbf h=\mathbf0，矛盾。这完成两个分支的证明。定理汇编 / Theorem Reference。

首元素为零的例子 / Example with a Zero First Entry. A0=[0213],det⁡A0=−2,A0−1=[−3/211/20].A_0=\begin{bmatrix}0&2\\1&3\end{bmatrix},\qquad \det A_0=-2,\qquad A_0^{-1}=\begin{bmatrix}-3/2&1\\1/2&0\end{bmatrix}. 公式不要求 a≠0a\ne0。若用消元，先交换两行，再做倍乘和行替换即可；不能一开始就除以零。双侧乘积均为 I2I_2，A0−1(4,7)𝖳=(1,2)𝖳A_0^{-1}(4,7)^{\mathsf T}=(1,2)^{\mathsf T}。后面用同一矩阵讨论换行与LU，提出的是怎样保存操作的新问题。

短练习 / Short Practice. 判断 J=[1224]J=\begin{bmatrix}1&2\\2&4\end{bmatrix} 是否可逆；能否对其四个元素分别取倒数得到逆？

答案与理由 / Answer and Reason

det⁡J=4−4=0\det J=4-4=0，且 J(−2,1)𝖳=𝟎J(-2,1)^{\mathsf T}=\mathbf0，所以不可逆。JJ 不是零矩阵：非零并不保证可逆。逆是针对矩阵乘法定义的，不能逐元素取倒数；也不能把 A−1𝐛A^{-1}\mathbf b 无说明地写成“𝐛/A\mathbf b/A”。

撤销复合时顺序反转 Reversing the Order When Undoing Composition

先做 BB 再做 AA，合起来是 ABAB；恢复输入时先撤销 AA，再撤销 BB。下面把这个顺序与其他逆性质一起写清。

教材§2.2，定理6 / Textbook §2.2, Theorem 6

  1. 若实方阵 AA 可逆，则 A−1A^{-1} 也可逆，且 (A−1)−1=A(A^{-1})^{-1}=A。

  2. 若 A,B∈ℝn×nA,B\in\mathbb R^{n\times n} 都可逆，则 ABAB 可逆，且 (AB)−1=B−1A−1(AB)^{-1}=B^{-1}A^{-1}。

  3. 若实方阵 AA 可逆，则 ATA^T 可逆，且 (AT)−1=(A−1)T(A^T)^{-1}=(A^{-1})^T。

逐项证明 / Proof of Each Part.

  1. AA−1=A−1A=InAA^{-1}=A^{-1}A=I_n 本身也说明 AA 是 A−1A^{-1} 的双侧逆；由唯一性得 (A−1)−1=A(A^{-1})^{-1}=A。

  2. 两个次序都要核对： (AB)(B−1A−1)=A(BB−1)A−1=In,(B−1A−1)(AB)=B−1(A−1A)B=In.\begin{aligned} (AB)(B^{-1}A^{-1})&=A(BB^{-1})A^{-1}=I_n,\\ (B^{-1}A^{-1})(AB)&=B^{-1}(A^{-1}A)B=I_n. \end{aligned} 所以逆为 B−1A−1B^{-1}A^{-1}。同样的论证可逐步用于多个可逆因子。

  3. 对两个恒等式转置，并使用乘积转置的反序规则： AT(A−1)T=(A−1A)T=In,(A−1)TAT=(AA−1)T=In.\begin{aligned} A^T(A^{-1})^T&=(A^{-1}A)^T=I_n,\\ (A^{-1})^TA^T&=(AA^{-1})^T=I_n. \end{aligned} 这说明 (A−1)T(A^{-1})^T 是 ATA^T 的双侧逆。定理汇编 / Theorem Reference。

另一个直接推论是：若 c≠0c\ne0 且 AA 可逆，则 (cA)−1=c−1A−1(cA)^{-1}=c^{-1}A^{-1}，因为两个次序的标量因子都相消成1。这个推论不允许在 c=0c=0 时使用。

练习：撤销旋转与剪切 / Practice: Undoing Rotation and Shear. 沿用 M=[0−110],S=[1101].M=\begin{bmatrix}0&-1\\1&0\end{bmatrix},\qquad S=\begin{bmatrix}1&1\\0&1\end{bmatrix}. 求 (MS)−1(MS)^{-1} 并作双侧验证。

提示 / Hint

MSMS 先剪切再旋转；先撤销旋转再撤销剪切，矩阵写成 S−1M−1S^{-1}M^{-1}。

完整答案 / Complete Solution

S−1=[1−101],M−1=[01−10],S−1M−1=[11−10].S^{-1}=\begin{bmatrix}1&-1\\0&1\end{bmatrix},\quad M^{-1}=\begin{bmatrix}0&1\\-1&0\end{bmatrix},\quad S^{-1}M^{-1}=\begin{bmatrix}1&1\\-1&0\end{bmatrix}. MS=[0−111]MS=\begin{bmatrix}0&-1\\1&1\end{bmatrix}。两个次序的乘积分别为 [0−111][11−10]=I2,[11−10][0−111]=I2.\begin{bmatrix}0&-1\\1&1\end{bmatrix}\begin{bmatrix}1&1\\-1&0\end{bmatrix}=I_2, \qquad \begin{bmatrix}1&1\\-1&0\end{bmatrix}\begin{bmatrix}0&-1\\1&1\end{bmatrix}=I_2.
