L2-01：矩形乘积与复合 Rectangular Products and Composition

独立练习 / Practice Problem

D=[120−103],F=[10210−1].D=\begin{bmatrix}1&2&0\\-1&0&3\end{bmatrix},\qquad F=\begin{bmatrix}1&0\\2&1\\0&-1\end{bmatrix}.

独立计算 / Independent Practice. 求 FDFD；用 𝐱=(1,2)𝖳\mathbf x=(1,2)^{\mathsf T} 分两步与一步核对 (DF)𝐱=D(F𝐱)(DF)\mathbf x=D(F\mathbf x)。

所需知识 / Prerequisites：行列计算 / Entry Formula · 转置与复合 / Transpose and Composition。

提示 / Hint

FDFD 的三行可分别看成 DD 两行的组合；F𝐱F\mathbf x 应有三个分量。

解答与说明 / Solution and Explanation

FD=[12014310−3].FD=\begin{bmatrix}1&2&0\\1&4&3\\1&0&-3\end{bmatrix}. 三行分别是 DD 的第一行、两倍第一行加第二行、第二行的相反数。 F𝐱=(1,4,−2)𝖳F\mathbf x=(1,4,-2)^{\mathsf T}，所以 D(F𝐱)=(9,−7)𝖳D(F\mathbf x)=(9,-7)^{\mathsf T}；直接算 DF(1,2)𝖳DF(1,2)^{\mathsf T} 也得 (9,−7)𝖳(9,-7)^{\mathsf T}。这是本例核对，一般等式的理由见知识链接中的线性推导。

L2-02：乘积的转置 Transpose of a Product

独立练习 / Practice Problem

D=[120−103],F=[10210−1].D=\begin{bmatrix}1&2&0\\-1&0&3\end{bmatrix},\qquad F=\begin{bmatrix}1&0\\2&1\\0&-1\end{bmatrix}.

动笔 / Practice. 用 D,FD,F 写出 (DF)𝖳(DF)^{\mathsf T} 和 F𝖳D𝖳F^{\mathsf T}D^{\mathsf T}，注明尺寸。

所需知识 / Prerequisites：行列计算 / Entry Formula · 转置与复合 / Transpose and Composition。

提示 / Hint

先写出 F𝖳F^{\mathsf T} 的两行与 D𝖳D^{\mathsf T} 的两列，再用行列点积核对。

解答与说明 / Solution and Explanation

F𝖳D𝖳=[12001−1][1−12003]=[5−12−3]=(DF)𝖳.F^{\mathsf T}D^{\mathsf T}=\begin{bmatrix}1&2&0\\0&1&-1\end{bmatrix} \begin{bmatrix}1&-1\\2&0\\0&3\end{bmatrix} =\begin{bmatrix}5&-1\\2&-3\end{bmatrix}=(DF)^{\mathsf T}. 右侧两个因子分别为 2×32\times3、3×23\times2，乘积为 2×22\times2。这是一般公式的一次数值核对。

L2-03：对角缩放与交换性 Diagonal Scaling and Commutativity

独立练习 / Practice Problem

本题 D=diag⁡(2,−1)D=\operatorname{diag}(2,-1)。

短练习 / Quick Practice. 对上面的 DD，将 AA 换成 [0110]\begin{bmatrix}0&1\\1&0\end{bmatrix}，比较 DA,ADDA,AD。若两个因子都是同阶对角矩阵，乘积是什么结构，能否交换次序？

所需知识 / Prerequisites：行列计算 / Entry Formula · 转置与复合 / Transpose and Composition。

提示 / Hint

先写清对象与条件，再用所学定义或等价变形检验结论。

解答与说明 / Solution and Explanation

DA=[02−10],AD=[0−120].DA=\begin{bmatrix}0&2\\-1&0\end{bmatrix},\qquad AD=\begin{bmatrix}0&-1\\2&0\end{bmatrix}. 两者不等。若另一个因子为 C=diag⁡(c1,…,cn)C=\operatorname{diag}(c_1,\ldots,c_n)，则 DC=diag⁡(d1c1,…,dncn)=CDDC=\operatorname{diag}(d_1c_1,\ldots,d_nc_n)=CD。同阶对角矩阵相乘仍为对角且彼此可交换，不表示对角矩阵与任意矩阵都可交换。

L2-04：旋转与剪切 Rotation and Shear

典型例题与练习 / Worked Example and Practice

复用线性变换主题的逆时针 90∘90^\circ 旋转矩阵 MM，配一个水平剪切（shear）SS：

M=[0−110],S=[1101],S(x,y)𝖳=(x+y,y)𝖳.M=\begin{bmatrix}0&-1\\1&0\end{bmatrix},\quad S=\begin{bmatrix}1&1\\0&1\end{bmatrix},\quad S(x,y)^{\mathsf T}=(x+y,y)^{\mathsf T}.

求 MS,SMMS,SM，对 𝐯=(2,1)𝖳\mathbf v=(2,1)^{\mathsf T} 比较两条复合路径。再对 𝐞1=(1,0)𝖳\mathbf e_1=(1,0)^{\mathsf T} 比较；为什么两乘积都有定义不代表相等？

所需知识 / Prerequisites：行列计算 / Entry Formula · 转置与复合 / Transpose and Composition。

提示 / Hint

最右因子先作用；分别记录中间向量与最终向量。

解答与说明 / Solution and Explanation

MS=[0−111],SM=[1−110].MS=\begin{bmatrix}0&-1\\1&1\end{bmatrix},\qquad SM=\begin{bmatrix}1&-1\\1&0\end{bmatrix}.

对第一部分的 𝐯=(2,1)𝖳\mathbf v=(2,1)^{\mathsf T}，先剪切再旋转是 (2,1)→(3,1)→(−1,3)(2,1)\to(3,1)\to(-1,3)；先旋转再剪切是 (2,1)→(−1,2)→(1,2)(2,1)\to(-1,2)\to(1,2)。

对单位输入的核对见下一段。

解答与说明 / Solution and Explanation

MS𝐞1=(0,1)𝖳MS\mathbf e_1=(0,1)^{\mathsf T}，SM𝐞1=(1,1)𝖳SM\mathbf e_1=(1,1)^{\mathsf T}。尺寸只保证运算合法；即使同为二阶方阵，作用次序也会改变列的像。不能为了计算方便把 MSMS 写成 SMSM。

E04：特殊矩阵乘法与求逆 Special Products and Inversion

典型例题 / Worked Example

典型例题 / Worked Example（基础 / Basic）. 取 U=[120013001],V=[20103−1004].U=\begin{bmatrix}1&2&0\\0&1&3\\0&0&1\end{bmatrix},\qquad V=\begin{bmatrix}2&0&1\\0&3&-1\\0&0&4\end{bmatrix}. 求 UVUV，解释它为何仍为上三角；再对 D=diag⁡(2,3,4)D=\operatorname{diag}(2,3,4) 比较 DUDU 与 UDUD。本例为课程自编；观察结构再计算的思路也可见 Harvard Math 21b，2017 第二次期中考试，此处只用已经学过的矩阵乘法。

所需知识 / Prerequisites：元素公式 / Entry Formula · 对角缩放 / Diagonal Scaling · 三角结构的证明 / Triangular Structure。

解答与说明 / Solution and Explanation

先看零元素，再计算 / Use the Zeros before Calculating. 两矩阵均为上三角，可先定位每个行列点积中可能非零的项。代表元素为 (UV)12=1⋅0+2⋅3+0⋅0=6,(UV)13=1⋅1+2⋅(−1)+0⋅4=−1,(UV)23=0⋅1+1⋅(−1)+3⋅4=11.\begin{aligned} (UV)_{12}&=1\cdot0+2\cdot3+0\cdot0=6,\\ (UV)_{13}&=1\cdot1+2\cdot(-1)+0\cdot4=-1,\\ (UV)_{23}&=0\cdot1+1\cdot(-1)+3\cdot4=11. \end{aligned} 对角元分别为 2,3,42,3,4；主对角线下方每个点积项都为零，例如 (UV)31=0⋅2+0⋅0+1⋅0=0(UV)_{31}=0\cdot2+0\cdot0+1\cdot0=0。因此 UV=[26−10311004].UV=\begin{bmatrix}2&6&-1\\0&3&11\\0&0&4\end{bmatrix}. 按列再核对第三列：U(1,−1,4)𝖳=(−1,11,4)𝖳U(1,-1,4)^{\mathsf T}=(-1,11,4)^{\mathsf T}，与计算一致。

由前面的对角缩放规则， DU=[240039004],UD=[2600312004].DU=\begin{bmatrix}2&4&0\\0&3&9\\0&0&4\end{bmatrix},\qquad UD=\begin{bmatrix}2&6&0\\0&3&12\\0&0&4\end{bmatrix}. 左乘把三行分别乘 2,3,42,3,4，右乘把三列分别乘 2,3,42,3,4。例如 (DU)12=2u12=4(DU)_{12}=2u_{12}=4，(UD)12=3u12=6(UD)_{12}=3u_{12}=6，所以两者不相等。结构帮助减少运算，但不允许交换因子。

E04：同步求逆 Simultaneous Inversion

典型例题 / Worked Example

先完成乘法阶段 / Product Stage；学过同步消元求逆后再完成本阶段。

基础；课程自编 / Basic; Course-Designed. 对特殊矩阵乘积例 / Special-Matrix Products中的 U=[120013001],U=\begin{bmatrix}1&2&0\\0&1&3\\0&0&1\end{bmatrix}, 按 [U∣I3][U\mid I_3] 方法求逆并验证。将未知矩阵 X=[𝐱1𝐱2𝐱3]X=[\mathbf x_1\ \mathbf x_2\ \mathbf x_3] 代入 UX=I3UX=I_3，就是同时求 U𝐱j=𝐞jU\mathbf x_j=\mathbf e_j，j=1,2,3j=1,2,3。
