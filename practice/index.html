例题与练习汇编：使用说明与索引

Examples and Exercises: Guide and Index

怎样使用 How to Use This Collection

本汇编目前覆盖第一、二部分的例题与练习。先读完整题面并独立作答，再按需要展开“提示 / Hint”和“解答与说明 / Solution and Explanation”。每题的知识链接可回查具体概念、算法或教材定理；浏览器后退可回到原题。

E、P、L1/L2 是题组编号。E01、E02、E04 按阶段阅读；E03 的第一、二阶段分别在两部分。选择方法题的详细链接放在折叠的“知识回顾 / Knowledge Review”中。概念引入所需的示例和随文短检查仍在学习主题。

来源按课程自编、既有训练或题型改编分别标明。改编题不等同于原卷题目，题目也不代表本课程的考试范围。
