L1-01：线性系统的表示 Representing Linear Systems

独立练习 / Practice Problem

本题中的原两式为 {2x−y=0,−x+2y=3.\left\{\begin{aligned}2x-y&=0,\\-x+2y&=3.\end{aligned}\right.

先独立完成，再展开答案核对。

  1. 以 x,yx,y 为未知数，3x−2y=53x-2y=5、xy=5xy=5、x2−y=0x^2-y=0 哪些是线性方程？

  2. 按 x,y,zx,y,z 顺序，把下面的方程组写成系数矩阵与增广矩阵：

    {x−3z=2,−y+z=−1.\left\{\begin{aligned} x-3z&=2,\\ -y+z&=-1. \end{aligned}\right.

  3. 按 u,vu,v 顺序，将下面的增广矩阵还原为方程组。若只给前两列，缺什么信息？

    [0−2410−1].\left[\begin{array}{rr|r}0&-2&4\\1&0&-1\end{array}\right].

  4. 判断 (0,0)(0,0)、(1,2)(1,2)、(3,3)(3,3) 是否为开头两式的解。再说明“三个方程、五个未知数”的候选答案需要几个数。

所需知识 / Prerequisites：缺项与增广矩阵 / Missing Terms and Augmented Matrices · 方程与合法操作 / Equations and Operations。

提示 / Hint

先写清对象与条件，再用所学定义或等价变形检验结论。

解答与说明 / Solution and Explanation

  1. 只有 3x−2y=53x-2y=5 是线性的；另两式分别含未知数乘积和平方。

  2. A=[10−30−11]A=\left[\begin{smallmatrix}1&0&-3\\0&-1&1\end{smallmatrix}\right]，增广矩阵为 [10−320−11−1]\left[\begin{array}{rrr|r}1&0&-3&2\\0&-1&1&-1\end{array}\right]。零不能省，第二行首项为零，yy 系数为 −1-1，等号右边的常数也为 −1-1。

  3. 方程组为

    {−2v=4,u=−1.\left\{\begin{aligned} -2v&=4,\\ u&=-1. \end{aligned}\right.

    仅有系数矩阵不能知道各方程右边的常数 4,−14,-1；反向转写还需固定未知数顺序。

解答与说明 / Solution and Explanation

三个点使两式左边依次为 (0,0)(0,0)、(0,3)(0,3)、(3,3)(3,3)，只有 (1,2)(1,2) 同时给出所需的 (0,3)(0,3)。 五个未知数的候选答案需要五个数；三个方程给出三项检查，不把答案改成三元组。

E01：一次消元与解集 One Elimination and Solution Sets

典型例题 / Worked Example

先学消元即可完成本阶段；学过列组合与特解后，再做后半题 / Second Stage。

综合 / Integrated. 给定 A=[121250363],𝐛=[13k],k∈ℝ.A=\begin{bmatrix}1&2&1\\2&5&0\\3&6&3\end{bmatrix},\qquad \mathbf b=\begin{bmatrix}1\\3\\k\end{bmatrix},\quad k\in\mathbb R. 求 AA 的 REF、RREF，并判断 A𝐱=𝐛A\mathbf x=\mathbf b 何时有解。参考 Berkeley Math 54，2020 第一次期中考试第2题的题型改编；矩阵、参数右端和以下追问均已调整。

所需知识 / Prerequisites：相容性与读解 / Consistency and Solutions · 教材§1.2定理2 / Theorem 2。

解答与说明 / Solution and Explanation

方法选择 / Choosing a Method. 参数只在方程右端目标向量中，因此对增广矩阵做一次消元，就能同时看清系数结构和相容条件。先依次做 R2←R2−2R1R_2\leftarrow R_2-2R_1、R3←R3−3R1R_3\leftarrow R_3-3R_1，消去第一列下方： [A∣𝐛]→[121101−21000k−3].[A\mid\mathbf b]\longrightarrow \left[\begin{array}{rrr|r}1&2&1&1\\0&1&-2&1\\0&0&0&k-3\end{array}\right]. 系数部分已经是 REF。最后一行要求 0=k−30=k-3，所以当且仅当 k=3k=3 时相容。当 k≠3k\ne3 时，无须为求解继续化简；上述增广矩阵尚不是 RREF。

当 k=3k=3 时，两个系数主元已为1，向后阶段只需清除第二个主元上方的元素： [121101−210000]→R1←R1−2R2[105−101−210000].\left[\begin{array}{rrr|r}1&2&1&1\\0&1&-2&1\\0&0&0&0\end{array}\right] \xrightarrow{R_1\leftarrow R_1-2R_2} \left[\begin{array}{rrr|r}1&0&5&-1\\0&1&-2&1\\0&0&0&0\end{array}\right]. 故 RREF⁡(A)=[10501−2000]\operatorname{RREF}(A)=\begin{bmatrix}1&0&5\\0&1&-2\\0&0&0\end{bmatrix}。取 x3=rx_3=r，全部解为 𝐱=[−1−5r1+2rr],r∈ℝ.\mathbf x=\begin{bmatrix}-1-5r\\1+2r\\r\end{bmatrix},\qquad r\in\mathbb R. 代回三行分别得到 1,3,31,3,3，与相容时的目标一致。由于固定系数矩阵始终只有两个主元，相容时总有自由变量 x3x_3，不会因改变 kk 突然出现唯一解；这里用的正是教材§1.2定理2。

学过列组合和特解后，继续用同一个矩阵求齐次解与不同目标的全部解 / Homogeneous and Nonhomogeneous Solutions，无需重复整段消元。

核对与完整性 / Verification and Completeness. A𝐡=[−5+4+1−10+10−15+12+3]=𝟎,A𝐞1=[123].A\mathbf h=\begin{bmatrix}-5+4+1\\-10+10\\-15+12+3\end{bmatrix}=\mathbf0,\qquad A\mathbf e_1=\begin{bmatrix}1\\2\\3\end{bmatrix}. 线性性保证任意 rr 都给出解；反过来任意解减去 𝐞1\mathbf e_1 都是齐次解，所以必为 r𝐡r\mathbf h。这两个方向既检查算式，也说明没有漏解。独立练习见系数也含参数时的三种解型 / Three Solution Types with a Parameterized Matrix。

P01：系数与目标都含参数 Parameters in Coefficients and Target

独立练习 / Practice Problem

综合；课程自编 / Integrated; Course-Designed. 对任意实数 t,kt,k，判断以下方程组何时有唯一解、无解或无穷多解，并写出有解时的全部解： {x1+x2+x3=1,x1+2x2+3x3=2,2x1+3x2+(4+t)x3=k.\left\{\begin{aligned} x_1+x_2+x_3&=1,\\ x_1+2x_2+3x_3&=2,\\ 2x_1+3x_2+(4+t)x_3&=k. \end{aligned}\right.

所需知识 / Prerequisites：相容性与自由变量 / Consistency and Free Variables · 教材§1.2定理2 / Theorem 2。
