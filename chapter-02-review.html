典型例题：判断行变换保持的对象 Worked Example: What Row Operations Preserve

综合 / Integrated. 已学过基、秩和行空间后，继续第一部分的二维反例 / The Two-Dimensional Counterexample。参考Berkeley 2020第一次期中考试第1题的判断题型；以下归纳及追问为课程补充。

设 A,F∈ℝm×nA,F\in\mathbb R^{m\times n}，FF 由 AA 经有限次初等行变换得到。请先判断以下六项是否保持，并各给一句理由，再对照解析。

解答与说明 / Solution and Explanation
对象 / Object 判断与理由 / Verdict and Reason
秩 / Rank 保持。行变换保持同一组列之间的全部线性关系，因此保持最大无关列数，也就保持列空间维数。
零空间 / Null Space 作为 ℝn\mathbb R^n 中的集合保持。零目标始终变为零，每一步都可恢复，故齐次方程双向等价。
行空间 / Row Space 作为 ℝn\mathbb R^n 中的集合保持。新行是旧行的组合，得一个包含；用恢复操作得相反包含。
列空间 / Column Space 作为 ℝm\mathbb R^m 中的集合一般不保持。第一部分反例的 {(c,c)𝖳}\{(c,c)^{\mathsf T}\} 变为 {(c,0)𝖳}\{(c,0)^{\mathsf T}\}，但两者维数都为1。
列之间的线性关系 / Relations among Columns 同一组关系系数保持。例如 ∑cj𝐚j=𝟎\sum c_j\mathbf a_j=\mathbf0 当且仅当 ∑cj𝐟j=𝟎\sum c_j\mathbf f_j=\mathbf0，由线性性及可恢复性得到。
非齐次方程的解集 / Nonhomogeneous Solution Set 目标也接受同一串操作时保持。若总操作矩阵为可逆 G∈ℝm×mG\in\mathbb R^{m\times m}，则 A𝐱=𝐛⇔F𝐱=G𝐛A\mathbf x=\mathbf b\iff F\mathbf x=G\mathbf b；不能一般写成 F𝐱=𝐛F\mathbf x=\mathbf b。

集合、维数、关系系数分别是什么 / Sets, Dimensions, and Relation Coefficients. 列空间中的元素是输出向量，列关系的系数向量在输入空间中。前者可能改变，而后者保持；维数相等只表示独立方向的数目相同。完整一般理由可回查行空间双向包含 / Row-Space Equality及四空间中的行变换 / Row Operations and the Four Spaces。

同一次消元回答哪些问题？ What Can One Elimination Tell Us?

矩阵运算描述线性变换怎样相加、缩放和复合；消元与矩阵分解既用于求解，也揭示列之间的关系。基、维数和四个基本子空间进一步解释这些关系：哪些方程右端目标向量能够达到，哪些输入差别不改变输出，行之间的关系又施加了什么相容性条件。对方阵，可逆矩阵定理将这些认识联系起来。

下面先用一个矩形矩阵综合求解与空间结构，再比较给定目标与任意目标的判据。它能帮助我们看清方阵可逆性结论所需的前提，而不把矩形情况也合并为同一判断。

从一个矩阵读出解与关系 Solutions and Relations from One Matrix

取熟悉的矩形矩阵 A=[120100111212],𝐛=(p,q,s)𝖳.A=\begin{bmatrix}1&2&0&1\\0&0&1&1\\1&2&1&2\end{bmatrix},\qquad\mathbf b=(p,q,s)^{\mathsf T}. 依次做 R3←R3−R1R_3\leftarrow R_3-R_1、R3←R3−R2R_3\leftarrow R_3-R_2。请回答：

  1. 当前方程组何时有解？有解时是否唯一，有几个自由变量？
  2. 哪些原列构成基？其余列怎样表示？写出CR分解。
  3. 写出行空间、列空间、零空间和左零空间的基、环境空间与维数。
  4. 哪条行关系限制了 𝐛\mathbf b？换一个目标向量时，哪些结果可复用？
分步提示 / Step-by-Step Hints

先看增广最后一行，再看系数主元列1、3。CR的 CC 取原列；RR 只取完整RREF的非零行。齐次解取自由变量 x2,x4x_2,x_4；左零空间可从第三行是前两行之和读出。

完整解答 / Full Solution

[A∣𝐛]→[1201p0011q0000s−p−q].[A\mid\mathbf b]\ \longrightarrow\ \left[\begin{array}{cccc|c}1&2&0&1&p\\0&0&1&1&q\\0&0&0&0&s-p-q\end{array}\right]. 相容当且仅当 s=p+qs=p+q。相容时有两个自由变量，全部解为 𝐱=(p−2u−v,u,q−v,v)𝖳,u,v∈ℝ.\mathbf x=(p-2u-v,u,q-v,v)^{\mathsf T},\qquad u,v\in\mathbb R. 原列1、3独立，𝐚2=2𝐚1,𝐚4=𝐚1+𝐚3\mathbf a_2=2\mathbf a_1,\mathbf a_4=\mathbf a_1+\mathbf a_3，所以 A=[100111][12010011]=CR.A=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}\begin{bmatrix}1&2&0&1\\0&0&1&1\end{bmatrix}=CR. 列空间基为 (1,0,1)𝖳,(0,1,1)𝖳(1,0,1)^{\mathsf T},(0,1,1)^{\mathsf T}，在 ℝ3\mathbb R^3 中维数2；行空间基为 (1,2,0,1)𝖳,(0,0,1,1)𝖳(1,2,0,1)^{\mathsf T},(0,0,1,1)^{\mathsf T}，在 ℝ4\mathbb R^4 中维数2。零空间基为 (−2,1,0,0)𝖳,(−1,0,−1,1)𝖳(-2,1,0,0)^{\mathsf T},(-1,0,-1,1)^{\mathsf T}，在 ℝ4\mathbb R^4 中维数2；左零空间基为 (−1,−1,1)𝖳(-1,-1,1)^{\mathsf T}，在 ℝ3\mathbb R^3 中维数1。

行关系 −R1−R2+R3=0-R_1-R_2+R_3=0 要求 −p−q+s=0-p-q+s=0。固定 AA 后，四空间、CR以及操作矩阵 G=[100010−1−11]G=\begin{bmatrix}1&0&0\\0&1&0\\-1&-1&1\end{bmatrix} 均可复用；只需计算变换后的目标向量 G𝐛G\mathbf b 并读解。若保留前向消元的因子，也有 A=LFA=LF，其中 L=G−1=[100010111]L=G^{-1}=\begin{bmatrix}1&0&0\\0&1&0\\1&1&1\end{bmatrix}。本例 U=FU=F 恰已是RREF，一般LU中的 UU 不必如此。本例 LL 的前两列也恰好等于 CC；一般只有截取因子后的列空间关系，不能认定因子的列就是原主元列。

给定目标向量与任意目标向量：秩判据 Rank Criteria for a Given or Arbitrary Target Vector

设 A∈ℝm×nA\in\mathbb R^{m\times n}，r=rank⁡Ar=\operatorname{rank}A。先明确量词，再翻译成主元或空间语言。

问题 / Question 判据 / Criterion 理由 / Reason
给定 𝐛\mathbf b 是否有解？ / A given target vector rank⁡[A∣𝐛]=r\operatorname{rank}[A\mid\mathbf b]=r 常数列不新增主元，等价于无矛盾行，也等价于 𝐛∈Col⁡A\mathbf b\in\operatorname{Col}A
相容时是否唯一？ / Uniqueness when consistent r=nr=n 零空间只有零向量，变换为单射；否则零空间有 n−rn-r 个自由方向，给出无穷多解
每个 𝐛∈ℝm\mathbf b\in\mathbb R^m 都有解？ / Every target vector r=mr=m 列空间等于整个陪域，变换为满射；左零空间为零，没有行关系限制目标向量
方阵是否可逆？ / Invertibility of a square matrix m=nm=n 且 r=nr=n 每行、每列都有主元，任意目标向量对应的方程组都唯一可解

第一行可从任一阶梯化理解：若消元后的常数列在系数部分零行处出现非零元素，就新增一个主元，增广秩比 rr 大1；否则不新增主元。第二行必须先有相容性，不能仅凭列无关断言当前有解。对任意目标向量“至多一个解”要求 r=nr=n，允许某些目标向量对应的方程组无解；“至少一个解”要求 r=mr=m，允许多个解。长方形矩阵的“满行秩”和“满列秩”须分清。

相容性还可由左零空间条件判断；其双向证明来自消元，不需提前使用正交补。第一部分的两张综合表仍按原语言成立，这里用空间及其维数解释原来的存在性与唯一性。求解 A𝐱=𝐛A\mathbf x=\mathbf b 就是寻找 𝐛\mathbf b 的列组合系数，也就是寻找在线性变换 TAT_A 下以 𝐛\mathbf b 为像的输入；列空间回答能否找到，零空间回答找到后能否改变输入而保持输出，左零空间则从行关系给出相容性条件。对方阵，这些联系汇合为四空间中的可逆性。

RREF、LU与CR怎样组织同一矩阵？ How Do RREF, LU, and CR Organize the Same Matrix?

形式 / Form 表达的结构 / Structure 主要用途 / Use
GA=FGA=F，FF为完整RREF 规范的主元位置、变量及列关系；GG可另记录操作 读全部解，判断相容，证明规范形式唯一
A=LUA=LU 或 PA=LUPA=LU 前向消元乘子和阶梯形 UU 对不同目标向量反复前代、回代
A=CRA=CR 原独立列与所有列的坐标 表示、重建矩阵，理解秩及列关系

RREF不是把原列空间原样留下；LU不要求把主元归一或清上方；CR的 RR 不含完整RREF的零行。在CR中，R𝐱R\mathbf x 是输出相对于 CC 的列基的坐标；用可达性与输入不唯一练习检查这一区别。三者来自相关的消元知识，却回答不同问题。分块则是组织同一矩阵的行列，不是第四种分解。

典型例题：从LU到CR与全部解 Worked Example: From LU to CR and All Solutions

综合 / Integrated. 对实矩阵 M=[120124141225]M=\begin{bmatrix}1&2&0&1\\2&4&1&4\\1&2&2&5\end{bmatrix} 依次完成：记录消元乘子并构造 M=LUM=LU；求RREF、主元列、秩与自由变量；从原列选择 CC 并写 M=CRM=CR；求零空间的一组基；当目标为四列之和时给出特解及全部解；最后比较三个因子的空间。

题型改编自 MIT 18.06，2010 Final Exam第1题：本题改变第三行，CR、坐标解释和空间比较为课程新增追问。
