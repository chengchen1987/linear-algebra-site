第二部分 · 综合复习

Part 2: Review Problems

同一次消元回答哪些问题？ What Can One Elimination Tell Us?

矩阵运算、求逆与LU解决怎样计算和复用的问题；秩、CR与四空间解释独立关系和相容性。把它们放回同一个方程组，能够同时看清“当前右端是否可达”和“所有右端是否都可达”的区别。先独立完成下面的综合例，再用后面的判据整理理由。

从一个矩阵读出解与关系 Solutions and Relations from One Matrix

取熟悉的矩形矩阵 A=[120100111212],𝐛=(p,q,s)𝖳.A=\begin{bmatrix}1&2&0&1\\0&0&1&1\\1&2&1&2\end{bmatrix},\qquad\mathbf b=(p,q,s)^{\mathsf T}. 依次做 R3←R3−R1R_3\leftarrow R_3-R_1、R3←R3−R2R_3\leftarrow R_3-R_2。请回答：

  1. 当前方程组何时有解？有解时是否唯一，有几个自由变量？
  2. 哪些原列构成基？其余列怎样表示？写出CR分解。
  3. 写出行空间、列空间、零空间和左零空间的基、环境空间与维数。
  4. 哪条行关系限制了 𝐛\mathbf b？换一组右端时，哪些结果可复用？
分步提示 / Step-by-Step Hints

先看增广最后一行，再看系数主元列1、3。CR的 CC 取原列；RR 只取完整RREF的非零行。齐次解取自由变量 x2,x4x_2,x_4；左零空间可从第三行是前两行之和读出。

完整答案 / Full Solution

[A∣𝐛]→[1201p0011q0000s−p−q].[A\mid\mathbf b]\ \longrightarrow\ \left[\begin{array}{cccc|c}1&2&0&1&p\\0&0&1&1&q\\0&0&0&0&s-p-q\end{array}\right]. 相容当且仅当 s=p+qs=p+q。相容时有两个自由变量，全部解为 𝐱=(p−2u−v,u,q−v,v)𝖳,u,v∈ℝ.\mathbf x=(p-2u-v,u,q-v,v)^{\mathsf T},\qquad u,v\in\mathbb R. 原列1、3独立，𝐚2=2𝐚1,𝐚4=𝐚1+𝐚3\mathbf a_2=2\mathbf a_1,\mathbf a_4=\mathbf a_1+\mathbf a_3，所以 A=[100111][12010011]=CR.A=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}\begin{bmatrix}1&2&0&1\\0&0&1&1\end{bmatrix}=CR. 列空间基为 (1,0,1)𝖳,(0,1,1)𝖳(1,0,1)^{\mathsf T},(0,1,1)^{\mathsf T}，在 ℝ3\mathbb R^3 中维数2；行空间基为 (1,2,0,1)𝖳,(0,0,1,1)𝖳(1,2,0,1)^{\mathsf T},(0,0,1,1)^{\mathsf T}，在 ℝ4\mathbb R^4 中维数2。零空间基为 (−2,1,0,0)𝖳,(−1,0,−1,1)𝖳(-2,1,0,0)^{\mathsf T},(-1,0,-1,1)^{\mathsf T}，在 ℝ4\mathbb R^4 中维数2；左零空间基为 (−1,−1,1)𝖳(-1,-1,1)^{\mathsf T}，在 ℝ3\mathbb R^3 中维数1。

行关系 −R1−R2+R3=0-R_1-R_2+R_3=0 要求 −p−q+s=0-p-q+s=0。固定 AA 后，四空间、CR以及操作矩阵 G=[100010−1−11]G=\begin{bmatrix}1&0&0\\0&1&0\\-1&-1&1\end{bmatrix} 均可复用；只需计算新 G𝐛G\mathbf b 并读解。若保留前向消元的因子，也有 A=LFA=LF，其中 L=G−1=[100010111]L=G^{-1}=\begin{bmatrix}1&0&0\\0&1&0\\1&1&1\end{bmatrix}。本例 U=FU=F 恰已是RREF，一般LU中的 UU 不必如此。

给定右端与所有右端：秩判据 Rank Criteria for a Given or Every Right-Hand Side

设 A∈ℝm×nA\in\mathbb R^{m\times n}，r=rank⁡Ar=\operatorname{rank}A。先明确量词，再翻译成主元或空间语言。

问题 / Question 判据 / Criterion 理由 / Reason
给定 𝐛\mathbf b 是否有解？ / A given right-hand side rank⁡[A∣𝐛]=r\operatorname{rank}[A\mid\mathbf b]=r 常数列不新增主元，等价于无矛盾行，也等价于 𝐛∈Col⁡A\mathbf b\in\operatorname{Col}A
相容时是否唯一？ / Uniqueness when consistent r=nr=n 没有自由变量；否则有 n−rn-r 个自由变量和无穷多解
每个 𝐛∈ℝm\mathbf b\in\mathbb R^m 都有解？ / Every right-hand side r=mr=m 每行有主元，列空间等于整个陪域
方阵是否可逆？ / Invertibility of a square matrix m=nm=n 且 r=nr=n 每行、每列都有主元，所有右端都唯一可解

第一行可从任一阶梯化理解：若消元后的常数列在系数部分零行处出现非零元素，就新增一个主元，增广秩比 rr 大1；否则不新增主元。第二行必须先有相容性，不能仅凭列无关断言当前有解。对所有右端“至多一个解”要求 r=nr=n，允许某些右端无解；“至少一个解”要求 r=mr=m，允许多个解。长方形矩阵的“满行秩”和“满列秩”须分清。

相容性还可由左零空间条件判断；其双向证明来自消元，不需提前使用正交补。第一部分的两张综合表仍按原语言成立，这里增加的是基和维数的计数方式。

RREF、LU与CR各保存什么？ What Do RREF, LU and CR Preserve?

形式 / Form 保存的信息 / Information 主要用途 / Use
GA=FGA=F，FF为完整RREF 规范的主元位置、变量及列关系；GG可另记录操作 读全部解，判断相容，证明规范形式唯一
A=LUA=LU 或 PA=LUPA=LU 前向消元乘子和阶梯形 UU 对不同右端反复前代、回代
A=CRA=CR 原独立列与所有列的坐标 表示、重建矩阵，理解秩及列关系

RREF不是把原列空间原样留下；LU不要求把主元归一或清上方；CR的 RR 不含完整RREF的零行。三者来自相关的消元知识，却回答不同问题。分块则是组织同一矩阵的行列，不是第四种分解。

独立复习题 Independent Review Problems

  1. 为什么 AB=ACAB=AC 一般不能约去 AA？给出一个足够条件和理由。
  2. 为什么求逆可以转化为多个方程组共用同一组行变换？怎样说明结果是双侧逆？
  3. 对LU主题的矩阵 AA，复用LU求右端 (1,2,−1)𝖳(1,2,-1)^{\mathsf T} 的解，写前代回代。
  4. 说明“方阵每行有非零元素”与“每行有主元”的区别，给反例。
完整答案 / Full Solution
  1. 取 A=diag⁡(1,0)A=\operatorname{diag}(1,0)、B=I2B=I_2、C=diag⁡(1,2)C=\operatorname{diag}(1,2)，AB=ACAB=AC 而 B≠CB\ne C。若 AA 列无关，逐列 A(𝐛j−𝐜j)=0A(\mathbf b_j-\mathbf c_j)=0 强迫差为零，足以消去；可逆方阵是特例。
  2. AB=InAB=I_n 的列方程是 A𝐛j=𝐞jA\mathbf b_j=\mathbf e_j，系数矩阵相同、右端向量不同，所以把它们并成 [A∣In][A\mid I_n] 同步消元。若左侧化为 InI_n，记总行操作矩阵为 GG，则 GA=InGA=I_n。GG 是可逆初等矩阵的乘积，故 A=G−1A=G^{-1}，也有 AG=InAG=I_n；右侧的 GG 就是 A−1A^{-1}。详见完整推导。
  3. LL 前代给 y1=1,y2=2−2=0,y3=−1+1−0=0y_1=1,y_2=2-2=0,y_3=-1+1-0=0；UU 回代 x3=0,x2=0,x1=1x_3=0,x_2=0,x_1=1。原 AA 第一列正是右端。
  4. J=[1224]J=\begin{bmatrix}1&2\\2&4\end{bmatrix} 每行都有非零元，却只有一个主元；齐次方程有非零解 (−2,1)𝖳(-2,1)^{\mathsf T}，不可逆。

分块与多个方程组 Blocks and Multiple Linear Systems

单位分块下三角矩阵的求逆练习及双侧验证请同时标明各块尺寸，并检查两个次序的乘积。

  3. 对 M=[BC0D]M=\begin{bmatrix}B&C\\0&D\end{bmatrix}，说明方形对角块条件、可逆条件和右上逆块的次序。
  4. 已有 PA=LUPA=LU，新右端到来时求解哪两个方程？中途换行为什么不能只改 UU？比较 kk 个右端复用与独立消元的常规稠密方阵计算量。

  2. 不能。第一对块为 2×12\times1 与 2×22\times2，不相容；可把 BB 行组改为 1+21+2。
  3. B:p×p,D:q×q,C:p×qB:p\times p,D:q\times q,C:p\times q。MM 可逆当且仅当 B,DB,D 都可逆；右上逆块是 −B−1CD−1-B^{-1}CD^{-1}。必要性与两个乘积的核对见完整推导。
